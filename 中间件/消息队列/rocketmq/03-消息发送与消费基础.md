# 第3章-消息发送与消费基础

## 3.1 普通消息发送

RocketMQ 提供了三种消息发送方式：同步发送、异步发送和单向发送。

### 同步发送

同步发送是最常用的消息发送方式，发送方会阻塞等待 Broker 的响应结果。

```java
import org.apache.rocketmq.client.producer.DefaultMQProducer;
import org.apache.rocketmq.client.producer.SendResult;
import org.apache.rocketmq.common.message.Message;
import org.apache.rocketmq.remoting.common.RemotingUtil;

public class SyncProducer {
    public static void main(String[] args) throws Exception {
        // 1. 创建生产者实例，指定生产者组名
        DefaultMQProducer producer = new DefaultMQProducer("my-producer-group");
        // 2. 设置 NameServer 地址
        producer.setNamesrvAddr("localhost:9876");
        // 3. 启动生产者
        producer.start();

        try {
            // 4. 创建消息实例，指定主题、标签和消息体
            Message msg = new Message(
                "TopicTest",        // 主题
                "TagA",             // 标签
                "Hello RocketMQ".getBytes(RemotingUtil.DEFAULT_CHARSET)  // 消息体
            );

            // 5. 同步发送消息，等待发送结果
            SendResult sendResult = producer.send(msg);
            System.out.printf("发送成功: msgId=%s, status=%s%n",
                sendResult.getMsgId(), sendResult.getSendStatus());
        } finally {
            // 6. 关闭生产者
            producer.shutdown();
        }
    }
}
```

### 异步发送

异步发送不会阻塞发送线程，适用于对响应时间敏感的业务场景。

```java
import org.apache.rocketmq.client.producer.DefaultMQProducer;
import org.apache.rocketmq.client.producer.SendCallback;
import org.apache.rocketmq.client.producer.SendResult;
import org.apache.rocketmq.common.message.Message;
import org.apache.rocketmq.remoting.common.RemotingUtil;

public class AsyncProducer {
    public static void main(String[] args) throws Exception {
        DefaultMQProducer producer = new DefaultMQProducer("my-async-producer-group");
        producer.setNamesrvAddr("localhost:9876");
        producer.start();

        // 设置异步发送失败重试次数
        producer.setRetryTimesWhenSendAsyncFailed(2);

        try {
            Message msg = new Message(
                "TopicTest",
                "TagA",
                "Async message content".getBytes(RemotingUtil.DEFAULT_CHARSET)
            );

            // 异步发送，通过回调处理发送结果
            producer.send(msg, new SendCallback() {
                @Override
                public void onSuccess(SendResult sendResult) {
                    System.out.printf("异步发送成功: msgId=%s%n", sendResult.getMsgId());
                }

                @Override
                public void onException(Throwable e) {
                    System.err.printf("异步发送失败: %s%n", e.getMessage());
                }
            });

            // 异步发送不会阻塞，需要等待一段时间确保回调执行
            Thread.sleep(3000);
        } finally {
            producer.shutdown();
        }
    }
}
```

### 单向发送

单向发送只管发送，不等待任何响应，适用于对可靠性要求不高的场景，如日志收集。

```java
import org.apache.rocketmq.client.producer.DefaultMQProducer;
import org.apache.rocketmq.common.message.Message;
import org.apache.rocketmq.remoting.common.RemotingUtil;

public class OnewayProducer {
    public static void main(String[] args) throws Exception {
        DefaultMQProducer producer = new DefaultMQProducer("my-oneway-producer-group");
        producer.setNamesrvAddr("localhost:9876");
        producer.start();

        try {
            Message msg = new Message(
                "TopicTest",
                "TagA",
                "Oneway message content".getBytes(RemotingUtil.DEFAULT_CHARSET)
            );

            // 单向发送，不等待响应
            producer.sendOneway(msg);
            System.out.println("单向消息已发送");
        } finally {
            producer.shutdown();
        }
    }
}
```

## 3.2 消息消费模式

### Push 模式 vs Pull 模式

RocketMQ 支持两种消费模式：

| 特性 | Push 模式 | Pull 模式 |
|------|----------|----------|
| 实现方式 | Broker 主动推送给消费者 | 消费者主动从 Broker 拉取 |
| 实时性 | 高，消息即时到达 | 取决于拉取间隔 |
| 复杂度 | 简单，用户只需实现监听器 | 复杂，需要自行管理拉取逻辑 |
| 推荐场景 | 大多数业务场景 | 需要自定义消费控制 |

Push 模式实际上是 Pull 模式的封装，客户端通过长轮询实现类似 Push 的效果。

### 消费监听器

Push 模式使用 `MessageListenerConcurrently` 或 `MessageListenerOrderly` 实现消息处理。

```java
import org.apache.rocketmq.client.consumer.DefaultMQPushConsumer;
import org.apache.rocketmq.client.consumer.listener.MessageListenerConcurrently;
import org.apache.rocketmq.client.consumer.listener.ConsumeConcurrentlyContext;
import org.apache.rocketmq.common.message.MessageExt;
import org.apache.rocketmq.common.protocol.heartbeat.MessageModel;
import java.util.List;

public class PushConsumer {
    public static void main(String[] args) throws Exception {
        // 1. 创建消费者实例，指定消费者组
        DefaultMQPushConsumer consumer = new DefaultMQPushConsumer("my-consumer-group");

        // 2. 设置 NameServer 地址
        consumer.setNamesrvAddr("localhost:9876");

        // 3. 订阅主题和标签
        consumer.subscribe("TopicTest", "*");

        // 4. 设置消费模式（集群消费或广播消费）
        consumer.setMessageModel(MessageModel.CLUSTERING);

        // 5. 注册消息监听器
        consumer.registerMessageListener(new MessageListenerConcurrently() {
            @Override
            public ConsumeConcurrentlyStatus consumeMessage(
                    List<MessageExt> msgs,
                    ConsumeConcurrentlyContext context) {
                for (MessageExt msg : msgs) {
                    System.out.printf("收到消息: msgId=%s, content=%s%n",
                        msg.getMsgId(), new String(msg.getBody()));
                }
                // 标记消息消费成功
                return ConsumeConcurrentlyStatus.CONSUME_SUCCESS;
            }
        });

        // 6. 启动消费者
        consumer.start();
        System.out.println("消费者已启动");

        // 保持主线程运行
        Thread.sleep(Long.MAX_VALUE);
    }
}
```

**两种监听器区别：**

- `MessageListenerConcurrently`：并发消费，适用于大多数场景，处理速度快但不能保证顺序
- `MessageListenerOrderly`：顺序消费，保证同一队列的消息按顺序处理，适用于需要严格顺序的场景

## 3.3 消费者分组

### Consumer Group 概念

消费者分组（Consumer Group）是 RocketMQ 中实现负载均衡和容错的基础概念：

- 同一分组内的消费者共享相同的订阅关系
- 分组内消费者共同承担消息消费任务，实现负载均衡
- 不同分组可以独立消费同一主题的消息

```
主题 TopicTest
    └── 队列 Queue1 ─────┬──→ 消费者组 A (消费者 A1)
        └── 队列 Queue2 ──┴──→ 消费者组 A (消费者 A2)
```

### 分组内负载均衡

当一个消费者组内有多个消费者时，队列会被均匀分配：

```java
// RocketMQ 自动进行负载均衡，无需手动配置
// 假设主题有 6 个队列，2 个消费者：
// - 消费者 1 处理队列 0,1,2,3
// - 消费者 2 处理队列 4,5

// 调整消费者数量时，RocketMQ 会自动重新分配
consumer.setConsumeThreadMin(10);  // 最小消费线程数
consumer.setConsumeThreadMax(20);  // 最大消费线程数
```

### Producer 代码

```java
package com.rocketmq.tutorial;

import org.apache.rocketmq.client.producer.DefaultMQProducer;
import org.apache.rocketmq.client.producer.SendResult;
import org.apache.rocketmq.common.message.Message;
import org.apache.rocketmq.remoting.common.RemotingUtil;

/**
 * 消息生产者示例
 */
public class Producer {
    private static final String NAMESRV_ADDR = "localhost:9876";
    private static final String PRODUCER_GROUP = "my-producer-group";
    private static final String TOPIC = "TopicTest";
    private static final String TAGS = "TagA";
    private static final String KEYS = "your-message-key";

    public static void main(String[] args) throws Exception {
        // 1. 创建生产者实例
        DefaultMQProducer producer = new DefaultMQProducer(PRODUCER_GROUP);

        // 2. 设置 NameServer 地址
        producer.setNamesrvAddr(NAMESRV_ADDR);

        // 3. 启动生产者
        producer.start();
        System.out.println("生产者已启动");

        try {
            // 4. 发送 10 条消息
            for (int i = 1; i <= 10; i++) {
                // 创建消息
                String body = String.format("Hello RocketMQ #%d", i);
                Message msg = new Message(
                    TOPIC,      // 主题
                    TAGS,       // 标签
                    KEYS,       // 消息 key
                    body.getBytes(RemotingUtil.DEFAULT_CHARSET)
                );

                // 设置消息属性（可选）
                msg.putUserProperty("sequence", String.valueOf(i));

                // 同步发送
                SendResult result = producer.send(msg);

                System.out.printf("消息 #%d 发送成功: msgId=%s, status=%s%n",
                    i, result.getMsgId(), result.getSendStatus());
            }
        } catch (Exception e) {
            System.err.printf("发送消息失败: %s%n", e.getMessage());
            e.printStackTrace();
        } finally {
            // 5. 关闭生产者
            producer.shutdown();
            System.out.println("生产者已关闭");
        }
    }
}
```

### Consumer 代码

```java
package com.rocketmq.tutorial;

import org.apache.rocketmq.client.consumer.DefaultMQPushConsumer;
import org.apache.rocketmq.client.consumer.listener.ConsumeConcurrentlyContext;
import org.apache.rocketmq.client.consumer.listener.ConsumeConcurrentlyStatus;
import org.apache.rocketmq.client.consumer.listener.MessageListenerConcurrently;
import org.apache.rocketmq.common.message.MessageExt;
import org.apache.rocketmq.common.protocol.heartbeat.MessageModel;

import java.util.List;

/**
 * 消息消费者示例
 */
public class Consumer {
    private static final String NAMESRV_ADDR = "localhost:9876";
    private static final String CONSUMER_GROUP = "my-consumer-group";
    private static final String TOPIC = "TopicTest";
    private static final String TAGS = "*";  // 订阅所有标签

    public static void main(String[] args) throws Exception {
        // 1. 创建消费者实例
        DefaultMQPushConsumer consumer = new DefaultMQPushConsumer(CONSUMER_GROUP);

        // 2. 设置 NameServer 地址
        consumer.setNamesrvAddr(NAMESRV_ADDR);

        // 3. 设置消费模式
        consumer.setMessageModel(MessageModel.CLUSTERING);

        // 4. 设置订阅主题和标签
        consumer.subscribe(TOPIC, TAGS);

        // 5. 设置消息消费线程数
        consumer.setConsumeThreadMin(5);
        consumer.setConsumeThreadMax(10);

        // 6. 注册消息监听器
        consumer.registerMessageListener(new MessageListenerConcurrently() {
            @Override
            public ConsumeConcurrentlyStatus consumeMessage(
                    List<MessageExt> msgs,
                    ConsumeConcurrentlyContext context) {

                for (MessageExt msg : msgs) {
                    String body = new String(msg.getBody());
                    String sequence = msg.getUserProperty("sequence");
                    System.out.printf("[线程 %s] 收到消息: seq=%s, body=%s%n",
                        Thread.currentThread().getName(),
                        sequence != null ? sequence : "N/A",
                        body);
                }

                // 返回消费成功状态
                return ConsumeConcurrentlyStatus.CONSUME_SUCCESS;
            }
        });

        // 7. 启动消费者
        consumer.start();
        System.out.println("消费者已启动，订阅主题: " + TOPIC);

        // 保持主线程运行
        System.out.println("按 Ctrl+C 停止消费者");
        Thread.sleep(Long.MAX_VALUE);
    }
}
```

### 运行说明

**1. 启动 RocketMQ 服务**

确保 NameServer 和 Broker 已启动：

```bash
# 启动 NameServer
mqnamesrv

# 启动 Broker
mqbroker -n localhost:9876
```

**2. 运行 Producer**

编译并运行生产者：

```bash
mvn clean compile
java -cp target/classes com.rocketmq.tutorial.Producer
```

预期输出：
```
生产者已启动
消息 #1 发送成功: msgId=AC1ICD..., status=SEND_OK
消息 #2 发送成功: msgId=AC1ICE..., status=SEND_OK
...
消息 #10 发送成功: msgId=AC1ICN..., status=SEND_OK
生产者已关闭
```

**3. 运行 Consumer**

在另一个终端运行消费者：

```bash
java -cp target/classes com.rocketmq.tutorial.Consumer
```

预期输出：
```
消费者已启动，订阅主题: TopicTest
按 Ctrl+C 停止消费者
[线程 ConsumeMessageThread_1] 收到消息: seq=1, body=Hello RocketMQ #1
[线程 ConsumeMessageThread_2] 收到消息: seq=5, body=Hello RocketMQ #5
[线程 ConsumeMessageThread_3] 收到消息: seq=3, body=Hello RocketMQ #3
...
```

**注意事项：**

- 确保 RocketMQ 服务已正常启动
- 生产者和消费者的 Group 名称可以根据业务需求自定义
- 消费者订阅主题后，会自动接收该主题的消息
- 生产环境建议使用集群部署方式运行 RocketMQ
