# 第08章 租户权限与安全

## 8.1 概述

在多租户系统中，租户权限与安全是保障数据隔离的核心机制。每个租户的数据必须严格隔离，任何跨租户的非法访问都必须被阻止。本章将详细讲解如何实现基于租户的访问控制、数据权限控制、以及相关的安全防护措施。

### 8.1.1 安全控制目标

```
┌─────────────────────────────────────────────────────────────────┐
│                      多租户安全控制目标                           │
├─────────────────────────────────────────────────────────────────┤
│  1. 数据隔离性  ─  用户只能访问所属租户的数据                      │
│  2. 访问控制性  ─  基于租户ID的隐式权限过滤                        │
│  3. 防护性      ─  防止SQL注入、租户ID伪造等攻击                   │
│  4. 可审计性    ─  敏感操作必须记录审计日志                        │
│  5. 一致性      ─  JWT中的租户信息必须与实际一致                   │
└─────────────────────────────────────────────────────────────────┘
```

## 8.2 基于租户的访问控制（Tenant-Based Authorization）

### 8.2.1 核心原理

基于租户的访问控制是一种隐式授权机制。用户登录后，系统会自动将其租户ID绑定到会话中，后续所有数据访问都会自动带上租户过滤条件，无需显式指定。

```
┌─────────────────────────────────────────────────────────────────┐
│                    租户访问控制流程                               │
│                                                                 │
│  ┌──────────┐    登录     ┌──────────┐    请求     ┌──────────┐  │
│  │   用户   │ ──────────> │  系统    │ ─────────> │  数据    │  │
│  │          │            │          │            │  查询    │  │
│  └──────────┘            └──────────┘            └──────────┘  │
│       │                      │                       │         │
│       │                      ▼                       ▼         │
│       │               ┌──────────────┐         ┌───────────┐    │
│       │               │ 提取tenant_id │ ─────> │ WHERE    │    │
│       │               │ 从JWT/会话    │         │ tenant_id=?│   │
│       │               └──────────────┘         └───────────┘    │
│       │                                            │            │
│       └────────────────────────────────────────────┘            │
│                     隐式自动注入租户条件                          │
└─────────────────────────────────────────────────────────────────┘
```

### 8.2.2 租户上下文（TenantContext）

租户上下文是存储当前请求对应租户信息的容器，通常使用 ThreadLocal 实现：

```java
package com.saas.tenant.context;

import org.springframework.stereotype.Component;

/**
 * 租户上下文持有者
 * 使用 ThreadLocal 存储当前线程的租户信息
 */
@Component
public class TenantContext {

    private static final ThreadLocal<String> CURRENT_TENANT = new ThreadLocal<>();
    private static final ThreadLocal<Long> CURRENT_USER_ID = new ThreadLocal<>();
    private static final ThreadLocal<String> CURRENT_USERNAME = new ThreadLocal<>();

    /**
     * 设置当前租户ID
     */
    public static void setCurrentTenant(String tenantId) {
        CURRENT_TENANT.set(tenantId);
    }

    /**
     * 获取当前租户ID
     */
    public static String getCurrentTenant() {
        return CURRENT_TENANT.get();
    }

    /**
     * 设置当前用户ID
     */
    public static void setCurrentUserId(Long userId) {
        CURRENT_USER_ID.set(userId);
    }

    /**
     * 获取当前用户ID
     */
    public static Long getCurrentUserId() {
        return CURRENT_USER_ID.get();
    }

    /**
     * 设置当前用户名
     */
    public static void setCurrentUsername(String username) {
        CURRENT_USERNAME.set(username);
    }

    /**
     * 获取当前用户名
     */
    public static String getCurrentUsername() {
        return CURRENT_USERNAME.get();
    }

    /**
     * 清除上下文（重要：防止内存泄漏）
     */
    public static void clear() {
        CURRENT_TENANT.remove();
        CURRENT_USER_ID.remove();
        CURRENT_USERNAME.remove();
    }
}
```

### 8.2.3 租户上下文拦截器

通过拦截器在请求开始时解析租户信息并设置到上下文中：

```java
package com.saas.tenant.interceptor;

import com.saas.tenant.context.TenantContext;
import com.saas.common.security.JwtTokenProvider;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Component;
import org.springframework.web.servlet.HandlerInterceptor;

/**
 * 租户上下文拦截器
 * 在请求处理前提取租户信息并设置到 TenantContext
 */
@Slf4j
@Component
@RequiredArgsConstructor
public class TenantContextInterceptor implements HandlerInterceptor {

    private final JwtTokenProvider jwtTokenProvider;

    @Override
    public boolean preHandle(HttpServletRequest request,
                            HttpServletResponse response,
                            Object handler) {
        String token = extractToken(request);

        if (token != null && jwtTokenProvider.validateToken(token)) {
            String tenantId = jwtTokenProvider.getTenantIdFromToken(token);
            Long userId = jwtTokenProvider.getUserIdFromToken(token);
            String username = jwtTokenProvider.getUsernameFromToken(token);

            TenantContext.setCurrentTenant(tenantId);
            TenantContext.setCurrentUserId(userId);
            TenantContext.setCurrentUsername(username);

            log.debug("设置租户上下文: tenantId={}, userId={}, username={}",
                     tenantId, userId, username);
        }

        return true;
    }

    @Override
    public void afterCompletion(HttpServletRequest request,
                               HttpServletResponse response,
                               Object handler,
                               Exception ex) {
        // 请求完成后清除上下文，防止内存泄漏
        TenantContext.clear();
    }

    private String extractToken(HttpServletRequest request) {
        String bearerToken = request.getHeader("Authorization");
        if (bearerToken != null && bearerToken.startsWith("Bearer ")) {
            return bearerToken.substring(7);
        }
        return null;
    }
}
```

## 8.3 Spring Security 集成

### 8.3.1 租户认证过滤器

租户认证过滤器是最核心的安全组件，它在每次请求时验证用户是否有权访问当前租户：

```java
package com.saas.tenant.security;

import com.saas.tenant.context.TenantContext;
import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import lombok.extern.slf4j.Slf4j;
import org.springframework.security.access.AccessDeniedException;
import org.springframework.security.core.Authentication;
import org.springframework.security.core.context.SecurityContextHolder;
import org.springframework.stereotype.Component;
import org.springframework.web.filter.OncePerRequestFilter;

import java.io.IOException;

/**
 * 租户授权过滤器
 * 验证当前用户是否有权访问请求的租户
 */
@Slf4j
@Component
public class TenantAuthorizationFilter extends OncePerRequestFilter {

    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                   HttpServletResponse response,
                                   FilterChain filterChain)
            throws ServletException, IOException {

        // 1. 获取当前请求的租户ID（从请求头或URL路径）
        String currentTenant = TenantContext.getCurrentTenant();

        // 2. 如果没有租户上下文（公开接口除外），直接放行
        if (currentTenant == null) {
            // 可以根据接口配置判断是否允许匿名访问
            filterChain.doFilter(request, response);
            return;
        }

        // 3. 获取当前认证信息
        Authentication auth = SecurityContextHolder.getContext().getAuthentication();

        if (auth != null && auth.isAuthenticated()) {
            // 4. 验证用户所属租户与当前请求的租户是否一致
            if (auth.getDetails() instanceof TenantUserDetails userDetails) {
                if (!userDetails.getTenantId().equals(currentTenant)) {
                    log.warn("跨租户访问尝试: 用户{}属于租户{}，试图访问租户{}",
                            userDetails.getUsername(),
                            userDetails.getTenantId(),
                            currentTenant);

                    throw new AccessDeniedException("无权访问此租户的数据");
                }
            }
        }

        filterChain.doFilter(request, response);
    }

    /**
     * 指定哪些URL不需要进行租户验证
     */
    @Override
    protected boolean shouldNotFilter(HttpServletRequest request) {
        String path = request.getRequestURI();
        // 登录、注册、公开接口不需要租户验证
        return path.startsWith("/api/public/") ||
               path.startsWith("/api/auth/") ||
               path.equals("/health") ||
               path.equals("/actuator/health");
    }
}
```

### 8.3.3 租户认证服务

```java
package com.saas.tenant.security;

import com.saas.tenant.context.TenantContext;
import lombok.RequiredArgsConstructor;
import org.springframework.security.core.authority.SimpleGrantedAuthority;
import org.springframework.security.core.userdetails.UserDetails;
import org.springframework.security.core.userdetails.UserDetailsService;
import org.springframework.security.core.userdetails.UsernameNotFoundException;
import org.springframework.stereotype.Service;

import java.util.List;

/**
 * 租户感知用户认证服务
 */
@Service
@RequiredArgsConstructor
public class TenantUserDetailsService implements UserDetailsService {

    @Override
    public UserDetails loadUserByUsername(String username) throws UsernameNotFoundException {
        // 注意：这里需要根据当前租户上下文来查询用户
        String currentTenant = TenantContext.getCurrentTenant();

        if (currentTenant == null) {
            throw new UsernameNotFoundException("无法确定租户上下文");
        }

        // 调用用户服务查询用户信息（需要包含租户条件）
        UserDTO user = userService.findByUsernameAndTenant(username, currentTenant);

        if (user == null) {
            throw new UsernameNotFoundException("用户不存在: " + username);
        }

        return new TenantUserDetails(
            user.getUsername(),
            user.getPassword(),
            user.isEnabled(),
            true, // accountNonExpired
            true, // credentialsNonExpired
            true, // accountNonLocked
            user.getTenantId(),
            user.getId(),
            List.of(new SimpleGrantedAuthority("ROLE_" + user.getRole()))
        );
    }
}
```

### 8.3.4 Security 配置

```java
package com.saas.config;

import com.saas.tenant.security.TenantAuthorizationFilter;
import lombok.RequiredArgsConstructor;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.annotation.method.configuration.EnableMethodSecurity;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.config.http.SessionCreationPolicy;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.security.web.SecurityFilterChain;
import org.springframework.security.web.authentication.UsernamePasswordAuthenticationFilter;

/**
 * Spring Security 配置
 */
@Configuration
@EnableWebSecurity
@EnableMethodSecurity
@RequiredArgsConstructor
public class SecurityConfig {

    private final TenantAuthorizationFilter tenantAuthorizationFilter;

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
            // 禁用CSRF（适用于前后端分离）
            .csrf(csrf -> csrf.disable())

            // 禁用Session，使用无状态认证
            .sessionManagement(session ->
                session.sessionCreationPolicy(SessionCreationPolicy.STATELESS))

            // 配置授权规则
            .authorizeHttpRequests(auth -> auth
                // 公开接口
                .requestMatchers("/api/public/**", "/api/auth/**").permitAll()
                .requestMatchers("/health", "/actuator/health").permitAll()
                // 其他接口需要认证
                .anyRequest().authenticated()
            )

            // 添加租户授权过滤器（在UsernamePasswordAuthenticationFilter之前）
            .addFilterBefore(tenantAuthorizationFilter,
                           UsernamePasswordAuthenticationFilter.class);

        return http.build();
    }

    @Bean
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();
    }
}
```

### 8.4.1 查询自动注入租户条件

数据访问层是租户隔离的最重要防线。所有数据查询必须自动带上租户条件：

```

│  │  Service    │ ───> │  Mapper     │ ───> │  SQL执行    │     │
│  │  业务层     │      │  数据访问层  │      │             │     │
│  └─────────────┘      └─────────────┘      └─────────────┘     │
│         │                    │                     │           │

│  ┌─────────────┐      ┌─────────────┐      ┌─────────────┐     │
```

#### MyBatis 拦截器实现

```java
package com.saas.tenant.interceptor;

import com.saas.tenant.context.TenantContext;
import lombok.extern.slf4j.Slf4j;
import org.apache.ibatis.executor.Executor;
import org.apache.ibatis.mapping.BoundSql;
import org.apache.ibatis.mapping.MappedStatement;
import org.apache.ibatis.mapping.SqlSource;
import org.apache.ibatis.plugin.*;
import org.apache.ibatis.session.ResultHandler;
import org.apache.ibatis.session.RowBounds;
import org.springframework.stereotype.Component;

import java.lang.reflect.Method;
import java.util.Properties;

/**
 * MyBatis 租户数据拦截器
 * 自动在所有查询中注入租户条件
 */
@Slf4j
@Component
@Intercepts({
    @Signature(type = Executor.class, method = "query",
              args = {MappedStatement.class, Object.class, RowBounds.class, ResultHandler.class}),
    @Signature(type = Executor.class, method = "update",
              args = {MappedStatement.class, Object.class})
})
public class TenantDataInterceptor implements Interceptor {

    private static final String TENANT_FIELD = "tenant_id";
    private static final String TENANT_COLUMN = "tenant_id";

    @Override
    public Object intercept(Invocation invocation) throws Throwable {
        MappedStatement ms = (MappedStatement) invocation.getArgs()[0];
        Object parameter = invocation.getArgs()[1];

        // 获取当前租户ID
        String tenantId = TenantContext.getCurrentTenant();

        // 如果没有租户上下文，不做处理
        if (tenantId == null) {
            return invocation.proceed();
        }

        BoundSql boundSql = ms.getBoundSql(parameter);
        String originalSql = boundSql.getSql();

        // 判断SQL类型并注入租户条件
        String modifiedSql = modifySql(ms.getSqlCommandType(), originalSql, tenantId);

        // 创建新的 MappedStatement
        MappedStatement newMs = createNewMappedStatement(ms, modifiedSql);

        // 替换参数
        invocation.getArgs()[0] = newMs;

        return invocation.proceed();
    }

    /**
     * 根据SQL类型修改SQL语句
     */
    private String modifySql(SqlCommandType commandType, String originalSql, String tenantId) {
        return switch (commandType) {
            case SELECT -> injectWhereClause(originalSql, tenantId);
            case INSERT -> injectInsertValue(originalSql, tenantId);
            case UPDATE -> injectUpdateWhere(originalSql, tenantId);
            case DELETE -> injectDeleteWhere(originalSql, tenantId);
            default -> originalSql;
        };
    }

    /**
     * 为SELECT语句注入WHERE条件
     */
    private String injectWhereClause(String sql, String tenantId) {
        String upperSql = sql.toUpperCase();

        if (upperSql.contains("WHERE")) {
            // 已有WHERE子句，追加条件
            if (upperSql.contains("AND " + TENANT_COLUMN.toUpperCase())) {
                // 已经有租户条件，不重复添加
                return sql;
            }
            return sql + " AND " + TENANT_COLUMN + " = '" + tenantId + "'";
        } else {
            // 没有WHERE子句，添加WHERE子句
            if (upperSql.contains("GROUP BY")) {
                // 处理GROUP BY后面的HAVING
                int groupIndex = upperSql.indexOf("GROUP BY");
                String beforeGroup = sql.substring(0, groupIndex);
                String afterGroup = sql.substring(groupIndex);
                return beforeGroup + " WHERE " + TENANT_COLUMN + " = '" + tenantId + "' " + afterGroup;
            }
            if (upperSql.contains("ORDER BY")) {
                // 处理ORDER BY
                int orderIndex = upperSql.indexOf("ORDER BY");
                String beforeOrder = sql.substring(0, orderIndex);
                String afterOrder = sql.substring(orderIndex);
                return beforeOrder + " WHERE " + TENANT_COLUMN + " = '" + tenantId + "' " + afterOrder;
            }
            return sql + " WHERE " + TENANT_COLUMN + " = '" + tenantId + "'";
        }
    }

    /**
     * 为INSERT语句注入租户ID值
     */
    private String injectInsertValue(String sql, String tenantId) {
        // 简化实现，实际需要更复杂的解析
        if (!sql.toUpperCase().contains(TENANT_COLUMN.toUpperCase())) {
            // 如果SQL中没有tenant_id字段，尝试添加
            // 这里需要根据实际表结构来判断
        }
        return sql;
    }

    /**
     * 为UPDATE语句注入WHERE条件
     */
    private String injectUpdateWhere(String sql, String tenantId) {
        String upperSql = sql.toUpperCase();

        if (upperSql.contains("WHERE")) {
            if (upperSql.contains("AND " + TENANT_COLUMN.toUpperCase())) {
                return sql;
            }
            return sql + " AND " + TENANT_COLUMN + " = '" + tenantId + "'";
        } else {
            return sql + " WHERE " + TENANT_COLUMN + " = '" + tenantId + "'";
        }
    }

    /**
     * 为DELETE语句注入WHERE条件
     */
    private String injectDeleteWhere(String sql, String tenantId) {
        String upperSql = sql.toUpperCase();

        if (upperSql.contains("WHERE")) {
            if (upperSql.contains("AND " + TENANT_COLUMN.toUpperCase())) {
                return sql;
            }
            return sql + " AND " + TENANT_COLUMN + " = '" + tenantId + "'";
        } else {
            return sql + " WHERE " + TENANT_COLUMN + " = '" + tenantId + "'";
        }
    }

    private MappedStatement createNewMappedStatement(MappedStatement ms, String newSql) {

    }

        return Plugin.wrap(target, this);
    }
```

### 8.4.2 基于租户的 MyBatis Plus 插件

```java
package com.saas.tenant.plugin;

import com.baomidou.mybatisplus.extension.plugins.handler.TenantLineHandler;
import com.saas.tenant.context.TenantContext;
import net.sf.jsqlparser.expression.Expression;
import net.sf.jsqlparser.expression.LongValue;
import org.springframework.stereotype.Component;

/**
 * MyBatis Plus 租户处理器
 */
@Component
public class TenantLineHandlerImpl implements TenantLineHandler {

    @Override
    public Expression getTenantId() {
        String tenantId = TenantContext.getCurrentTenant();
        if (tenantId == null) {
            return null;
        }
        // 使用租户ID作为表达式
        return new LongValue(Long.parseLong(tenantId));
    }

    @Override
    public String getTenantIdColumn() {
        return "tenant_id";
    }

    /**
     * 判断是否忽略租户过滤
     * 某些系统表可能不需要租户过滤
     */
    @Override
    public boolean ignoreTable(String tableName) {
        // 系统表不需要租户过滤
        return "sys_user".equals(tableName) ||
               "sys_role".equals(tableName) ||
               "sys_dict".equals(tableName);
    }
}
```

### 8.4.3 修改/删除时的租户校验

```java
package com.saas.tenant.service;

import com.saas.common.exception.AccessDeniedException;
import com.saas.tenant.context.TenantContext;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Service;

/**
 * 租户数据校验服务
 */
@Slf4j
@Service
public class TenantDataValidationService {

    /**
     * 校验当前用户是否有权操作该数据
     */
    public void validateDataAccess(String dataTenantId) {
        String currentTenant = TenantContext.getCurrentTenant();

        if (currentTenant == null) {
            log.error("数据访问校验失败：租户上下文为空");
            throw new AccessDeniedException("无法确定租户上下文");
        }

        if (!currentTenant.equals(dataTenantId)) {
            log.warn("跨租户数据访问尝试：当前租户{}，数据所属租户{}",
                    currentTenant, dataTenantId);
            throw new AccessDeniedException("无权访问此数据");
        }
    }

    /**
     * 校验当前用户是否有权操作该数据（基于数据对象）
     */
    public <T> void validateDataAccess(T entity, String tenantIdFieldName) {
        try {
            Object tenantId = entity.getClass().getDeclaredField(tenantIdFieldName)
                    .get(entity);
            validateDataAccess(tenantId.toString());
        } catch (NoSuchFieldException | IllegalAccessException e) {
            log.error("数据访问校验失败：无法获取租户ID字段", e);
            throw new AccessDeniedException("数据访问校验失败");
        }
    }
}
```

#### SQL 注入防护实现

```java
package com.saas.common.security;

import org.springframework.stereotype.Component;

import java.util.regex.Pattern;

/**
 * SQL注入检测器
 */
@Component
public class SqlInjectionDetector {

    // 危险SQL模式
    private static final Pattern[] DANGEROUS_PATTERNS = {
        // 注释符
        Pattern.compile("--"),
        Pattern.compile("/\\*"),
        Pattern.compile("\\*/"),
        // 分号（结束语句）
        Pattern.compile(";"),
        // UNION注入
        Pattern.compile("(?i)union.*select"),
        Pattern.compile("(?i)union.*all"),
        // 危险函数
        Pattern.compile("(?i)exec\\s*\\("),
        Pattern.compile("(?i)execute\\s*\\("),
        Pattern.compile("(?i)eval\\s*\\("),
        Pattern.compile("(?i)system\\s*\\("),
        // 引号逃逸
        Pattern.compile("(?i)'\\s*or\\s*'"),
        Pattern.compile("(?i)'\\s*and\\s*'"),
        // 常见攻击向量
        Pattern.compile("(?i)drop\\s+table"),
        Pattern.compile("(?i)drop\\s+database"),
        Pattern.compile("(?i)truncate\\s+"),
        Pattern.compile("(?i)alter\\s+"),
        Pattern.compile("(?i)create\\s+"),
        // 堆叠查询
        Pattern.compile(";\\s*\\w+\\s*\\("),
    };

    // 允许的字符模式（白名单）
    private static final Pattern ALLOWED_CHARS = Pattern.compile("^[a-zA-Z0-9_\\-\\s@.,]+$");

    /**
     * 检测是否存在SQL注入风险
     */
    public boolean containsSqlInjection(String input) {
        if (input == null || input.isEmpty()) {
            return false;
        }

        // 检查危险模式
        for (Pattern pattern : DANGEROUS_PATTERNS) {
            if (pattern.matcher(input).find()) {
                return true;
            }
        }

        return false;
    }

    /**
     * 验证输入是否只包含允许的字符
     */
    public boolean isValidInput(String input) {
        if (input == null) {
            return true;
        }
        return ALLOWED_CHARS.matcher(input).matches();
    }

    /**
     * 清理输入（如果检测到注入则返回null）
     */
    public String sanitize(String input) {
        if (containsSqlInjection(input)) {
            return null;
        }
        return input;
    }
}
```

```java
            return args[0].toString();

        return null;
```

### 8.6.2 JWT Token 提供者

```java
package com.saas.common.security;

import io.jsonwebtoken.*;
import io.jsonwebtoken.security.Keys;
import jakarta.annotation.PostConstruct;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;

import javax.crypto.SecretKey;
import java.nio.charset.StandardCharsets;
import java.util.Date;
import java.util.HashMap;
import java.util.Map;

/**
 * JWT Token 提供者
 */
@Slf4j
@Component
public class JwtTokenProvider {

    @Value("${jwt.secret}")
    private String jwtSecret;

    @Value("${jwt.expiration:86400000}")
    private long jwtExpiration;

    private SecretKey secretKey;

    @PostConstruct
    public void init() {
        this.secretKey = Keys.hmacShaKeyFor(jwtSecret.getBytes(StandardCharsets.UTF_8));
    }

    /**
     * 生成 Token
     */
    public String generateToken(String username, String tenantId, Long userId) {
        Date now = new Date();
        Date expiryDate = new Date(now.getTime() + jwtExpiration);

        Map<String, Object> claims = new HashMap<>();
        claims.put("tenant_id", tenantId);
        claims.put("user_id", userId);
        claims.put("username", username);

        return Jwts.builder()
                .setClaims(claims)
                .setSubject(username)
                .setIssuedAt(now)
                .setExpiration(expiryDate)
                .signWith(secretKey, SignatureAlgorithm.HS256)
                .compact();
    }

    /**
     * 验证 Token
     */
    public boolean validateToken(String token) {
        try {
            Jwts.parserBuilder()
                    .setSigningKey(secretKey)
                    .build()
                    .parseClaimsJws(token);
            return true;
        } catch (JwtException | IllegalArgumentException e) {
            log.error("JWT Token 验证失败: {}", e.getMessage());
            return false;
        }
    }

    /**
     * 从 Token 获取用户名
     */
    public String getUsernameFromToken(String token) {
        Claims claims = getClaims(token);
        return claims.getSubject();
    }

    /**
     * 从 Token 获取租户ID
     */
    public String getTenantIdFromToken(String token) {
        Claims claims = getClaims(token);
        return claims.get("tenant_id", String.class);
    }

    /**
     * 从 Token 获取用户ID
     */
    public Long getUserIdFromToken(String token) {
        Claims claims = getClaims(token);
        return claims.get("user_id", Long.class);
    }

    /**
     * 获取 Token 中的所有声明
     */
    public Claims getClaims(String token) {
        return Jwts.parserBuilder()
                .setSigningKey(secretKey)
                .build()
                .parseClaimsJws(token)
                .getBody();
    }

    /**
     * 验证 Token 中的租户一致性
     */
    public boolean validateTenantConsistency(String token, String expectedTenantId) {
        String tokenTenantId = getTenantIdFromToken(token);
        return tokenTenantId != null && tokenTenantId.equals(expectedTenantId);
    }
}
```

### 8.6.3 JWT 认证过滤器

```java
package com.saas.common.security;

import com.saas.tenant.context.TenantContext;
import com.saas.tenant.security.TenantUserDetails;
import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.security.authentication.UsernamePasswordAuthenticationToken;
import org.springframework.security.core.authority.SimpleGrantedAuthority;
import org.springframework.security.core.context.SecurityContextHolder;
import org.springframework.security.web.authentication.WebAuthenticationDetailsSource;
import org.springframework.stereotype.Component;
import org.springframework.util.StringUtils;
import org.springframework.web.filter.OncePerRequestFilter;

import java.io.IOException;
import java.util.List;

/**
 * JWT 认证过滤器
 */
@Slf4j
@Component
@RequiredArgsConstructor
public class JwtAuthenticationFilter extends OncePerRequestFilter {

    private final JwtTokenProvider jwtTokenProvider;

    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                   HttpServletResponse response,
                                   FilterChain filterChain)
            throws ServletException, IOException {

        try {
            String jwt = getJwtFromRequest(request);

            if (StringUtils.hasText(jwt) && jwtTokenProvider.validateToken(jwt)) {
                String username = jwtTokenProvider.getUsernameFromToken(jwt);
                String tenantId = jwtTokenProvider.getTenantIdFromToken(jwt);
                Long userId = jwtTokenProvider.getUserIdFromToken(jwt);

                // 设置租户上下文
                TenantContext.setCurrentTenant(tenantId);
                TenantContext.setCurrentUserId(userId);
                TenantContext.setCurrentUsername(username);

                // 创建认证令牌
                TenantUserDetails userDetails = new TenantUserDetails(
                        username,
                        "", // 密码不在token中，使用空字符串
                        tenantId,
                        userId,
                        List.of(new SimpleGrantedAuthority("ROLE_USER"))
                );

                UsernamePasswordAuthenticationToken authentication =
                        new UsernamePasswordAuthenticationToken(
                                userDetails,
                                null,
                                userDetails.getAuthorities()
                        );

                authentication.setDetails(
                        new WebAuthenticationDetailsSource().buildDetails(request)
                );

                SecurityContextHolder.getContext().setAuthentication(authentication);

                log.debug("用户 {} 认证成功，租户: {}", username, tenantId);
            }
        } catch (Exception e) {
            log.error("无法设置用户认证信息: {}", e.getMessage());
        }

        filterChain.doFilter(request, response);
    }

    private String getJwtFromRequest(HttpServletRequest request) {
        String bearerToken = request.getHeader("Authorization");
        if (StringUtils.hasText(bearerToken) && bearerToken.startsWith("Bearer ")) {
            return bearerToken.substring(7);
        }
        return null;
    }
}
```

## 8.8 章节总结

本章详细介绍了多租户系统中租户权限与安全的实现方案，主要包括以下内容：

### 8.8.1 核心要点

| 序号 | 要点 | 说明 |
|-----|------|------|
| 1 | **租户上下文** | 使用 ThreadLocal 存储当前请求的租户信息，请求结束后清除 |
| 2 | **隐式授权** | 用户只能访问所属租户的数据，租户ID作为隐式过滤条件 |
| 3 | **多层防护** | 网络层 → 应用层 → 数据层 → 查询层，层层设防 |
| 4 | **JWT Token** | 在 Token 中嵌入 tenant_id，验证时确保一致性 |
| 5 | **自动注入** | MyBatis 拦截器/插件自动在所有SQL中注入租户条件 |
| 6 | **审计日志** | 记录所有敏感操作，便于事后追溯 |

### 8.8.2 安全原则

```
┌─────────────────────────────────────────────────────────────────┐
│                      租户安全五大原则                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ✓ 最小权限原则  ─  用户只能访问必要的数据                        │
│  ✓ 纵深防御原则  ─  多层安全措施互相配合                          │
│  ✓ 零信任原则   ─  永远不信任客户端输入的租户ID                    │
│  ✓ 默认拒绝原则  ─  未明确允许的访问一律拒绝                       │
│  ✓ 可审计原则   ─  所有敏感操作必须记录日志                        │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 8.8.3 常见问题与解决方案

| 问题 | 原因 | 解决方案 |
|-----|------|---------|
| 跨租户数据泄露 | 租户条件未正确注入 | 检查 MyBatis 拦截器配置 |
| Token 被盗用 | 签名密钥泄露 | 定期轮换密钥，使用 HTTPS |
| SQL 注入攻击 | 未使用参数化查询 | 强制使用参数化查询，过滤危险字符 |
| 审计日志缺失 | 记录点遗漏 | 使用 AOP 切面统一记录 |
| 性能下降 | 租户条件导致索引失效 | 确保 tenant_id 有合适索引 |
