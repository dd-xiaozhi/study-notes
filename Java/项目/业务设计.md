## 树状结构数据创建

![image-20240425213344477](https://xiaozhi-blog.oss-cn-guangzhou.aliyuncs.com/img01/img01/image-20240425213344477.png)

上图，是我们最终实现的结构，将数据以树状控件的方式展示，前端这里不多解释

树的节点与节点之间是如何进行联系的呢？

我们可以在表中设置一个 parentId 字段来建立父子关系，它表示是父亲的ID，通过这个可以找到对应节点的父亲节点，以此类推往上也是通过它来查找，以此来创建树

**代码实现**

```java
/**
 * 构建树结构数据
 * @param deptList  部门list
 */
private List<SysDeptResp> getDeptTree(List<SysDeptResp> deptList) {
    // 核心：子找父
    var deptTreeList = new ArrayList<SysDeptResp>();
    // 根据父ID进行分组
    List<Long> idList = deptList.stream().map(SysDeptResp::getDeptId).toList();
    Map<Long, List<SysDeptResp>> childrenMap = deptList.stream()
            .collect(Collectors.groupingBy(SysDeptResp::getParentId, Collectors.toList()));
    for (SysDeptResp sysDeptResp : deptList) {
        // 如果父节点不在id列表中，那么它就是顶级父节点
        Long parentId = sysDeptResp.getParentId();
        if (!idList.contains(parentId)) {
            getChildrenList(childrenMap, sysDeptResp);
            deptTreeList.add(sysDeptResp);
        }
    }
    // 如果为空说明没有父节点，直接返回匹配的数据
    if (deptTreeList.isEmpty()) {
        return deptList;
    }
    // 退出条件就是遍历完成
    return deptTreeList;
}

/**
 * 获取子节点列表
 * @param map   父ID对应的子列表
 * @param sysDeptResp   响应数据对象
 */
private void getChildrenList(Map<Long, List<SysDeptResp>> map, SysDeptResp sysDeptResp) {
    // 获取子节点列表
    List<SysDeptResp> sysDeptList = map.get(sysDeptResp.getDeptId());
    if (ObjectUtils.isEmpty(sysDeptList)) {
        sysDeptList = ListUtil.empty();
    }
    // 遍历子节点，子节点获取它的子节点
    for (SysDeptResp sysDept : sysDeptList) {
        Long deptId = sysDept.getDeptId();
        if (map.containsKey(deptId)) {
            getChildrenList(map, sysDept);
        }
    }
    sysDeptResp.setChildrenList(sysDeptList);
}
```





# 系统业务

## 使用redis来记录访问次数

### **使用拦截器来处理**

```java
@Component
public class RedisInterceptor implements HandlerInterceptor {

    @Autowired
    StringRedisTemplate redisTemplate;

    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) throws Exception {
        String uri = request.getRequestURI();
        System.out.println(uri);
        redisTemplate.opsForValue().increment(uri); // 每次访问 + 1
        return true;
    }
}
```

```java
@Configuration
public class MyConfig implements WebMvcConfigurer {

    @Autowired
    RedisInterceptor redisInterceptor;

    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(redisInterceptor)
                .addPathPatterns("/*")
                // 放行所有的静态资源
                .excludePathPatterns("/","/login","/css/**","/js/**","/fonts/**","/images/**");
    }
}
```

## 布局

![image-20240513013139842](https://xiaozhi-blog.oss-cn-guangzhou.aliyuncs.com/img01/img01/image-20240513013139842.png) 

我想实现前面一块固定，下面一块内容不固定，使用滚条来查看内容，这是很常见的业务问题，我使用的 grip 布局来解决这个问题

首先我们要设置一下main的样式

```css
.layout_main {
    position: absolute;
    width: calc(100% - $base-menu-width);
    height: calc(100vh - $base-tabbar-height - 25px);
    // background-color: yellowgreen;
    left: $base-menu-width;
    top: $base-tabbar-height;
    padding: 10px;
    overflow: auto;
    transition: all 0.3s;
    display: grid;
    grid-template-rows: auto 1fr; /* 第一行自适应内容高度，第二行占据剩余空间 */
    grid-template-columns: 100%; /* 仅一列，占满容器宽度 */
    overflow: hidden; /* 防止容器本身出现滚动条 */
    &.fold {
      width: calc(100vw - $base-menu-min-width);
      left: $base-menu-min-width;
    }
  }
```

main高度我们是通过减去 顶部操作栏和底部高度得出的

接下来我们设置一下内容的样式

```css
.one-search-card-class {
  grid-row: 1; /* 第一个卡片在第一行 */
  overflow: hidden; /* 防止第一个卡片内容溢出 */
}
.content-card-class {
  grid-row: 2; /* 第二个卡片在第二行 */
  overflow-y: auto; /* 第二个卡片内容超出时使用垂直滚动条 */
}
```
