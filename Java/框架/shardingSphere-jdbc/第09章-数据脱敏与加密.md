# 第9章：数据脱敏与加密

## 9.1 数据脱敏背景与应用场景

### 9.1.1 为什么需要数据脱敏

在大数据时代，数据安全和隐私保护成为企业必须面对的核心问题。数据脱敏（Data Masking）是一种保护敏感数据的技术手段，通过将原始敏感数据转换为不可识别的格式，在保证业务功能正常运作的前提下，防止敏感信息泄露。

**典型应用场景包括：**

| 场景 | 说明 | 示例 |
|------|------|------|
| 开发测试环境 | 测试环境不能使用真实用户数据 | 手机号、身份证号替换为虚拟值 |
| 数据分析共享 | 对外提供数据分析结果时隐藏敏感字段 | 银行卡号部分遮蔽 |
| 合规要求 | 满足 GDPR、PCI-DSS 等法规要求 | 信用卡号加密存储 |
| 内部数据安全 | 限制不同级别人员访问敏感数据 | 工资、地址等信息脱敏 |
| 微服务数据交换 | 服务间传输敏感数据时加密 | 用户密码、密钥等 |

### 9.1.2 ShardingSphere-JDBC 加密脱敏工作原理

ShardingSphere-JDBC 在 JDBC 层面实现了数据加密，对应用程序透明。其核心工作流程如下：

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  Application│────▶│ ShardingSphere-JDBC │────▶│   Database  │────▶│  Response  │
│   Query     │     │   Encryptor          │     │   Storage  │     │  Decryptor │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
                           │                                       │
                    ┌──────┴──────┐                          ┌─────┴─────┐
                    │  写入流程   │                          │  读取流程 │
                    │ 1. AES加密  │                          │ 1. AES解密│
                    │ 2. 存储密文 │                          │ 2. 返回明文│
                    └─────────────┘                          └───────────┘
```

**写入操作流程：**
1. 应用程序执行 `INSERT/UPDATE` 语句
2. ShardingSphere 拦截 SQL，识别需要加密的字段
3. 调用配置的加密算法对字段值进行加密
4. 将密文替换原文后发送到数据库执行

**读取操作流程：**
1. 应用程序执行 `SELECT` 语句查询加密列
2. ShardingSphere 从数据库获取密文
3. 调用配置的解密算法对密文进行解密
4. 返回明文给应用程序

### 9.1.3 加密脱敏与列加密的区别

ShardingSphere-JDBC 提供了两种数据保护机制：

| 特性 | 数据脱敏（Encrypt） | 列加密（Column Encrypt） |
|------|---------------------|-------------------------|
| **用途** | 数据写入时加密，读取时解密 | 持久化加密存储，读取时按需解密 |
| **查询支持** | 不支持密文列查询 | 支持密文列直接查询 |
| **性能影响** | 读写时额外加解密开销 | 查询加密列时无需解密 |
| **适用场景** | 隐私数据保护、GDPR合规 | 需要对加密列建立索引 |
| **实现层次** | JDBC SQL 处理层 | 数据库存储层 |

## 9.2 内置加密算法详解

ShardingSphere-JDBC 提供了多种内置加密算法，满足不同的安全等级和性能要求。

### 9.2.1 MD5 算法

**算法特性：**
- 类型：散列算法（不可逆）
- 输出长度：128 位（16 字节）
- 特点：相同输入产生相同输出，常用于数据完整性校验

**配置参数：**

```yaml
rules:
- !ENCRYPT
  encryptors:
    md5_encryptor:
      type: MD5
      props:
        # 可选：是否使用 salted（加盐）模式
        # 默认为空字符串，表示不使用盐
        salt: "your-salt-value"
```

**Java 配置方式：**

```java
public final class AlgorithmParameter implements AlgorithmDynamicParameter {
    
    @Getter
    private final Properties props = new Properties();
    
    // 配置 MD5 加盐
    public void setSalt(String salt) {
        props.setProperty("salt", salt);
    }
}

// 使用
EncryptRuleConfiguration config = new EncryptRuleConfiguration();
config.getEncryptors().put("md5_encryptor", new AlgorithmConfiguration("MD5", 
    new Properties() {{
        setProperty("salt", "random-salt-string");
    }
));
```

**应用场景：**
- 数据完整性校验
- 密码存储（通常需要配合其他机制）
- 不需要解密的场景

**示例：**
```java
// 加密
String plaintext = "123456";
String ciphertext = encryptor.encrypt(plaintext); // 输出: e10adc3949ba59abbe56e057f20f883e

// 加密（带盐）
String ciphertext = encryptorWithSalt.encrypt(plaintext); // 输出受盐值影响
```

### 9.2.2 AES 算法（Advanced Encryption Standard）

**算法特性：**
- 类型：对称加密算法（可逆）
- 密钥长度：128位、192位、256位
- 模式：GCM、ECB、CBC 等
- 特点：安全性高，性能好，广泛采用

**配置参数：**

```yaml
rules:
- !ENCRYPT
  encryptors:
    aes_encryptor:
      type: AES
      props:
        # AES 密钥，长度必须为 16/24/32 字节对应 128/192/256 位
        aes-key-value: "your-16-24-or-32-byte-key"
```

**密钥生成与安全建议：**

```java
import javax.crypto.KeyGenerator;
import javax.crypto.SecretKey;
import java.security.SecureRandom;
import java.util.Base64;

// 生成安全的 AES 密钥
public static String generateAESKey() {
    try {
        KeyGenerator keyGen = KeyGenerator.getInstance("AES");
        keyGen.init(256, new SecureRandom());
        SecretKey secretKey = keyGen.generateKey();
        return Base64.getEncoder().encodeToString(secretKey.getEncoded());
    } catch (NoSuchAlgorithmException e) {
        throw new RuntimeException(e);
    }
}

// 生成 32 字节密钥（256 位）
public static String generateAESKeyManual() {
    byte[] keyBytes = new byte[32];
    new SecureRandom().nextBytes(keyBytes);
    return Base64.getEncoder().encodeToString(keyBytes);
}
```

**Java 配置完整示例：**

```java
import org.apache.shardingsphere.spi.algorithm.encrypt.ShardingEncryptor;
import org.apache.shardingsphere.encrypt.api.context.texthash.AESTextEncryptor;
import org.apache.shardingsphere.encrypt.api.context.texthash.MD5TextEncryptor;

import java.util.Properties;

public class AESEncryptExample {
    public static void main(String[] args) {
        // 配置 AES 加密器
        Properties props = new Properties();
        props.setProperty("aes-key-value", "aes-key-12345678901234567890"); // 26 字节
        
        AESTextEncryptor encryptor = new AESTextEncryptor();
        encryptor.init(props);
        
        // 加密
        String plaintext = "sensitive-data";
        String ciphertext = encryptor.encrypt(plaintext);
        System.out.println("密文: " + ciphertext);
        
        // 解密
        String decrypted = encryptor.decrypt(ciphertext);
        System.out.println("明文: " + decrypted); // sensitive-data
    }
}
```

### 9.2.3 RC4 算法（Rivest Cipher 4）

**算法特性：**
- 类型：对称流加密算法（可逆）
- 密钥长度：40-2048 位
- 特点：流式加密，速度快，适合大数据量加密

**配置参数：**

```yaml
rules:
- !ENCRYPT
  encryptors:
    rc4_encryptor:
      type: RC4
      props:
        # RC4 密钥
        rc4-key-value: "your-rc4-key"
```

**应用场景：**
- 大数据量实时加密
- 网络数据传输加密
- 日志数据脱敏

**示例：**

```java
import org.apache.shardingsphere.encrypt.api.context.texthash.RC4TextEncryptor;
import java.util.Properties;

public class RC4EncryptExample {
    public static void main(String[] args) {
        Properties props = new Properties();
        props.setProperty("rc4-key-value", "secret-rc4-key-12345");
        
        RC4TextEncryptor encryptor = new RC4TextEncryptor();
        encryptor.init(props);
        
        // 加密
        String plaintext = "stream-data-to-encrypt";
        String ciphertext = encryptor.encrypt(plaintext);
        
        // 解密
        String decrypted = encryptor.decrypt(ciphertext);
        assert plaintext.equals(decrypted);
    }
}
```

### 9.2.4 SM3/SM4 国密算法

SM3 和 SM4 是中国国家密码管理局发布的国产密码算法，在政府、金融等领域有强制使用要求。

#### SM3（散列算法）

**算法特性：**
- 类型：密码散列算法（不可逆）
- 输出长度：256 位（32 字节）
- 特点：杂凑值长度为 32 字节，填充机制与 MD5 类似

**配置参数：**

```yaml
rules:
- !ENCRYPT
  encryptors:
    sm3_encryptor:
      type: SM3
      props:
        # 可选：SM3 盐值，默认为空
        sm3-salt: "sm3-salt-value"
```

#### SM4（对称加密算法）

**算法特性：**
- 类型：对称分组加密算法（可逆）
- 密钥长度：128 位（16 字节）
- 分组长度：128 位（16 字节）
- 模式：ECB、CBC、PCBC、CFB、OFB、CTR

**配置参数：**

```yaml
rules:
- !ENCRYPT
  encryptors:
    sm4_encryptor:
      type: SM4
      props:
        # SM4 密钥（固定 16 字节）
        sm4-key-value: "1234567890abcdef"  # 16 字节十六进制字符串
        # 加密模式（可选，默认为 ECB）
        sm4-mode: CBC
        # 初始向量（CBC 模式必须，ECB 模式忽略）
        sm4-iv: "0102030405060708"  # 16 字节十六进制字符串
```

**国密算法完整配置示例：**

```java
import org.apache.shardingsphere.encrypt.api.context.texthash.SM3TextEncryptor;
import org.apache.shardingsphere.encrypt.api.context.texthash.SM4TextEncryptor;
import java.util.Properties;

public class GMEncryptExample {
    public static void main(String[] args) {
        // SM3 配置
        Properties sm3Props = new Properties();
        sm3Props.setProperty("sm3-salt", "gm-salt-value");
        SM3TextEncryptor sm3Encryptor = new SM3TextEncryptor();
        sm3Encryptor.init(sm3Props);
        
        String data = "sensitive-data";
        String sm3Hash = sm3Encryptor.encrypt(data);
        System.out.println("SM3 Hash: " + sm3Hash);
        
        // SM4 配置（ECB 模式）
        Properties sm4Props = new Properties();
        sm4Props.setProperty("sm4-key-value", "1234567890abcdef"); // 16 字节
        SM4TextEncryptor sm4Encryptor = new SM4TextEncryptor();
        sm4Encryptor.init(sm4Props);
        
        String ciphertext = sm4Encryptor.encrypt(data);
        String decrypted = sm4Encryptor.decrypt(ciphertext);
        System.out.println("SM4 加密: " + ciphertext);
        System.out.println("SM4 解密: " + decrypted);
        
        // SM4 配置（CBC 模式）
        Properties sm4CBCProps = new Properties();
        sm4CBCProps.setProperty("sm4-key-value", "1234567890abcdef");
        sm4CBCProps.setProperty("sm4-mode", "CBC");
        sm4CBCProps.setProperty("sm4-iv", "0102030405060708");
        SM4TextEncryptor sm4CBCEncryptor = new SM4TextEncryptor();
        sm4CBCEncryptor.init(sm4CBCProps);
    }
}
```

**SM4 密钥安全存储建议：**

```java
import javax.crypto.spec.SecretKeySpec;
import java.nio.charset.StandardCharsets;
import java.security.SecureRandom;

/**
 * SM4 密钥管理工具类

public class SM4KeyManager {

     */

        return bytesToHex(keyBytes);
    }
    
    /**
     * 生成随机 IV
     */
    public static String generateIV() {
        byte[] ivBytes = new byte[16];
        new SecureRandom().nextBytes(ivBytes);
        return bytesToHex(ivBytes);
    }
    
    /**
     * 从配置文件中加载密钥（实际生产环境应使用 KMS）
     */
    public static String loadKeyFromVault(String path) {
        // 实际实现应从密钥管理系统（KMS）加载
        // 这里仅作示例
        return System.getenv("SM4_KEY");
    }
    
    private static String bytesToHex(byte[] bytes) {
        StringBuilder sb = new StringBuilder();
        for (byte b : bytes) {
            sb.append(String.format("%02x", b & 0xFF));
        }
        return sb.toString();
    }
}
```

### 9.2.5 内置加密算法对比

| 算法 | 类型 | 可逆性 | 密钥长度 | 安全性 | 性能 | 适用场景 |
|------|------|--------|----------|---------|------|----------|
| MD5 | 散列 | 不可逆 | 无 | 低（已发现碰撞） | 极高 | 完整性校验 |
| AES | 对称分组 | 可逆 | 128/192/256位 | 高 | 高 | 通用加密 |
| RC4 | 对称流 | 可逆 | 40-2048位 | 中高 | 极高 | 大数据流加密 |
| SM3 | 散列 | 不可逆 | 无 | 高 | 高 | 国密合规 |
| SM4 | 对称分组 | 可逆 | 128位 | 高 | 高 | 国密合规 |

## 9.3 脱敏规则配置详解

### 9.3.1 配置模型概述

ShardingSphere-JDBC 的加密配置采用声明式配置方式，核心配置模型如下：

```
EncryptRuleConfiguration
├── tables: Map<String, EncryptTableRuleConfiguration>
│   └── columns: Map<String, EncryptColumnRuleConfiguration>
│       ├── plainColumn: String (可选，明文列名)
│       ├── cipherColumn: String (密文列名)
│       ├── encryptorName: String (加密器名称)
│       └── assistedQueryColumn: String (可选，辅助查询列)
└── encryptors: Map<String, AlgorithmConfiguration>
    └── type: String (加密算法类型)
    └── props: Properties (算法参数)
```

### 9.3.2 加密规则配置属性

| 属性 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `tables.<table-name>.columns.<column-name>.plainColumn` | String | 否 | 明文列名，用于存储原始数据 |
| `tables.<table-name>.columns.<column-name>.cipherColumn` | String | 是 | 密文列名，用于存储加密数据 |
| `tables.<table-name>.columns.<column-name>.encryptorName` | String | 是 | 使用的加密器名称 |
| `tables.<table-name>.columns.<column-name>.assistedQueryColumn` | String | 否 | 辅助查询列名，用于密文列查询 |
| `tables.<table-name>.columns.<column-name>.likeQueryColumn` | String | 否 | 模糊查询列名 |

### 9.3.3 YAML 配置详解

**基础配置结构：**

```yaml
# 完整配置示例
dataSource:
  # 数据源配置
  ds_0:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/demo_ds_0
    username: root
    password: root123

rules:
  # 加密规则配置
  - !ENCRYPT
    # 加密算法定义

      # AES 加密器

        type: AES
        props:
          aes-key-value: "aes-key-12345678901234567890"
      
      # MD5 加密器
      md5_encryptor:
        type: MD5
        props:
          salt: "random-salt"
      
      # SM4 加密器（国密）
      sm4_encryptor:
        type: SM4
        props:
          sm4-key-value: "1234567890abcdef"
          sm4-mode: CBC
          sm4-iv: "0102030405060708"
    
    # 表级加密规则
    tables:
      # 用户表加密配置

        columns:
          # 密码字段：AES 加密
```

### 9.3.5 Java API 配置

```java
import org.apache.shardingsphere.encrypt.api.config.EncryptRuleConfiguration;
import org.apache.shardingsphere.encrypt.api.config.rule.EncryptTableRuleConfiguration;
import org.apache.shardingsphere.encrypt.api.config.column.EncryptColumnRuleConfiguration;
import org.apache.shardingsphere.spi.algorithm.encrypt.ShardingEncryptor;
import org.apache.shardingsphere.encrypt.api.context.texthash.AESTextEncryptor;

import java.util.Arrays;
import java.util.Collections;
import java.util.Properties;

public class EncryptRuleConfigurationExample {
    
    public static EncryptRuleConfiguration createEncryptRule() {
        // 1. 创建加密器配置
        Properties aesProps = new Properties();
        aesProps.setProperty("aes-key-value", "aes-key-12345678901234567890");
        
        Properties md5Props = new Properties();
        md5Props.setProperty("salt", "random-salt-value");
        
        // 2. 创建加密表规则配置
        EncryptColumnRuleConfiguration passwordColumn = new EncryptColumnRuleConfiguration(
            "password_plain",           // plainColumn
            "password_cipher",          // cipherColumn
            "aes_encryptor",            // encryptorName
            null,                        // assistedQueryColumn
            null                         // likeQueryColumn
        );
        
        EncryptColumnRuleConfiguration phoneColumn = new EncryptColumnRuleConfiguration(
            "phone_plain",
            "phone_cipher",
            "md5_encryptor",
            null,
            null
        );
        
        // 3. 构建表级配置
        Map<String, EncryptColumnRuleConfiguration> columnConfigs = new HashMap<>();
        columnConfigs.put("password", passwordColumn);
        columnConfigs.put("phone", phoneColumn);
        
        EncryptTableRuleConfiguration userTableRule = new EncryptTableRuleConfiguration(
            "t_user",                   // 表名
            columnConfigs               // 列配置
        );
        
        // 4. 构建全局加密规则配置
        EncryptRuleConfiguration encryptRule = new EncryptRuleConfiguration(
            Collections.singletonList(userTableRule),  // 表规则列表
            createEncryptors()                          // 加密器配置
        );
        
        return encryptRule;
    }
    
    private static Map<String, AlgorithmConfiguration> createEncryptors() {
        Map<String, AlgorithmConfiguration> encryptors = new HashMap<>();
        
        // AES 加密器
        Properties aesProps = new Properties();
        aesProps.setProperty("aes-key-value", "aes-key-12345678901234567890");
        encryptors.put("aes_encryptor", new AlgorithmConfiguration("AES", aesProps));
        
        // MD5 加密器
        Properties md5Props = new Properties();
        md5Props.setProperty("salt", "random-salt");
        encryptors.put("md5_encryptor", new AlgorithmConfiguration("MD5", md5Props));
        
        // SM4 加密器
        Properties sm4Props = new Properties();
        sm4Props.setProperty("sm4-key-value", "1234567890abcdef");
        sm4Props.setProperty("sm4-mode", "CBC");
        sm4Props.setProperty("sm4-iv", "0102030405060708");
        encryptors.put("sm4_encryptor", new AlgorithmConfiguration("SM4", sm4Props));
        
        return encryptors;
    }
}
```

## 9.4 自定义加密算法接口 CustomKeyGenerateAlgorithm

### 9.4.1 接口概述

当内置加密算法无法满足业务需求时，ShardingSphere 提供了 `CustomKeyGenerateAlgorithm` 接口，允许开发者实现自定义加密算法。

### 9.4.2 接口定义

```java
package org.apache.shardingsphere.spi.algorithm.encrypt;

import org.apache.shardingsphere.spi.SingletonSPI;

import java.util.Properties;

/**
 * 自定义加密算法接口
 * 开发者可以通过实现此接口来创建自定义的加密/解密逻辑
 */
public interface CustomKeyGenerateAlgorithm extends SingletonSPI {
    
    /**
     * 初始化加密算法
     * @param props 配置属性
     */
    default void init(Properties props) {
    }
    
    /**
     * 加密操作
     * @param plaintext 明文数据
     * @return 密文数据
     */
    String encrypt(String plaintext);
    
    /**
     * 解密操作
     * @param ciphertext 密文数据
     * @return 明文数据
     */
    String decrypt(String ciphertext);
    
    /**
     * 获取算法类型名称
     * @return 算法类型
     */
    String getType();
}
```

### 9.4.3 实现自定义加密算法

**示例：实现 RSA 非对称加密算法**

```java
package com.example.encrypt.algorithm;

import org.apache.shardingsphere.spi.algorithm.encrypt.CustomKeyGenerateAlgorithm;

import javax.crypto.Cipher;
import java.security.*;
import java.util.Base64;
import java.util.Properties;

/**
 * RSA 非对称加密算法实现
 * 使用公钥加密，私钥解密
 */
public class RSACustomEncryptor implements CustomKeyGenerateAlgorithm {
    
    private static final String ALGORITHM = "RSA";
    private static final String TRANSFORMATION = "RSA/ECB/PKCS1Padding";
    private static final int KEY_SIZE = 2048;
    
    private Properties props;
    private PublicKey publicKey;
    private PrivateKey privateKey;
    private String type;
    
    @Override
    public void init(Properties props) {
        this.props = props;
        this.type = props.getProperty("type", "RSA");
        
        // 从配置加载密钥或生成新密钥
        String privateKeyContent = props.getProperty("rsa.private.key");
        String publicKeyContent = props.getProperty("rsa.public.key");
        
        try {
            if (privateKeyContent != null && publicKeyContent != null) {
                // 从配置加载现有密钥
                KeyFactory keyFactory = KeyFactory.getInstance(ALGORITHM);
                this.publicKey = keyFactory.generatePublic(new java.security.spec.X509EncodedKeySpec(
                    Base64.getDecoder().decode(publicKeyContent)));
                this.privateKey = keyFactory.generatePrivate(new java.security.spec.PKCS8EncodedKeySpec(
                    Base64.getDecoder().decode(privateKeyContent)));
            } else {
                // 生成新的密钥对
                KeyPairGenerator keyGen = KeyPairGenerator.getInstance(ALGORITHM);
                keyGen.initialize(KEY_SIZE, new SecureRandom());
                KeyPair keyPair = keyGen.generateKeyPair();
                this.publicKey = keyPair.getPublic();
                this.privateKey = keyPair.getPrivate();
            }
        } catch (Exception e) {
            throw new RuntimeException("初始化 RSA 密钥失败", e);
        }
    }
    
    @Override
    public String encrypt(String plaintext) {
        if (plaintext == null || plaintext.isEmpty()) {
            return plaintext;
        }
        
        try {
            Cipher cipher = Cipher.getInstance(TRANSFORMATION);
            cipher.init(Cipher.ENCRYPT_MODE, publicKey);
            byte[] encrypted = cipher.doFinal(plaintext.getBytes("UTF-8"));
            return Base64.getEncoder().encodeToString(encrypted);
        } catch (Exception e) {
            throw new RuntimeException("RSA 加密失败", e);
        }
    }
    
    @Override
    public String decrypt(String ciphertext) {
        if (ciphertext == null || ciphertext.isEmpty()) {
            return ciphertext;
        }
        
        try {
            Cipher cipher = Cipher.getInstance(TRANSFORMATION);
            cipher.init(Cipher.DECRYPT_MODE, privateKey);
            byte[] decrypted = cipher.doFinal(Base64.getDecoder().decode(ciphertext));
            return new String(decrypted, "UTF-8");
        } catch (Exception e) {
            throw new RuntimeException("RSA 解密失败", e);
        }
    }
    
    @Override
    public String getType() {
        return type;
    }
    
    /**
     * 获取公钥（供外部使用）
     */
    public String getPublicKeyBase64() {
        return Base64.getEncoder().encodeToString(publicKey.getEncoded());
    }
    
    /**
     * 获取私钥（供外部使用，需要安全存储）
     */
    public String getPrivateKeyBase64() {
        return Base64.getEncoder().encodeToString(privateKey.getEncoded());
    }
}
```

**示例：实现带脱敏规则的身份证加密器**

```java
package com.example.encrypt.algorithm;

import org.apache.shardingsphere.spi.algorithm.encrypt.CustomKeyGenerateAlgorithm;
import java.util.Properties;

/**
 * 身份证号专用加密器
 * 保留前三位和最后四位，中间部分脱敏
 * 例如：110101199001011234 -> 110*******1234
 */
public class IDCardMaskEncryptor implements CustomKeyGenerateAlgorithm {
    
    private static final String TYPE = "ID_CARD_MASK";
    private static final String MASK_CHAR = "*";
    private Properties props;
    private String type;
    
    @Override
    public void init(Properties props) {
        this.props = props;
        this.type = props.getProperty("type", TYPE);
    }
    
    @Override
    public String encrypt(String plaintext) {
        if (plaintext == null || plaintext.isEmpty()) {
            return plaintext;
        }
        
        // 移除可能存在的空格和"X"
        String idCard = plaintext.trim().toUpperCase();
        
        if (idCard.length() < 8) {
            return plaintext; // 长度不够，保持原样
        }
        
        // 保留前三位和最后四位
        String prefix = idCard.substring(0, 3);
        String suffix = idCard.substring(idCard.length() - 4);
        String mask = String.valueOf(MASK_CHAR).repeat(idCard.length() - 7);
        
        return prefix + mask + suffix;
    }
    
    @Override
    public String decrypt(String ciphertext) {
        // 脱敏算法不可逆，直接返回脱敏后的值
        return ciphertext;
    }
    
    @Override
    public String getType() {
        return type;
    }
}
```

**示例：实现雪花ID加密器**

```java
package com.example.encrypt.algorithm;

import org.apache.shardingsphere.spi.algorithm.encrypt.CustomKeyGenerateAlgorithm;
import java.util.Properties;

/**
 * 雪花ID加密器
 * 将数字ID进行分段加密，保护业务数据
 */
public class SnowflakeIdEncryptor implements CustomKeyGenerateAlgorithm {
    
    private static final String TYPE = "SNOWFLAKE_ID";
    private Properties props;
    private String type;
    private int shiftBits;
    
    @Override
    public void init(Properties props) {
        this.props = props;
        this.type = props.getProperty("type", TYPE);
        this.shiftBits = Integer.parseInt(props.getProperty("shift.bits", "8"));
    }
    
    @Override
    public String encrypt(String plaintext) {
        if (plaintext == null || plaintext.isEmpty()) {
            return plaintext;
        }
        
        try {
            long id = Long.parseLong(plaintext);
            // 对ID进行位运算加密
            long encrypted = ((id >> shiftBits) ^ (id << (16 - shiftBits))) & 0x7FFFFFFFFFFFFFFFL;
            return String.valueOf(encrypted);
        } catch (NumberFormatException e) {
            return plaintext;
        }
    }
    
    @Override
    public String decrypt(String ciphertext) {
        if (ciphertext == null || ciphertext.isEmpty()) {
            return ciphertext;
        }
        
        try {
            long encrypted = Long.parseLong(ciphertext);
            // 逆向运算解密
            long id = ((encrypted >> shiftBits) ^ (encrypted << (16 - shiftBits))) & 0x7FFFFFFFFFFFFFFFL;
            return String.valueOf(id);
        } catch (NumberFormatException e) {
            return ciphertext;
        }
    }
    
    @Override
    public String getType() {
        return type;
    }
}
```

## 9.5 密文列查询处理

### 9.5.1 问题背景

当数据被加密后，直接在密文列上执行 SQL 查询会失败，因为数据库存储的是密文而不是明文。例如：

```sql
-- 用户期望查询手机号以"138"开头的用户
SELECT * FROM t_user WHERE phone = '13812345678';

-- 但数据库中存储的是加密后的密文
-- 实际查询变成 WHERE 'aj7kQ2l...' = '13812345678'
-- 导致查询失败
```

### 9.5.2 辅助查询列方案

ShardingSphere 提供了辅助查询列（Assisted Query Column）机制来解决密文列查询问题。

**工作原理：**

```
┌────────────────────────────────────────────────────────────────┐
│                         写入操作                                │
│  INSERT INTO t_user (phone, phone_cipher, phone_assisted)       │
│  VALUES ('13812345678', 'encrypted_cipher', 'assisted_value')  │
└────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌────────────────────────────────────────────────────────────────┐
│                         查询操作                                │
│  SELECT * FROM t_user WHERE phone_assisted = 'assisted_value'  │
│                         ↓                                       │
│              通过辅助列查询获取 cipherColumn                     │
│                         ↓                                       │
│              ShardingSphere 自动解密后返回                      │
└────────────────────────────────────────────────────────────────┘
```

### 9.5.3 配置辅助查询列

**完整配置示例：**

```yaml
rules:
  - !ENCRYPT
    encryptors:
      aes_encryptor:
        type: AES
        props:
          aes-key-value: "aes-key-12345678901234567890"
      
      # 用于辅助查询的哈希加密器（不可逆）
      assisted_encryptor:
        type: MD5
        props:
          salt: "assisted-query-salt"
    
    tables:
      t_user:
        columns:
          phone:
            plainColumn: phone_plain
            cipherColumn: phone_cipher
            # 辅助查询列，使用专用加密器
            assistedQueryColumn: phone_assisted
            encryptorName: aes_encryptor
```

**Java API 配置：**

```java
EncryptColumnRuleConfiguration phoneColumn = new EncryptColumnRuleConfiguration(
    "phone_plain",           // plainColumn
    "phone_cipher",          // cipherColumn
    "aes_encryptor",         // encryptorName
    "phone_assisted",        // assistedQueryColumn - 关键配置
    null                     // likeQueryColumn
);
```

### 9.5.4 辅助查询列加密器

辅助查询列需要使用支持范围查询的加密算法，通常选择：

| 算法 | 特点 | 适用场景 |
|------|------|----------|
| MD5 | 固定长度输出，适合等值查询 | 等值查询 |
| SHA-256 | 安全性更高，适合等值查询 | 等值查询 |
| 自定义哈希 | 可自定义脱敏规则 | 需要部分匹配 |

**配置辅助查询专用加密器：**

```yaml
rules:
  - !ENCRYPT
    # 定义两种加密器
    encryptors:
      # 主加密器（AES）
      main_encryptor:
        type: AES
        props:
          aes-key-value: "aes-key-12345678901234567890"
      
      # 辅助查询加密器（MD5）
      assisted_encryptor:
        type: MD5
        props:
          salt: "consistent-salt-for-assisted"
    
    tables:
      t_user:
        columns:
          phone:
            plainColumn: phone_plain
            cipherColumn: phone_cipher
            assistedQueryColumn: phone_assisted
            encryptorName: main_encryptor
```

### 9.5.5 等值查询处理

**等值查询：**

```java
// Java 代码
String phoneToFind = "13812345678";

// ShardingSphere 会自动处理：
// 1. 使用 assisted_encryptor 加密查询条件
// 2. 执行 SELECT * FROM t_user WHERE phone_assisted = 'md5(13812345678+salt)'
// 3. 解密返回结果
List<User> users = userMapper.selectByPhone(phoneToFind);
```

**等价 SQL 转换：**

```sql

SELECT * FROM t_user WHERE phone = '13812345678';

-- ShardingSphere 转换后的 SQL
SELECT user_id, phone_plain, phone_cipher, phone_assisted 
FROM t_user 
WHERE phone_assisted = 'a1b2c3d4e5f6...';  -- MD5 哈希值
```

对于需要模糊匹配的字段，可以使用 `likeQueryColumn`：

**前缀匹配示例：**

```java
// 创建支持前缀匹配的辅助加密器
public class PrefixPreservingEncryptor implements CustomKeyGenerateAlgorithm {
    
    @Override
    public String encrypt(String plaintext) {
        // 只保留前 N 位进行加密，其余保留原文
        int prefixLength = 3;
        String prefix = plaintext.substring(0, prefixLength);
        String suffix = plaintext.substring(prefixLength);
        return prefix + "|" + encryptSuffix(suffix);
    }
    
    // 前缀可匹配，完整内容需解密

    }
```

### 9.5.7 范围查询处理

对于范围查询（`>`, `<`, `BETWEEN`），需要特殊处理：

```yaml
rules:
  - !ENCRYPT
    encryptors:
      aes_encryptor:
        type: AES
        props:
          aes-key-value: "aes-key-12345678901234567890"
    
    tables:
      t_order:
        columns:
          amount:
            plainColumn: amount_plain
            cipherColumn: amount_cipher
            # 范围查询辅助列
            assistedQueryColumn: amount_assisted
            encryptorName: aes_encryptor
```

**范围查询 Java 代码：**

```java
// 查询金额在 1000-5000 的订单
List<Order> orders = orderMapper.selectByAmountRange(
    new BigDecimal("1000"), 
    new BigDecimal("5000")
);

// ShardingSphere 内部处理：
// 1. 找到金额在指定范围的数据行（通过辅助列或其他方式）
// 2. 对每条记录的 cipherColumn 解密
// 3. 在内存中过滤出符合范围的数据
// 4. 返回结果
```

**注意：** 范围查询在加密场景下性能较差，因为需要在内存中解密后过滤。建议对于需要范围查询的字段，考虑使用确定性加密或单独存储未加密的索引列。

## 9.6 加密后数据迁移方案

### 9.6.1 迁移挑战

在生产环境中，从未加密到加密的迁移面临以下挑战：

| 挑战 | 说明 | 解决方案 |
|------|------|----------|
| 历史数据 | 已有的明文数据需要加密 | 数据迁移工具 |
| 零停机 | 业务不能中断 | 双写策略 |
| 一致性 | 迁移过程中数据不能丢失或不一致 | 原子迁移 |
| 回滚 | 迁移失败需要能回退 | 增量迁移 + 回滚方案 |

### 9.6.2 迁移方案一：离线迁移

**适用场景：** 业务可以停机维护窗口

```
阶段1：备份
├── 备份原始数据
└── 验证备份完整性

阶段2：历史数据加密
├── 读取明文数据
├── 调用加密算法加密
├── 写入加密列
└── 验证加密结果

阶段3：切换
├── 启用加密规则
└── 业务验证
```

**离线迁移脚本示例：**

```java
package com.example.migration;

import org.apache.shardingsphere.encrypt.api.context.texthash.AESTextEncryptor;
import java.sql.*;
import java.util.Properties;

/**
 * 离线数据加密迁移工具
 */
public class OfflineMigration {
    
    private static final String SOURCE_JDBC = "jdbc:mysql://localhost:3306/source_db";
    private static final String AES_KEY = "aes-key-12345678901234567890";
    
    public static void main(String[] args) {
        AESTextEncryptor encryptor = new AESTextEncryptor();
        encryptor.init(createProps());
        
        migrate("t_user", "password", "password_cipher", encryptor);
    }
    
    public static void migrate(String table, String plainColumn, 
                               String cipherColumn, AESTextEncryptor encryptor) {
        String selectSQL = String.format(
            "SELECT id, %s FROM %s WHERE %s IS NOT NULL", 
            plainColumn, table, plainColumn);
        String updateSQL = String.format(
            "UPDATE %s SET %s = ? WHERE id = ?", 
            table, cipherColumn);
        
        try (Connection conn = DriverManager.getConnection(SOURCE_JDBC, "root", "root");
             PreparedStatement selectStmt = conn.prepareStatement(selectSQL);
             PreparedStatement updateStmt = conn.prepareStatement(updateSQL)) {
            
            conn.setAutoCommit(false);
            ResultSet rs = selectStmt.executeQuery();
            
            int batchCount = 0;
            while (rs.next()) {
                long id = rs.getLong("id");
                String plainText = rs.getString(plainColumn);
                
                if (plainText != null) {
                    String cipherText = encryptor.encrypt(plainText);
                    updateStmt.setString(1, cipherText);
                    updateStmt.setLong(2, id);
                    updateStmt.addBatch();
                    batchCount++;
                    
                    if (batchCount % 1000 == 0) {
                        updateStmt.executeBatch();
                        conn.commit();
                        System.out.println("已迁移 " + batchCount + " 条记录");
                    }
                }
            }
            
            updateStmt.executeBatch();
            conn.commit();
            System.out.println("迁移完成，总计 " + batchCount + " 条记录");
            
        } catch (SQLException e) {
            throw new RuntimeException("迁移失败", e);
        }
    }
    
    private static Properties createProps() {
        Properties props = new Properties();
        props.setProperty("aes-key-value", AES_KEY);
        return props;
    }
}
```

### 9.6.3 迁移方案二：双写策略（不停机迁移）

**适用场景：** 业务需要持续运行，不能停机

```
┌─────────────────────────────────────────────────────────────┐
│                    双写策略架构                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   Application (双写)                                         │
│       │                                                     │
│       ├──▶ 原始表 (t_user) ──▶ 明文列                       │
│       │                                                     │
│       └──▶ 加密表 (t_user_enc) ──▶ 密文列                   │
│                                                             │
│   Data Migration Job                                         │
│       │                                                     │
│       ├── 读取原始表                                         │
│       ├── 加密后写入加密表                                   │
│       └── 增量同步                                           │
│                                                             │
│   Switchover                                                │
│       ├── 验证数据一致性                                     │
│       └── 切换读请求到加密表                                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**步骤1：创建加密表**

```sql
-- 创建与原始表结构相同的加密表
CREATE TABLE t_user_enc LIKE t_user;

-- 添加加密列
ALTER TABLE t_user_enc ADD COLUMN password_cipher VARCHAR(255);
ALTER TABLE t_user_enc ADD COLUMN phone_cipher VARCHAR(255);
ALTER TABLE t_user_enc ADD COLUMN password_assisted VARCHAR(64);
ALTER TABLE t_user_enc ADD COLUMN phone_assisted VARCHAR(64);
```

**步骤2：历史数据迁移（增量）**

```java
package com.example.migration;

import java.sql.*;
import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;

/**
 * 增量数据迁移工具
 * 适用于不停机迁移场景
 */
public class IncrementalMigration {
    
    private static final String SOURCE_JDBC = "jdbc:mysql://localhost:3306/source_db";
    private static final String TARGET_JDBC = "jdbc:mysql://localhost:3306/target_db";
    private static final DateTimeFormatter FORMATTER = 
        DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
    
    public static void main(String[] args) {
        // 记录迁移开始时间点
        LocalDateTime startTime = LocalDateTime.now();
        System.out.println("迁移开始时间: " + startTime.format(FORMATTER));
        
        // 执行初始全量迁移
        fullMigration();
        
        // 持续增量同步
        while (true) {
            try {
                incrementalMigration(startTime);
                Thread.sleep(1000); // 每秒检查一次
            } catch (InterruptedException e) {
                break;
            }
        }
    }
    
    /**
     * 全量迁移历史数据
     */
    private static void fullMigration() {
        String selectSQL = "SELECT * FROM t_user";
        
        try (Connection sourceConn = DriverManager.getConnection(SOURCE_JDBC, "root", "root");
             Connection targetConn = DriverManager.getConnection(TARGET_JDBC, "root", "root")) {
            
            sourceConn.setAutoCommit(false);
            targetConn.setAutoCommit(false);
            
            Statement selectStmt = sourceConn.createStatement();
            selectStmt.setFetchSize(1000);
            ResultSet rs = selectStmt.executeQuery(selectSQL);
            
            String insertSQL = "INSERT INTO t_user_enc (id, name, phone, phone_cipher, " +
                              "phone_assisted, password, password_cipher, password_assisted) " +
                              "VALUES (?, ?, ?, ?, ?, ?, ?, ?)";
            PreparedStatement insertStmt = targetConn.prepareStatement(insertSQL);
            
            while (rs.next()) {
                // 迁移数据（实际应调用加密器）
                insertStmt.setLong(1, rs.getLong("id"));
                insertStmt.setString(2, rs.getString("name"));
                insertStmt.setString(3, rs.getString("phone"));
                insertStmt.setString(4, encrypt(rs.getString("phone"))); // 加密
                insertStmt.setString(5, hashForQuery(rs.getString("phone"))); // 辅助查询哈希
```

```java
     * 执行回滚
     */
    public static void rollback(Connection conn, String tableName, long timestamp) {
        String backupTable = BACKUP_TABLE_PREFIX + tableName + "_" + timestamp;
        
        try {
            conn.setAutoCommit(false);
            
            // 清空当前表
            String truncateSQL = String.format("TRUNCATE TABLE %s", tableName);
            try (Statement stmt = conn.createStatement()) {
                stmt.execute(truncateSQL);
            }

                stmt.execute(restoreSQL);
            }
            
            conn.commit();
            System.out.println("回滚完成");
            
        } catch (SQLException e) {
            try {

            } catch (SQLException ex) {

            }

        }

/**
```

```java
@Service
@RequiredArgsConstructor
public class UserService {

     */

                     "VALUES (?, ?, ?, ?, ?)";

     * 注意：此查询会被 ShardingSphere 转换为使用辅助查询列
     */
    public UserDTO findByPhone(String phone) {
        String sql = "SELECT id, username, phone, id_card, email FROM t_user WHERE phone = ?";
        
        // 内部执行：
        // SELECT ... FROM t_user WHERE phone_assisted = MD5(phone + salt)
        // 然后自动解密返回给业务
        
        List<Map<String, Object>> results = jdbcTemplate.queryForList(sql, phone);

        jdbcTemplate.update(sql, 
            request.getPhone(),
            request.getEmail(),
            userId
        );
    }
    
    /**
     * 批量查询用户（自动解密）
     */
    public List<UserDTO> findByIds(List<Long> ids) {

            return List.of();
        }
        
        String placeholders = String.join(",", ids.stream()
            .map(id -> "?").toList());
        String sql = "SELECT id, username, phone, id_card, email FROM t_user WHERE id IN (" 
            + placeholders + ")";
        
        // 自动解密所有加密字段
        List<Map<String, Object>> results = jdbcTemplate.queryForList(sql, ids.toArray());
        return results.stream().map(this::mapToDTO).toList();
    }
    
    private UserDTO mapToDTO(Map<String, Object> row) {
        UserDTO dto = new UserDTO();
        dto.setId((Long) row.get("id"));
        dto.setUsername((String) row.get("username"));

        dto.setIdCard((String) row.get("id_card"));
```

```java
public class PerformanceSensitiveStrategy {

                ps.setString(1, user.getUsername());
                ps.setString(2, user.getPassword());  // 自动加密

            }

            public int getBatchSize() {
                return users.size();
            }
        });
    }
    
    /**
     * 策略4：为辅助查询列建立索引
     * 
     * 辅助查询列用于 WHERE 条件，必须有索引
     */
    public void ensureIndexExists(Connection conn, String tableName, String columnName) 
            throws SQLException {
        String indexName = "idx_" + columnName + "_assisted";
        
        // 检查索引是否存在
        DatabaseMetaData metaData = conn.getMetaData();
        ResultSet indexes = metaData.getIndexInfo(null, null, tableName, false, false);
        
        boolean indexExists = false;
        while (indexes.next()) {
            if (indexName.equals(indexes.getString("INDEX_NAME"))) {
                indexExists = true;
                break;
            }
        }
        
        // 如果不存在则创建
        if (!indexExists) {
            try (Statement stmt = conn.createStatement()) {
                stmt.execute(String.format(
                    "CREATE INDEX %s ON %s (%s)", indexName, tableName, columnName));
            }
        }
    }

        }
```

```java
    }
    
    private static void checkConnectivity(
            Connection sourceConn, 
            Connection targetConn,
            HealthCheckReport report) {

                report.addError("源数据库连接无效");
            } else {
                report.addInfo("源数据库连接正常");
            }
            
            if (!targetConn.isValid(5)) {
                report.addError("目标数据库连接无效");
            } else {
                report.addInfo("目标数据库连接正常");
            }
        } catch (SQLException e) {
            report.addError("连接检查失败: " + e.getMessage());
        }
    }

            "SELECT COUNT(*) as cnt FROM %s", tableName);
        
        try (Statement stmt = conn.createStatement();
             ResultSet rs = stmt.executeQuery(sql)) {

                long count = rs.getLong("cnt");
                report.setSourceRecordCount(count);
                
                if (count == 0) {
                    report.addWarning("源表为空，无需迁移");
                } else if (count > 10_000_000) {

        }
        
        if (indexCount == 0) {
            report.addWarning("目标表没有索引，可能影响查询性能");
        }
    }
```

```java
package com.example.keyrotation;

import org.apache.shardingsphere.encrypt.api.context.texthash.AESTextEncryptor;

import java.sql.*;
import java.time.LocalDateTime;

/**
 * 密钥轮换工具
 * 在不停止服务的情况下更换加密密钥
 */
public class KeyRotationTool {
    
    private static final DateTimeFormatter FORMATTER = 
        DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
    
    private final AESTextEncryptor oldEncryptor;
    private final AESTextEncryptor newEncryptor;
    
    public KeyRotationTool(String oldKey, String newKey) {
        this.oldEncryptor = new AESTextEncryptor();
        Properties oldProps = new Properties();
        oldProps.setProperty("aes-key-value", oldKey);
        this.oldEncryptor.init(oldProps);
        
        this.newEncryptor = new AESTextEncryptor();
        Properties newProps = new Properties();
        newProps.setProperty("aes-key-value", newKey);
        this.newEncryptor.init(newProps);
    }
    
    /**
     * 执行密钥轮换
     * 
     * 策略：
     * 1. 记录轮换开始时间
     * 2. 逐步重新加密历史数据（使用新密钥）
     * 3. 更新配置
     * 4. 新数据使用新密钥
     */
    public RotationResult rotate(
            Connection conn,
            String tableName,
            String cipherColumn,
            int batchSize) throws SQLException {
        
        RotationResult result = new RotationResult();
        LocalDateTime startTime = LocalDateTime.now();
        result.setStartTime(startTime.format(FORMATTER));
        
        // 检查是否已有轮换记录
        Long lastRotatedId = getLastRotatedId(conn, tableName);
        result.setLastRotatedId(lastRotatedId);
        
        // 逐步重新加密
        String selectSQL = String.format(
            "SELECT id, %s FROM %s WHERE id > ? ORDER BY id LIMIT ?",
            cipherColumn, tableName);
        
        String updateSQL = String.format(
            "UPDATE %s SET %s = ? WHERE id = ?",
            tableName, cipherColumn);
        
        AtomicLong processedCount = new AtomicLong(0);
        
        try (PreparedStatement selectStmt = conn.prepareStatement(selectSQL);
             PreparedStatement updateStmt = conn.prepareStatement(updateSQL)) {
            
            conn.setAutoCommit(false);
            
            long currentId = lastRotatedId;
            boolean hasMore = true;
            
            while (hasMore) {
                selectStmt.setLong(1, currentId);
                selectStmt.setInt(2, batchSize);
                
                try (ResultSet rs = selectStmt.executeQuery()) {
                    boolean found = false;
                    
                    while (rs.next()) {
                        found = true;
                        long id = rs.getLong("id");
                        String oldCipherText = rs.getString(cipherColumn);
                        
                        if (oldCipherText != null) {
                            try {
                                // 1. 用旧密钥解密
                                String plaintext = oldEncryptor.decrypt(oldCipherText);
                                
                                // 2. 用新密钥重新加密
                                String newCipherText = newEncryptor.encrypt(plaintext);
                                
                                // 3. 更新
                                updateStmt.setString(1, newCipherText);
                                updateStmt.setLong(2, id);
                                updateStmt.addBatch();
                                
                                processedCount.incrementAndGet();
                                currentId = id;
                                
                            } catch (Exception e) {
                                result.addFailedId(id, e.getMessage());
                            }
                        }
                    }
                    
                    // 如果本批次没有数据，说明已经处理完毕
                    if (!found) {
                        hasMore = false;
                    }
                }
                
                // 执行批量更新
                updateStmt.executeBatch();
                conn.commit();
                
                // 每批次记录进度
                if (processedCount.get() % 10000 == 0) {
                    result.setProcessedCount(processedCount.get());
                    logProgress(result);
                }
            }
        }
        
        // 记录轮换完成
        LocalDateTime endTime = LocalDateTime.now();
        result.setEndTime(endTime.format(FORMATTER));
        result.setProcessedCount(processedCount.get());
        result.setSuccess(processedCount.get() > 0);
        
        saveRotationCheckpoint(conn, tableName, currentId);
        
        return result;
    }
    
    private Long getLastRotatedId(Connection conn, String tableName) throws SQLException {
        String sql = String.format(
            "SELECT checkpoint_value FROM encryption_rotation_checkpoint " +
            "WHERE table_name = ? AND checkpoint_key = 'last_rotated_id'",
            tableName);
        
        try (Statement stmt = conn.createStatement();
             ResultSet rs = stmt.executeQuery(sql)) {
            
            if (rs.next()) {
                return rs.getLong("checkpoint_value");
            }
        }
        
        return 0L;
    }
    
    private void saveRotationCheckpoint(Connection conn, String tableName, long id) 
            throws SQLException {
        String sql = String.format(
            "INSERT INTO encryption_rotation_checkpoint (table_name, checkpoint_key, checkpoint_value, updated_at) " +
            "VALUES (?, 'last_rotated_id', ?, NOW()) " +
            "ON DUPLICATE KEY UPDATE checkpoint_value = ?, updated_at = NOW()",
            tableName, id, id);
        
        try (Statement stmt = conn.createStatement()) {
            stmt.execute(sql);
        }
    }
    
    private void logProgress(RotationResult result) {
        System.out.println(String.format(
            "[%s] 密钥轮换进度: 已处理 %d 条记录, 失败 %d 条",
            LocalDateTime.now().format(FORMATTER),
            result.getProcessedCount(),
            result.getFailedIds().size()));
    }
}
```

```java
package com.example.monitoring;

public class EncryptionMonitoring {

            .record(durationMs, TimeUnit.MILLISECONDS);

            .record(durationMs, TimeUnit.MILLISECONDS);
    }
    
    /**
     * 记录加密错误
     */
    public void recordEncryptError(String tableName, String columnName, String error) {
        encryptErrorCounter.incrementAndGet();
        
        meterRegistry.counter("encrypt.errors", "table", tableName, "column", columnName)
            .increment();
        
        // 发送告警
        sendAlert("加密错误", 
            String.format("表 %s 的列 %s 加密失败: %s", tableName, columnName, error));
    }
    
    /**
     * 周期性检查辅助查询列的使用情况
     */
    public void checkQueryPerformance(Connection conn) throws SQLException {
        String sql = """
            SELECT 
                table_name,
                index_name,
                cardinality,
                CASE 
                    WHEN cardinality < 100 THEN '警告: 索引唯一值过少'
                    WHEN cardinality < 1000 THEN '注意: 索引区分度低'
                    ELSE '正常'
                END as status
            FROM information_schema.statistics
            WHERE table_schema = DATABASE()
            AND column_name LIKE '%_assisted'
            ORDER BY cardinality
            """;
        
        try (Statement stmt = conn.createStatement();
             ResultSet rs = stmt.executeQuery(sql)) {
            
            while (rs.next()) {
                String status = rs.getString("status");
                if (!"正常".equals(status)) {
                    sendAlert("辅助查询列性能警告",
                        String.format("表 %s 的辅助查询列 %s: %s",
                            rs.getString("table_name"),
                            rs.getString("index_name"),
                            status));
                }
            }
        }
    }

     * 生成监控报告
     */
    public MonitoringReport generateReport() {
        MonitoringReport report = new MonitoringReport();
        report.setGeneratedAt(LocalDateTime.now().format(FORMATTER));
        report.setTotalEncryptOperations(encryptCounter.get());
        report.setTotalDecryptOperations(decryptCounter.get());
        report.setTotalErrors(encryptErrorCounter.get());
        
        // 计算错误率
```

```java
package com.example.audit;

import org.aspectj.lang.ProceedingJoinPoint;
import org.aspectj.lang.annotation.Around;
import org.aspectj.lang.annotation.Aspect;
import org.springframework.stereotype.Component;

import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;
import java.util.Arrays;

/**
 * 加密操作审计日志
 * 记录所有涉及敏感数据的操作
 */
@Aspect
@Component
public class EncryptionAuditAspect {
    
    private static final DateTimeFormatter FORMATTER = 
        DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
    
    private final AuditLogService auditLogService;
    
    public EncryptionAuditAspect(AuditLogService auditLogService) {
        this.auditLogService = auditLogService;
    }
    
    /**
     * 审计 INSERT 操作
     */
    @Around("execution(* com.example.mapper.UserMapper.insert*(..))")
    public Object auditInsert(ProceedingJoinPoint joinPoint) throws Throwable {
        String operation = "ENCRYPT_INSERT";
        String tableName = extractTableName(joinPoint);
        Object[] args = joinPoint.getArgs();
        
        long startTime = System.currentTimeMillis();
        
        try {
            Object result = joinPoint.proceed();
            
            // 记录成功操作（不记录具体数据，只记录操作信息）
            auditLogService.log(AuditLog.builder()
                .operation(operation)
                .tableName(tableName)
                .recordId(extractRecordId(args))
                .status("SUCCESS")
                .timestamp(LocalDateTime.now().format(FORMATTER))
                .durationMs(System.currentTimeMillis() - startTime)
                .build());
            
            return result;
            
        } catch (Exception e) {
            // 记录失败操作
            auditLogService.log(AuditLog.builder()
                .operation(operation)
                .tableName(tableName)
                .recordId(extractRecordId(args))
                .status("FAILED")
                .errorMessage(e.getMessage())
                .timestamp(LocalDateTime.now().format(FORMATTER))
                .durationMs(System.currentTimeMillis() - startTime)
                .build());
            
            throw e;
        }
    }
    
    /**
     * 审计 SELECT 操作
     */
    @Around("execution(* com.example.mapper.UserMapper.selectBy*(..))")
    public Object auditSelect(ProceedingJoinPoint joinPoint) throws Throwable {
        String operation = "ENCRYPT_SELECT";
        String methodName = joinPoint.getSignature().getName();
        
        long startTime = System.currentTimeMillis();
        
        try {
            Object result = joinPoint.proceed();
            
            auditLogService.log(AuditLog.builder()
                .operation(operation)
                .queryMethod(methodName)
                .status("SUCCESS")
                .timestamp(LocalDateTime.now().format(FORMATTER))
                .durationMs(System.currentTimeMillis() - startTime)
                .resultCount(extractResultCount(result))
                .build());
            
            return result;
            
        } catch (Exception e) {
            auditLogService.log(AuditLog.builder()
                .operation(operation)
                .queryMethod(methodName)
                .status("FAILED")
                .errorMessage(e.getMessage())
                .timestamp(LocalDateTime.now().format(FORMATTER))
                .durationMs(System.currentTimeMillis() - startTime)
                .build());
            
            throw e;
        }
    }
    
    /**
     * 审计 UPDATE 操作
     */
    @Around("execution(* com.example.mapper.UserMapper.update*(..))")
    public Object auditUpdate(ProceedingJoinPoint joinPoint) throws Throwable {
        String operation = "ENCRYPT_UPDATE";
        String tableName = extractTableName(joinPoint);
        
        long startTime = System.currentTimeMillis();
        
        try {
            Object result = joinPoint.proceed();
            
            auditLogService.log(AuditLog.builder()
                .operation(operation)
                .tableName(tableName)
                .recordId(extractRecordId(args))
                .status("SUCCESS")
                .timestamp(LocalDateTime.now().format(FORMATTER))
                .durationMs(System.currentTimeMillis() - startTime)
                .build());
            
            return result;
            
        } catch (Exception e) {
            auditLogService.log(AuditLog.builder()
                .operation(operation)
                .tableName(tableName)
                .recordId(extractRecordId(args))
                .status("FAILED")
                .errorMessage(e.getMessage())
                .timestamp(LocalDateTime.now().format(FORMATTER))
                .durationMs(System.currentTimeMillis() - startTime)
                .build());
            
            throw e;
        }
    }
    
    private String extractTableName(ProceedingJoinPoint joinPoint) {
        String className = joinPoint.getTarget().getClass().getSimpleName();
        return className.replace("Mapper", "").toLowerCase();
    }
    
    private Long extractRecordId(Object[] args) {
        if (args == null || args.length == 0) {
            return null;
        }
        return Arrays.stream(args)
            .filter(arg -> arg instanceof Long)
            .map(arg -> (Long) arg)
            .findFirst()
            .orElse(null);
    }
    
    private int extractResultCount(Object result) {
        if (result instanceof List) {
            return ((List<?>) result).size();
        }
        return result != null ? 1 : 0;
    }
}
```
