## 1. Sorted Set 数据结构原理

### 1.1 什么是 Sorted Set

Sorted Set（有序集合）是 Redis 中一种重要的数据结构，它将元素按照分数（score）进行排序存储。每个元素由**成员（member）**和**分数（score）**组成：

```
┌─────────────────────────────────────────────────────────────┐
│                    Sorted Set 结构示意                       │
├─────────────────────────────────────────────────────────────┤
│  分数 (Score)              成员 (Member)                     │
│     9500          ──────>    "玩家A"                        │
│     8700          ──────>    "玩家B"                        │
│     7200          ──────>    "玩家C"                        │
│     6500          ──────>    "玩家D"                        │
│     5200          ──────>    "玩家E"                        │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 底层实现原理

Sorted Set 的底层实现有两种编码方式：

#### 压缩列表（ziplist）

当有序集合的元素数量较少且元素值较小时，Redis 使用压缩列表作为底层实现：

- **适用条件**：元素数量 < 128 且所有元素长度 < 64 字节
- **优点**：内存紧凑，节省空间
- **存储方式**：按照分数从小到大顺序存储，元素紧凑排列

```
┌─────┬─────┬─────┬─────┬─────┬─────┬─────┐
│zlbytes│zltail│zllen│score│member│score│member│...│zlend│
└─────┴─────┴─────┴─────┴─────┴─────┴─────┘
```

#### 跳表（skiplist）+ 哈希表（dict）

当元素数量较多或元素较长时，Redis 使用跳表作为底层实现：

```
                    跳表结构
    ┌─────────────────────────────────────────┐
    │  Level 3:  [NULL] ──────────> [NULL]    │
    │              │                  │        │
    │  Level 2:  [节点1] ─────> [节点3] ──> [NULL]
    │              │          │         │        │
    │  Level 1:  [节点1] ─> [节点2] ─> [节点3] ─> [节点4] ─> [NULL]
    │              │          │         │         │
    │  Level 0:  [节点1] ─> [节点2] ─> [节点3] ─> [节点4] ─> [节点5] ─> [NULL]
    └─────────────────────────────────────────┘
                         │
                         ▼
              ┌─────────────────────┐
              │  哈希表 (dict)      │
              │  member -> score    │
              │  "玩家A" -> 9500    │
              │  "玩家B" -> 8700    │
              │  "玩家C" -> 7200    │
              └─────────────────────┘
```

**为什么使用跳表？**

1. **高效的范围查询**：O(log n) 时间复杂度获取区间元素
2. **有序性**：跳表天然支持按照分数排序
3. **高效的排名计算**：O(log n) 时间复杂度计算某个元素的排名

### 1.3 时间复杂度

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| ZADD | O(log n) | 添加元素，n 为元素数量 |
| ZINCRBY | O(log n) | 增加分数 |
| ZRANK | O(log n) | 获取正序排名 |
| ZREVRANK | O(log n) | 获取倒序排名 |
| ZSCORE | O(1) | 获取单个元素分数 |
| ZRANGE | O(log n + m) | 获取区间元素，m 为返回元素数 |
| ZREVRANGE | O(log n + m) | 倒序获取区间元素 |

## 2. 核心命令详解

### 2.1 ZADD - 添加元素

```redis
ZADD key score member [score member ...]
```

**示例**：

```redis
# 添加单个成员
ZADD leaderboard 9500 "玩家A"

# 添加多个成员
ZADD leaderboard 8700 "玩家B" 7200 "玩家C" 6500 "玩家D"

# 带选项添加
ZADD leaderboard NX 9000 "玩家E"     # 仅当成员不存在时添加
ZADD leaderboard XX 9500 "玩家A"     # 仅当成员已存在时更新
ZADD leaderboard LT 8500 "玩家B"     # 仅当新分数小于当前分数时更新
ZADD leaderboard GT 8800 "玩家B"     # 仅当新分数大于当前分数时更新
ZADD leaderboard CH 9500 "玩家A"     # 返回变更的元素数量
```

### 2.2 ZINCRBY - 增加分数

```redis
ZINCRBY key increment member
```

**示例**：

```redis
# 玩家B获得500积分
ZINCRBY leaderboard 500 "玩家B"

# 玩家C被扣除200积分（使用负数）
ZINCRBY leaderboard -200 "玩家C"
```

### 2.3 ZRANK / ZREVRANK - 获取排名

```redis
ZRANK key member      # 获取正序排名（分数从低到高），0-based
ZREVRANK key member   # 获取倒序排名（分数从高到低），0-based
```

**示例**：

```redis
# 添加测试数据
ZADD leaderboard 9500 "玩家A" 8700 "玩家B" 7200 "玩家C"

# 获取正序排名（最低分排名第一）
ZRANK leaderboard "玩家C"    # 返回 0
ZRANK leaderboard "玩家B"    # 返回 1
ZRANK leaderboard "玩家A"    # 返回 2

# 获取倒序排名（最高分排名第一）
ZREVRANK leaderboard "玩家A"  # 返回 0
ZREVRANK leaderboard "玩家B"  # 返回 1
ZREVRANK leaderboard "玩家C"  # 返回 2
```

### 2.4 ZSCORE - 获取分数

```redis
ZSCORE key member
```

**示例**：

```redis
ZSCORE leaderboard "玩家A"    # 返回 "9500"
```

### 2.5 ZRANGE / ZREVRANGE - 范围查询

```redis
ZRANGE key start stop [WITHSCORES]      # 正序获取
ZREVRANGE key start stop [WITHSCORES]   # 倒序获取
```

**示例**：

```redis
# 获取前3名（带分数）
ZREVRANGE leaderboard 0 2 WITHSCORES

# 获取所有成员
ZRANGE leaderboard 0 -1

# 获取某个玩家的邻居（前后5名）
ZRANGE leaderboard 1 5 WITHSCORES
```

### 2.6 ZCARD - 获取集合大小

```redis
ZCARD leaderboard
```

### 2.7 ZCOUNT - 统计分数范围内的元素数量

```redis
ZCOUNT leaderboard 8000 10000    # 统计8000-10000分之间的玩家数量
```

### 2.8 ZRANGEBYSCORE / ZREVRANGEBYSCORE - 按分数范围查询

```redis
ZRANGEBYSCORE leaderboard 8000 10000 WITHSCORES LIMIT 0 10
```

### 3.4 Redis 配置类

```java
package com.example.leaderboard.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.data.redis.connection.RedisConnectionFactory;
import org.springframework.data.redis.connection.RedisStandaloneConfiguration;
import org.springframework.data.redis.connection.lettuce.LettuceConnectionFactory;
import org.springframework.data.redis.connection.lettuce.LettucePoolingClientConfiguration;
import org.springframework.data.redis.core.RedisTemplate;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.data.redis.serializer.GenericJackson2JsonRedisSerializer;
import org.springframework.data.redis.serializer.StringRedisSerializer;

import java.time.Duration;

/**
 * Redis 配置类
 * 配置连接池和使用 JSON 序列化
 */
@Configuration
public class RedisConfig {

    @Bean
    public RedisConnectionFactory redisConnectionFactory() {
        // 单机模式配置
        RedisStandaloneConfiguration config = new RedisStandaloneConfiguration();
        config.setHostName("localhost");
        config.setPort(6379);
        config.setDatabase(0);

        // 连接池配置
        LettucePoolingClientConfiguration poolConfig = LettucePoolingClientConfiguration.builder()
                .commandTimeout(Duration.ofSeconds(10))
                .build();

        return new LettuceConnectionFactory(config, poolConfig);
    }

    @Bean
    public RedisTemplate<String, Object> redisTemplate(RedisConnectionFactory factory) {
        RedisTemplate<String, Object> template = new RedisTemplate<>();
        template.setConnectionFactory(factory);

        // 使用 String 序列化 key
        template.setKeySerializer(new StringRedisSerializer());
        template.setHashKeySerializer(new StringRedisSerializer());

        // 使用 JSON 序列化 value
        template.setValueSerializer(new GenericJackson2JsonRedisSerializer());
        template.setHashValueSerializer(new GenericJackson2JsonRedisSerializer());

        template.afterPropertiesSet();
        return template;
    }

    @Bean
    public StringRedisTemplate stringRedisTemplate(RedisConnectionFactory factory) {
        return new StringRedisTemplate(factory);
    }
}
```

### 3.7 服务层实现

```java
package com.example.leaderboard.service.impl;

import com.example.leaderboard.dto.PlayerRankDTO;
import com.example.leaderboard.dto.RankRangeDTO;
import com.example.leaderboard.entity.PlayerScore;
import com.example.leaderboard.service.GameLeaderboardService;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.data.redis.core.ZSetOperations;
import org.springframework.stereotype.Service;

import java.util.*;
import java.util.concurrent.TimeUnit;
import java.util.stream.Collectors;

/**
 * 游戏排行榜服务实现类
 */
@Slf4j
@Service
@RequiredArgsConstructor
public class GameLeaderboardServiceImpl implements GameLeaderboardService {

    /**
     * Redis Key 常量
     */
    private static final String LEADERBOARD_KEY = "game:leaderboard:scores";

    /**
     * 玩家信息 Hash Key 前缀
     */
    private static final String PLAYER_INFO_KEY_PREFIX = "game:player:info:";

    /**
     * 排行榜数据过期时间（7天）
     */
    private static final long EXPIRE_DAYS = 7;

    private final StringRedisTemplate stringRedisTemplate;

    /**
     * 获取 ZSet 操作对象
     */
    private ZSetOperations<String, String> getZSetOps() {
        return stringRedisTemplate.opsForZSet();
    }

    // ==================== 基本操作实现 ====================

    @Override
    public boolean upsertScore(String playerId, String playerName, Long score) {
        try {
            // 更新有序集合中的分数
            // 使用 (score * 1_000_000_000_000L) + (MAX - updateTime) 实现同分时按时间排序
            long now = System.currentTimeMillis();
            double compositeScore = score * 1_000_000_000_000L + (Long.MAX_VALUE - now);

            Boolean result = getZSetOps().add(LEADERBOARD_KEY, playerId, compositeScore);

            // 存储玩家信息到 Hash
            String playerInfoKey = PLAYER_INFO_KEY_PREFIX + playerId;
            stringRedisTemplate.opsForHash().put(playerInfoKey, "name", playerName);
            stringRedisTemplate.opsForHash().put(playerInfoKey, "score", String.valueOf(score));
            stringRedisTemplate.opsForHash().put(playerInfoKey, "updateTime", String.valueOf(now));
            stringRedisTemplate.expire(playerInfoKey, EXPIRE_DAYS, TimeUnit.DAYS);

            log.debug("更新玩家 {} 积分: {}", playerId, score);
            return Boolean.TRUE.equals(result);
        } catch (Exception e) {
            log.error("更新玩家 {} 积分失败: {}", playerId, e.getMessage());
            return false;
        }
    }

    @Override
    public Optional<Long> incrementScore(String playerId, Long delta) {
        try {
            // 先获取当前分数
            Double currentScore = getZSetOps().score(LEADERBOARD_KEY, playerId);
            if (currentScore == null) {
                log.warn("玩家 {} 不存在，无法增加积分", playerId);
                return Optional.empty();
            }

            // 从复合分数中提取原始分数
            long originalScore = currentScore.longValue() / 1_000_000_000_000L;
            long newScore = originalScore + delta;

            if (newScore < 0) {
                newScore = 0; // 积分不能为负
            }

            // 更新分数
            upsertScore(playerId, getPlayerName(playerId), newScore);

            return Optional.of(newScore);
        } catch (Exception e) {
            log.error("增加玩家 {} 积分失败: {}", playerId, e.getMessage());
            return Optional.empty();
        }
    }

    @Override
    public Optional<Long> getScore(String playerId) {
        Double score = getZSetOps().score(LEADERBOARD_KEY, playerId);
        if (score == null) {
            return Optional.empty();
        }
        // 从复合分数中提取原始分数
        return Optional.of(score.longValue() / 1_000_000_000_000L);
    }

    // ==================== 排名查询实现 ====================

    @Override
    public Optional<Long> getPlayerRank(String playerId) {
        // ZREVRANK 返回倒序排名（分数最高排名为0），需要 +1 转为从1开始
        Long rank = getZSetOps().reverseRank(LEADERBOARD_KEY, playerId);
        return Optional.ofNullable(rank).map(r -> r + 1);
    }

    @Override
    public Optional<PlayerRankDTO> getPlayerRankDetail(String playerId) {
        // 获取排名
        Long rank = getZSetOps().reverseRank(LEADERBOARD_KEY, playerId);
        if (rank == null) {
            return Optional.empty();
        }

        // 获取分数（复合分数）
        Double compositeScore = getZSetOps().score(LEADERBOARD_KEY, playerId);
        if (compositeScore == null) {
            return Optional.empty();
        }

        // 提取原始分数
        long originalScore = compositeScore.longValue() / 1_000_000_000_000L;

        // 获取玩家信息
        String playerName = getPlayerName(playerId);

        // 计算与上一名的分差
        Long scoreGap = 0L;
        if (rank > 0) {
            Set<ZSetOperations.TypedTuple<String>> topN = getZSetOps()
                    .reverseRangeWithScores(LEADERBOARD_KEY, rank - 1, rank - 1);
            if (topN != null && !topN.isEmpty()) {
                Double prevScore = topN.iterator().next().getScore();
                if (prevScore != null) {
                    long prevOriginalScore = prevScore.longValue() / 1_000_000_000_000L;
                    scoreGap = prevOriginalScore - originalScore;
                }
            }
        }

        return Optional.of(PlayerRankDTO.builder()
                .rank(rank + 1) // 转为从1开始
                .playerId(playerId)
                .playerName(playerName)
                .score(originalScore)
                .scoreGap(scoreGap)
                .build());
    }

    // ==================== 榜单查询实现 ====================

    @Override
    public List<PlayerRankDTO> getTopPlayers(int limit) {
        // ZREVRANGE 倒序获取，WITHSCORES 返回分数
        Set<ZSetOperations.TypedTuple<String>> tuples =
                getZSetOps().reverseRangeWithScores(LEADERBOARD_KEY, 0, limit - 1);

        return convertToRankDTOList(tuples, 1);
    }

    @Override
    public RankRangeDTO getRankRange(Long startRank, Long endRank) {
        // 转换为 0-based 索引
        long startIndex = startRank - 1;
        long endIndex = endRank - 1;

        Set<ZSetOperations.TypedTuple<String>> tuples =
                getZSetOps().reverseRangeWithScores(LEADERBOARD_KEY, startIndex, endIndex);

        Long totalCount = getZSetOps().zCard(LEADERBOARD_KEY);

        List<PlayerRankDTO> players = convertToRankDTOList(tuples, startRank);

        return RankRangeDTO.builder()
                .totalCount(totalCount)
                .startRank(startRank)
                .endRank(endRank)
                .players(players)
                .build();
    }

    @Override
    public List<PlayerRankDTO> getPlayerNeighbors(String playerId, int range) {
        Long rank = getZSetOps().reverseRank(LEADERBOARD_KEY, playerId);
        if (rank == null) {
            return Collections.emptyList();
        }

        // 计算邻居范围
        long startIndex = Math.max(0, rank - range);
        long endIndex = rank + range;

        Set<ZSetOperations.TypedTuple<String>> tuples =
                getZSetOps().reverseRangeWithScores(LEADERBOARD_KEY, startIndex, endIndex);

        return convertToRankDTOList(tuples, startIndex + 1);
    }

    // ==================== 数据管理实现 ====================

    @Override
    public boolean removePlayer(String playerId) {
        try {
            Long removed = getZSetOps().remove(LEADERBOARD_KEY, playerId);
            stringRedisTemplate.delete(PLAYER_INFO_KEY_PREFIX + playerId);
            return removed != null && removed > 0;
        } catch (Exception e) {
            log.error("移除玩家 {} 失败: {}", playerId, e.getMessage());
            return false;
        }
    }

    @Override
    public Long getTotalCount() {
        return getZSetOps().zCard(LEADERBOARD_KEY);
    }

    @Override
    public void clearLeaderboard() {
        stringRedisTemplate.delete(LEADERBOARD_KEY);
        log.warn("排行榜已清空！");
    }

    // ==================== 私有辅助方法 ====================

    /**
     * 获取玩家名称
     */
    private String getPlayerName(String playerId) {
        String playerInfoKey = PLAYER_INFO_KEY_PREFIX + playerId;
        Object name = stringRedisTemplate.opsForHash().get(playerInfoKey, "name");
        return name != null ? name.toString() : "未知玩家";
    }

    /**
     * 将 Redis 查询结果转换为 DTO 列表
     */
    private List<PlayerRankDTO> convertToRankDTOList(
            Set<ZSetOperations.TypedTuple<String>> tuples, long startRank) {

        if (tuples == null || tuples.isEmpty()) {
            return Collections.emptyList();
        }

        List<PlayerRankDTO> result = new ArrayList<>();
        long currentRank = startRank;
        Long prevScore = null;

        for (ZSetOperations.TypedTuple<String> tuple : tuples) {
            String playerId = tuple.getValue();
            Double compositeScore = tuple.getScore();

            if (playerId == null || compositeScore == null) {
                continue;
            }

            // 提取原始分数
            long originalScore = compositeScore.longValue() / 1_000_000_000_000L;

            // 计算分差
            Long scoreGap = 0L;
            if (prevScore != null) {
                scoreGap = prevScore - originalScore;
            }
            prevScore = originalScore;

            result.add(PlayerRankDTO.builder()
                    .rank(currentRank)
                    .playerId(playerId)
                    .playerName(getPlayerName(playerId))
                    .score(originalScore)
                    .scoreGap(scoreGap)
                    .build());

            currentRank++;
        }

        return result;
    }
}
```

```java
package com.example.leaderboard.service.impl;

import com.example.leaderboard.dto.ContentHotDTO;
import com.example.leaderboard.dto.HotRankRangeDTO;
import com.example.leaderboard.service.ContentHotService;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.data.redis.core.ZSetOperations;
import org.springframework.stereotype.Service;

import java.time.Duration;
import java.time.Instant;
import java.util.*;
import java.util.concurrent.TimeUnit;
import java.util.stream.Collectors;

/**
 * 内容热度榜服务实现
 */
@Slf4j
@Service
@RequiredArgsConstructor
public class ContentHotServiceImpl implements ContentHotService {

    /**
     * 热榜 Redis Key 常量
     */
    private static final String HOT_RANKING_KEY = "content:hot:ranking";

    /**
     * 分类热榜 Key 前缀
     */
    private static final String HOT_TYPE_KEY_PREFIX = "content:hot:type:";

    /**
     * 内容信息 Hash Key 前缀
     */
    private static final String CONTENT_INFO_KEY_PREFIX = "content:info:";

    /**
     * 内容指标计数器 Key 前缀
     */
    private static final String METRICS_KEY_PREFIX = "content:metrics:";

    /**
     * 热度数据过期时间（24小时）
     */
    private static final long EXPIRE_HOURS = 24;

    /**
     * 浏览量权重
     */
    private static final double VIEW_WEIGHT = 1.0;

    /**
     * 点赞量权重
     */
    private static final double LIKE_WEIGHT = 5.0;

    /**
     * 评论量权重
     */
    private static final double COMMENT_WEIGHT = 10.0;

    /**
     * 转发量权重
     */
    private static final double SHARE_WEIGHT = 20.0;

    private final StringRedisTemplate stringRedisTemplate;

    private ZSetOperations<String, String> getZSetOps() {
        return stringRedisTemplate.opsForZSet();
    }

    // ==================== 热度操作实现 ====================

    @Override
    public void recordView(String contentId, String contentType, String contentTitle) {
        incrementMetric(contentId, "view", 1);
        ensureContentInfo(contentId, contentType, contentTitle);
        recalculateHotScore(contentId);
    }

    @Override
    public void recordLike(String contentId) {
        incrementMetric(contentId, "like", 1);
        recalculateHotScore(contentId);
    }

    @Override
    public void recordComment(String contentId) {
        incrementMetric(contentId, "comment", 1);
        recalculateHotScore(contentId);
    }

    @Override
    public void recordShare(String contentId) {
        incrementMetric(contentId, "share", 1);
        recalculateHotScore(contentId);
    }

    @Override
    public void updateHotScore(String contentId, Map<String, Long> metrics) {
        // 更新各项指标
        metrics.forEach((type, value) -> {
            String metricsKey = METRICS_KEY_PREFIX + contentId;
            stringRedisTemplate.opsForHash().put(metricsKey, type, String.valueOf(value));
        });
        stringRedisTemplate.expire(metricsKey, EXPIRE_HOURS, TimeUnit.HOURS);

        // 重新计算热度
        recalculateHotScore(contentId);
    }

    @Override
    public Optional<Double> getHotScore(String contentId) {
        Double score = getZSetOps().score(HOT_RANKING_KEY, contentId);
        return Optional.ofNullable(score);
    }

    // ==================== 榜单查询实现 ====================

    @Override
    public List<ContentHotDTO> getHotRanking(int limit) {
        int safeLimit = Math.min(limit, 100);
        Set<ZSetOperations.TypedTuple<String>> tuples =
                getZSetOps().reverseRangeWithScores(HOT_RANKING_KEY, 0, safeLimit - 1);

        return convertToHotDTOList(tuples, 1);
    }

    @Override
    public List<ContentHotDTO> getHotRankingByType(String contentType, int limit) {
        String typeKey = HOT_TYPE_KEY_PREFIX + contentType;
        int safeLimit = Math.min(limit, 100);

        Set<ZSetOperations.TypedTuple<String>> tuples =
                getZSetOps().reverseRangeWithScores(typeKey, 0, safeLimit - 1);

        return convertToHotDTOList(tuples, 1);
    }

    @Override
    public HotRankRangeDTO getHotRankingByPage(int page, int size) {
        if (page < 1 || size < 1) {
            return HotRankRangeDTO.builder()
                    .totalCount(0L)
                    .page(page)
                    .pageSize(size)
                    .totalPages(0)
                    .contents(Collections.emptyList())
                    .build();
        }

        int safeSize = Math.min(size, 50);
        long startIndex = (long) (page - 1) * safeSize;
        long endIndex = startIndex + safeSize - 1;

        Set<ZSetOperations.TypedTuple<String>> tuples =
                getZSetOps().reverseRangeWithScores(HOT_RANKING_KEY, startIndex, endIndex);

        Long totalCount = getZSetOps().zCard(HOT_RANKING_KEY);
        int totalPages = (int) Math.ceil((double) totalCount / safeSize);

        List<ContentHotDTO> contents = convertToHotDTOList(tuples, startIndex + 1);

        return HotRankRangeDTO.builder()
                .totalCount(totalCount)
                .page(page)
                .pageSize(safeSize)
                .totalPages(totalPages)
                .contents(contents)
                .build();
    }

    // ==================== 内容管理实现 ====================

    @Override
    public Optional<ContentHotDTO> getContentInfo(String contentId) {
        String infoKey = CONTENT_INFO_KEY_PREFIX + contentId;
        Map<Object, Object> info = stringRedisTemplate.opsForHash().entries(infoKey);

        if (info.isEmpty()) {
            return Optional.empty();
        }

        Double hotScore = getZSetOps().score(HOT_RANKING_KEY, contentId);
        Long rank = getZSetOps().reverseRank(HOT_RANKING_KEY, contentId);

        return Optional.of(ContentHotDTO.builder()
                .contentId(contentId)
                .contentType(info.get("type") != null ? info.get("type").toString() : null)
                .contentTitle(info.get("title") != null ? info.get("title").toString() : null)
                .hotScore(hotScore != null ? hotScore : 0.0)
                .rank(rank != null ? rank + 1 : null)
                .viewCount(getMetricValue(info, "view"))
                .likeCount(getMetricValue(info, "like"))
                .commentCount(getMetricValue(info, "comment"))
                .shareCount(getMetricValue(info, "share"))
                .build());
    }

    @Override
    public boolean removeContent(String contentId) {
        try {
            // 从总榜移除
            getZSetOps().remove(HOT_RANKING_KEY, contentId);

            // 获取内容类型，从分类榜移除
            String infoKey = CONTENT_INFO_KEY_PREFIX + contentId;
            Object typeObj = stringRedisTemplate.opsForHash().get(infoKey, "type");
            if (typeObj != null) {
                String typeKey = HOT_TYPE_KEY_PREFIX + typeObj.toString();
                getZSetOps().remove(typeKey, contentId);
            }

            // 删除内容信息
            stringRedisTemplate.delete(infoKey);
            stringRedisTemplate.delete(METRICS_KEY_PREFIX + contentId);

            return true;
        } catch (Exception e) {
            log.error("移除内容 {} 失败: {}", contentId, e.getMessage());
            return false;
        }
    }

    @Override
    public Optional<Long> getContentRank(String contentId) {
        Long rank = getZSetOps().reverseRank(HOT_RANKING_KEY, contentId);
        return Optional.ofNullable(rank).map(r -> r + 1);
    }

    // ==================== 私有辅助方法 ====================

    /**
     * 增加指标计数
     */
    private void incrementMetric(String contentId, String metricType, long delta) {
        String metricsKey = METRICS_KEY_PREFIX + contentId;
        stringRedisTemplate.opsForHash().increment(metricsKey, metricType, delta);
        stringRedisTemplate.expire(metricsKey, EXPIRE_HOURS, TimeUnit.HOURS);
    }

    /**
     * 确保内容信息存在
     */
    private void ensureContentInfo(String contentId, String contentType, String contentTitle) {
        String infoKey = CONTENT_INFO_KEY_PREFIX + contentId;

        // 如果标题已存在，不覆盖
        Boolean hasTitle = stringRedisTemplate.opsForHash().hasKey(infoKey, "title");
        if (Boolean.FALSE.equals(hasTitle)) {
            stringRedisTemplate.opsForHash().put(infoKey, "type", contentType);
            stringRedisTemplate.opsForHash().put(infoKey, "title", contentTitle);
            stringRedisTemplate.expire(infoKey, EXPIRE_HOURS, TimeUnit.HOURS);
        }
    }

    /**
     * 重新计算内容热度
     */
    private void recalculateHotScore(String contentId) {
        String metricsKey = METRICS_KEY_PREFIX + contentId;
        Map<Object, Object> metrics = stringRedisTemplate.opsForHash().entries(metricsKey);

        if (metrics.isEmpty()) {
            return;
        }

        // 计算综合热度
        long viewCount = getMetricValue(metrics, "view");
        long likeCount = getMetricValue(metrics, "like");
        long commentCount = getMetricValue(metrics, "comment");
        long shareCount = getMetricValue(metrics, "share");

        double hotScore = viewCount * VIEW_WEIGHT
                + likeCount * LIKE_WEIGHT
                + commentCount * COMMENT_WEIGHT
                + shareCount * SHARE_WEIGHT;

        // 更新总榜
        getZSetOps().add(HOT_RANKING_KEY, contentId, hotScore);
        stringRedisTemplate.expire(HOT_RANKING_KEY, EXPIRE_HOURS + Duration.ofHours(1));

        // 更新分类榜
        String infoKey = CONTENT_INFO_KEY_PREFIX + contentId;
        Object typeObj = stringRedisTemplate.opsForHash().get(infoKey, "type");
        if (typeObj != null) {
            String typeKey = HOT_TYPE_KEY_PREFIX + typeObj.toString();
            getZSetOps().add(typeKey, contentId, hotScore);
            stringRedisTemplate.expire(typeKey, EXPIRE_HOURS, TimeUnit.HOURS);
        }

        log.debug("内容 {} 热度更新: view={}, like={}, comment={}, share={}, hotScore={}",
                contentId, viewCount, likeCount, commentCount, shareCount, hotScore);
    }

    /**
     * 从 metrics Map 中获取指标值
     */
    private long getMetricValue(Map<Object, Object> metrics, String key) {
        Object value = metrics.get(key);
        if (value == null) {
            return 0;
        }
        if (value instanceof Long) {
            return (Long) value;
        }
        try {
            return Long.parseLong(value.toString());
        } catch (NumberFormatException e) {
            return 0;
        }
    }

    /**
     * 将 Redis 结果转换为 DTO 列表
     */
    private List<ContentHotDTO> convertToHotDTOList(
            Set<ZSetOperations.TypedTuple<String>> tuples, long startRank) {

        if (tuples == null || tuples.isEmpty()) {
            return Collections.emptyList();
        }

        List<ContentHotDTO> result = new ArrayList<>();
        long currentRank = startRank;

        for (ZSetOperations.TypedTuple<String> tuple : tuples) {
            String contentId = tuple.getValue();
            Double hotScore = tuple.getScore();

            if (contentId == null || hotScore == null) {
                continue;
            }

            // 获取内容详细信息
            Optional<ContentHotDTO> info = getContentInfo(contentId);
            if (info.isPresent()) {
                ContentHotDTO dto = info.get();
                dto.setRank(currentRank);
                result.add(dto);
            } else {
                // 如果没有详细信息，只显示ID和热度
                result.add(ContentHotDTO.builder()
                        .contentId(contentId)
                        .hotScore(hotScore)
                        .rank(currentRank)
                        .build());
            }

            currentRank++;
        }

        return result;
    }
}
```

## 5. 分页查询与区间查询

### 5.1 分页查询实现

在实际应用中，排行榜数据量可能非常大，需要分页查询。以下是几种常见的分页策略：

```
┌─────────────────────────────────────────────────────────────┐
│                    分页查询策略                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 偏移量分页（OFFSET）                                     │
│     优点：简单易用                                          │
│     缺点：数据量大时性能下降（需扫描跳过大量数据）             │
│     适用场景：页码较小的场景                                 │
│                                                             │
│  2. 游标分页（Cursor-based）                                 │
│     优点：性能稳定，不受数据量影响                           │
│     缺点：只能向前或向后翻页                                 │
│     适用场景：数据量大的场景，推荐使用                        │
│                                                             │
│  3. 倒排分页（从大到小）                                     │
│     使用 ZREVRANGE 从高排名往低排名查询                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 5.3 游标分页实现

```java
/**
 * 游标分页查询
 * 基于排名的游标分页，性能更稳定
 *
 * @param cursorRank 游标排名（查询此排名之后的数据，为空则从第一名开始）
 * @param size 每页大小
 * @return 下一批数据和新的游标
 */
public CursorPageResult<PlayerRankDTO> getRankRangeByCursor(
        Long cursorRank, int size) {

    long startIndex;

    if (cursorRank == null) {
        // 首次查询，从第一名开始
        startIndex = 0;
    } else {
        // 从游标排名之后开始（跳过游标本身）
        startIndex = cursorRank;
    }

    long endIndex = startIndex + size; // 多查一条作为下一轮游标

    Set<ZSetOperations.TypedTuple<String>> tuples = getZSetOps()
            .reverseRangeWithScores(LEADERBOARD_KEY, startIndex, endIndex);

    if (tuples == null || tuples.isEmpty()) {
        return CursorPageResult.<PlayerRankDTO>builder()
                .data(Collections.emptyList())
                .nextCursor(null)
                .hasMore(false)
                .build();
    }

    List<PlayerRankDTO> players = convertToRankDTOList(tuples, startIndex + 1);

    // 判断是否还有更多数据
    boolean hasMore = players.size() > size;
    Long nextCursor = hasMore ? startIndex + size + 1 : null;

    // 截取实际需要返回的数据
    if (players.size() > size) {
        players = players.subList(0, size);
    }

    return CursorPageResult.<PlayerRankDTO>builder()
            .data(players)
            .nextCursor(nextCursor)
            .hasMore(hasMore)
            .build();
}
```

### 5.4 区间查询实现

```java
/**
 * 获取指定分数区间的玩家
 *
 * @param minScore 最低分数
 * @param maxScore 最高分数
 * @return 该区间的玩家列表
 */
public List<PlayerRankDTO> getPlayersByScoreRange(long minScore, long maxScore) {
    // 转换为复合分数
    double minComposite = minScore * 1_000_000_000_000L;
    double maxComposite = (maxScore + 1) * 1_000_000_000_000L - 1;

    Set<String> players = getZSetOps()
            .rangeByScore(LEADERBOARD_KEY, minComposite, maxComposite);

    if (players == null || players.isEmpty()) {
        return Collections.emptyList();
    }

    // 获取排名信息
    List<PlayerRankDTO> result = new ArrayList<>();
    for (String playerId : players) {
        Optional<PlayerRankDTO> detail = getPlayerRankDetail(playerId);
        detail.ifPresent(result::add);
    }

    return result;
}

/**
 * 获取某玩家的前后邻居
 *
 * @param playerId 玩家ID
 * @param beforeCount 前面的玩家数量
 * @param afterCount 后面的玩家数量
 * @return 邻居玩家列表
 */
public List<PlayerRankDTO> getPlayerNeighborsWithCount(
        String playerId, int beforeCount, int afterCount) {

    Long rank = getZSetOps().reverseRank(LEADERBOARD_KEY, playerId);
    if (rank == null) {
        return Collections.emptyList();
    }

    long startIndex = Math.max(0, rank - beforeCount);
    long endIndex = rank + afterCount;

    Set<ZSetOperations.TypedTuple<String>> tuples = getZSetOps()
            .reverseRangeWithScores(LEADERBOARD_KEY, startIndex, endIndex);

    return convertToRankDTOList(tuples, startIndex + 1);
}
```

```java
package com.example.leaderboard.service.impl;

import com.example.leaderboard.service.GameLeaderboardService;
import com.example.leaderboard.service.RealTimeRankingService;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.stereotype.Service;

import java.util.Map;
import java.util.concurrent.TimeUnit;

/**
 * 实时排名更新服务实现
 */
@Slf4j
@Service
@RequiredArgsConstructor
public class RealTimeRankingServiceImpl implements RealTimeRankingService {

    /**
     * 用户行为计数器 Key 前缀
     */
    private static final String USER_ACTION_KEY_PREFIX = "ranking:action:";

    /**
     * 行为计数器过期时间（5分钟，用于聚合批量更新）
     */
    private static final long ACTION_EXPIRE_MINUTES = 5;

    private final StringRedisTemplate stringRedisTemplate;
    private final GameLeaderboardService leaderboardService;

    @Override
    public void onUserAction(String userId, String actionType, long delta) {
        String actionKey = USER_ACTION_KEY_PREFIX + actionType + ":" + userId;

        // 原子性增加计数
        Long newCount = stringRedisTemplate.opsForValue().increment(actionKey, delta);
        stringRedisTemplate.expire(actionKey, ACTION_EXPIRE_MINUTES, TimeUnit.MINUTES);

        // 计算权重分数
        double weight = getActionWeight(actionType);
        long weightedScore = (long) (delta * weight);

        // 实时更新排名
        if (weightedScore != 0) {
            leaderboardService.incrementScore(userId, weightedScore);
            log.debug("用户 {} 行为 {} 增加 {}，排名已更新", userId, actionType, delta);
        }
    }

    @Override
    public void batchUpdateRanking(Map<String, Long> updates) {
        updates.forEach((userId, score) -> {
            if (score != null && score != 0) {
                leaderboardService.incrementScore(userId, score);
            }
        });
        log.info("批量更新了 {} 个用户的排名", updates.size());
    }

    @Override
    public Long getRealTimeRank(String userId) {
        return leaderboardService.getPlayerRank(userId).orElse(null);
    }

    /**
     * 获取行为权重
     */
    private double getActionWeight(String actionType) {
        return switch (actionType) {
            case "view" -> 1.0;
            case "like" -> 5.0;
            case "comment" -> 10.0;
            case "share" -> 20.0;
            case "purchase" -> 100.0;
            default -> 1.0;
        };
    }
}
```

```java
            for (String playerId : topPlayers) {
                leaderboardService.getPlayerRankDetail(playerId)
                        .ifPresent(detail -> {
                            // TODO: 保存到数据库
                            // playerRepository.save(detail);
                            log.debug("同步玩家 {} 排名到数据库", playerId);

            log.info("成功同步 {} 个玩家的排名数据到数据库", topPlayers.size());

        } catch (Exception e) {
            log.error("同步排行榜数据失败: {}", e.getMessage(), e);
        }
    }

    /**
     * 每小时：清理过期数据
     * 移除长时间不活跃的玩家，避免数据膨胀
     */
    @Scheduled(cron = "0 0 * * * *")
    public void cleanupInactivePlayers() {
        log.info("开始清理不活跃玩家...");

        try {
            Long totalCount = leaderboardService.getTotalCount();
            if (totalCount == null || totalCount == 0) {
                return;
            }

            // 获取所有玩家
            Set<String> allPlayers = stringRedisTemplate.opsForZSet()
                    .range(LEADERBOARD_KEY, 0, -1);

            if (allPlayers == null || allPlayers.isEmpty()) {
                return;
            }

            // 模拟清理逻辑
            // 实际应用中需要结合玩家最后活跃时间来判断
            int cleanedCount = 0;
            int threshold = 30; // 30天不活跃则清理

            for (String playerId : allPlayers) {
                // 检查玩家最后活跃时间
                String lastActiveKey = "player:lastactive:" + playerId;
                String lastActive = stringRedisTemplate.opsForValue().get(lastActiveKey);

                if (lastActive != null) {
                    long lastActiveTime = Long.parseLong(lastActive);
                    long daysSinceLastActive = (System.currentTimeMillis() - lastActiveTime)
                            / (1000 * 60 * 60 * 24);

                    if (daysSinceLastActive > threshold) {
                        leaderboardService.removePlayer(playerId);
                        cleanedCount++;
                        log.debug("清理不活跃玩家: {} ({}天未活跃)", playerId, daysSinceLastActive);
                    }
                }
            }

            if (cleanedCount > 0) {
                log.info("清理了 {} 个不活跃玩家", cleanedCount);
            }

        } catch (Exception e) {
            log.error("清理不活跃玩家失败: {}", e.getMessage(), e);
        }
    }

    /**
     * 每天凌晨3点：生成排行榜快照
     * 用于数据分析、历史排名查询等
     */
    @Scheduled(cron = "0 0 3 * * *")
    public void generateRankingSnapshot() {
        log.info("开始生成排行榜快照...");

        try {
            String snapshotKey = "ranking:snapshot:" + System.currentTimeMillis();

            // 获取当前完整排行榜
            Set<String> allPlayers = stringRedisTemplate.opsForZSet()
                    .range(LEADERBOARD_KEY, 0, -1);

            if (allPlayers == null || allPlayers.isEmpty()) {
                log.info("没有数据需要生成快照");
                return;
            }

            // 复制到快照 Key
            for (String playerId : allPlayers) {
                Double score = stringRedisTemplate.opsForZSet().score(LEADERBOARD_KEY, playerId);
                if (score != null) {
                    stringRedisTemplate.opsForZSet().add(snapshotKey, playerId, score);
                }
            }

            // 快照保留7天
            stringRedisTemplate.expire(snapshotKey, 7, java.util.concurrent.TimeUnit.DAYS);

            log.info("成功生成排行榜快照: {}，包含 {} 个玩家", snapshotKey, allPlayers.size());

        } catch (Exception e) {
            log.error("生成排行榜快照失败: {}", e.getMessage(), e);
        }
    }

    /**
     * 每分钟：处理待同步的行为数据
     * 将用户行为从临时存储合并到主排行
     */
    @Scheduled(cron = "0 * * * * *")
    public void processPendingActions() {
        try {
            Set<String> pendingKeys = stringRedisTemplate.keys("ranking:action:*");
            if (pendingKeys == null || pendingKeys.isEmpty()) {
                return;
            }

            List<String> processedKeys = new ArrayList<>();

            for (String key : pendingKeys) {
                String actionType = extractActionType(key);
                String playerId = extractPlayerId(key);

                if (actionType != null && playerId != null) {
                    String value = stringRedisTemplate.opsForValue().get(key);
                    if (value != null) {
                        long delta = Long.parseLong(value);
                        if (delta != 0) {
                            // 更新到待同步队列
                            String syncKey = PENDING_SYNC_KEY + ":" + playerId;
                            stringRedisTemplate.opsForValue().increment(syncKey, delta);
                            processedKeys.add(key);
                        }
                    }
                }
            }

            // 清理已处理的行为记录
            for (String key : processedKeys) {
                stringRedisTemplate.delete(key);
            }

            if (!processedKeys.isEmpty()) {
                log.debug("处理了 {} 条待同步行为数据", processedKeys.size());
            }

        } catch (Exception e) {
            log.error("处理待同步行为数据失败: {}", e.getMessage(), e);
        }
    }

    private String extractActionType(String key) {
        // 格式: ranking:action:{actionType}:{playerId}
        String[] parts = key.split(":");
        return parts.length >= 3 ? parts[2] : null;
    }

    private String extractPlayerId(String key) {
        // 格式: ranking:action:{actionType}:{playerId}
        String[] parts = key.split(":");
        return parts.length >= 4 ? parts[3] : null;
    }
}
```
