# 第2章 Jenkins 安装与部署

Jenkins 作为一款开源的自动化服务器，支持在多种平台上安装和运行。本章将详细介绍在不同操作系统和环境下的安装方法，以及初始配置、升级迁移等关键内容。

## 2.1 系统要求

在开始安装之前，首先了解 Jenkins 的系统要求。

### 2.1.1 硬件要求

| 配置项 | 最低要求 | 推荐配置 |
|--------|----------|----------|
| CPU | 1 核 | 4 核或以上 |
| 内存 | 256 MB | 2 GB 或以上 |
| 磁盘空间 | 1 GB | 50 GB 或以上（取决于构建历史） |
| 网络 | 100 Mbps | 1 Gbps |

### 2.1.2 软件要求

- **Java**: Jenkins 2.462+ 需要 Java 17 或更高版本；旧版本需要 Java 11
- **操作系统**: Windows 10/11, Linux (Debian, Ubuntu, Red Hat, CentOS 等), macOS
- **浏览器**: Chrome, Firefox, Edge, Safari（最新版本）

## 2.2 Windows 安装（exe 安装包）

使用 Windows 安装向导是最简单的安装方式，适合大多数 Windows 用户。

### 2.2.1 下载安装包

1. 访问 Jenkins 官方下载页面：https://www.jenkins.io/download/
2. 选择 "Windows" 选项，下载 `jenkins.msi` 安装包

### 2.2.2 安装步骤

#### 图形界面安装

1. 双击下载的 `jenkins.msi` 文件启动安装向导
2. 在 "Destination Folder" 界面选择安装目录（默认：`C:\Program Files\Jenkins`）
3. 点击 "Install" 开始安装
4. 安装完成后勾选 "Start Jenkins" 选项
5. 点击 "Finish" 完成安装

#### 命令行静默安装

如需自动化部署，可使用命令行进行静默安装：

```powershell
# 完整安装（指定安装目录）
msiexec /i jenkins.msi /qn INSTALLDIR="D:\Jenkins" /l*v install.log

# 自定义端口安装（安装后修改）
msiexec /i jenkins.msi /qn INSTALLDIR="D:\Jenkins" /l*v install.log

# 参数说明
# /i     - 安装模式
# /qn    - 无界面安装
# /l*v   - 详细日志输出
```

### 2.2.3 修改端口号

默认情况下，Jenkins 使用端口 `8080`。如需修改：

1. 打开 Jenkins 安装目录下的 `jenkins.xml` 配置文件
2. 找到以下行：
   ```xml
   <arguments>-Xrs -Xmx256m -Dhudson.lifecycle=hudson.lifecycle.WindowsServiceLifecycle -jar "%BASE%\jenkins.war" --httpPort=8080</arguments>
   ```
3. 修改 `--httpPort=8080` 为 desired port，例如 `--httpPort=9090`
4. 重启 Jenkins 服务

```powershell
# 使用 net 命令重启服务
net stop Jenkins
net start Jenkins
```

### 2.2.4 验证安装

1. 打开浏览器访问 `http://localhost:8080`（或你配置的端口）
2. 首次访问会显示解锁界面
3. 查看管理员密码文件：`C:\Program Files\Jenkins\secrets\initialAdminPassword`
4. 输入密码完成解锁

## 2.3 Linux 安装

### 2.3.1 Debian/Ubuntu（apt）

#### 方法一：使用官方 apt 仓库（推荐）

```bash
# 1. 安装必要的前置依赖
sudo apt update
sudo apt install -y curl gnupg lsb-release

# 2. 添加 Jenkins GPG 密钥
curl -fsSL https://pkg.jenkins.io/jenkins.io.key | sudo gpg --dearmor -o /usr/share/keyrings/jenkins-keyring.gpg

# 3. 添加 Jenkins apt 仓库
echo "deb [signed-by=/usr/share/keyrings/jenkins-keyring.gpg] https://pkg.jenkins.io/debian binary/" | sudo tee /etc/apt/sources.list.d/jenkins.list > /dev/null

# 4. 更新软件包索引
sudo apt update

# 5. 安装 Jenkins
sudo apt install -y jenkins

# 6. 启动 Jenkins 服务
sudo systemctl enable jenkins
sudo systemctl start jenkins

# 7. 检查服务状态
sudo systemctl status jenkins
```

#### 方法二：使用默认仓库（版本可能较旧）

```bash
sudo apt update
sudo apt install -y openjdk-17-jdk
sudo apt install -y jenkins
sudo systemctl enable jenkins
sudo systemctl start jenkins
```

#### 配置文件位置

- 主配置文件：`/etc/default/jenkins`
- 日志文件：`/var/log/jenkins/jenkins.log`
- Home 目录：`/var/lib/jenkins`

### 2.3.2 Red Hat/CentOS（yum/dnf）

#### 方法一：使用官方 yum 仓库（推荐）

```bash
# 1. 安装 Java（如果尚未安装）
sudo yum install -y java-17-openjdk java-17-openjdk-devel

# 2. 添加 Jenkins 仓库
sudo wget -O /etc/yum.repos.d/jenkins.repo https://pkg.jenkins.io/redhat-stable/jenkins.repo
sudo rpm --import https://pkg.jenkins.io/redhat-stable/jenkins.io.key

# 3. 清理 yum 缓存
sudo yum clean metadata

# 4. 安装 Jenkins
sudo yum install -y jenkins

# 5. 设置 Jenkins 开机自启
sudo systemctl enable jenkins

# 6. 启动 Jenkins
sudo systemctl start jenkins

# 7. 检查服务状态
sudo systemctl status jenkins
```

#### 方法二：手动下载 rpm 包安装

```bash
# 1. 下载 Jenkins rpm 包
sudo rpm -ivh https://pkg.jenkins.io/redhat-stable/jenkins-2.462-1.1.noarch.rpm

# 2. 启动服务
sudo systemctl enable jenkins
sudo systemctl start jenkins
```

#### 配置文件位置

- 主配置文件：`/etc/sysconfig/jenkins`
- 日志文件：`/var/log/jenkins/jenkins.log`
- Home 目录：`/var/lib/jenkins`

### 2.3.3 手动安装（通用）

适用于任何 Linux 发行版，不依赖系统包管理器。

#### 步骤 1：安装 Java

```bash
# Debian/Ubuntu
sudo apt install -y openjdk-17-jdk

# Red Hat/CentOS
sudo yum install -y java-17-openjdk java-17-openjdk-devel

# 验证 Java 安装
java -version
```

#### 步骤 2：下载 Jenkins

```bash
# 创建 Jenkins 用户（可选但推荐）
sudo useradd -m -s /bin/bash jenkins

# 创建安装目录
sudo mkdir -p /opt/jenkins
cd /opt/jenkins

# 下载 Jenkins WAR 文件
sudo wget https://get.jenkins.io/war-stable/latest/jenkins.war -O jenkins.war

# 设置权限
sudo chown -R jenkins:jenkins /opt/jenkins
```

#### 步骤 3：创建 systemd 服务文件

```bash
sudo tee /etc/systemd/system/jenkins.service << 'EOF'
[Unit]
Description=Jenkins Automation Server
Documentation=https://www.jenkins.io/
After=network-online.target

[Service]
Type=simple
User=jenkins
Group=jenkins
WorkingDirectory=/opt/jenkins
ExecStart=/usr/bin/java -jar /opt/jenkins/jenkins.war
Restart=on-failure
RestartSec=10
StandardOutput=syslog
StandardError=syslog
SyslogIdentifier=jenkins

# 可选：设置内存参数
Environment=JENKINS_HOME=/var/lib/jenkins

[Install]
WantedBy=multi-user.target
EOF
```

#### 步骤 4：启动服务

```bash
# 重新加载 systemd 配置
sudo systemctl daemon-reload

# 启动 Jenkins
sudo systemctl enable jenkins
sudo systemctl start jenkins

# 查看日志
sudo journalctl -u jenkins -f
```

## 2.4 Docker 安装

### 2.4.1 使用 Docker 运行 Jenkins

#### 基本用法

```bash
# 拉取官方 Jenkins 镜像
docker pull jenkins/jenkins:lts

# 运行 Jenkins 容器
docker run -d \
  --name jenkins \
  -p 8080:8080 \
  -p 50000:50000 \
  -v jenkins_home:/var/jenkins_home \
  jenkins/jenkins:lts
```

#### 详细配置示例

```bash
# 创建 Jenkins 数据目录
mkdir -p /data/jenkins

# 运行 Jenkins 容器（带完整配置）
docker run -d \
  --name jenkins \
  -p 8080:8080 \
  -p 50000:50000 \
  -v /data/jenkins:/var/jenkins_home \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -e JENKINS_OPTS="--prefix=/jenkins" \
  -e JAVA_OPTS="-Xmx2048m" \
  --restart unless-stopped \
  jenkins/jenkins:lts

# 参数说明：
# -d                    后台运行
# --name jenkins         容器名称
# -p 8080:8080           映射 Web 界面端口
# -p 50000:50000         映射 agent 通信端口
# -v jenkins_home        数据持久化卷
# -v docker.sock        允许 Docker-in-Docker 构建
# --restart unless-stopped 自动重启
```

### 2.4.2 Docker Compose 部署

创建 `docker-compose.yml` 文件：

```yaml
version: '3.8'

services:
  jenkins:
    image: jenkins/jenkins:lts
    container_name: jenkins
    restart: unless-stopped
    privileged: true
    ports:
      - "8080:8080"
      - "50000:50000"
    volumes:
      - jenkins_data:/var/jenkins_home
      - /var/run/docker.sock:/var/run/docker.sock
    environment:
      - JAVA_OPTS=-Xmx2048m -Xms512m
      - JENKINS_OPTS=--prefix=/jenkins
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8080/login"]
      interval: 30s
      timeout: 10s
      retries: 5
      start_period: 60s

volumes:
  jenkins_data:
    driver: local
```

启动服务：

```bash
# 启动 Jenkins
docker-compose up -d

# 查看日志
docker-compose logs -f

# 停止服务
docker-compose down

# 完全清除（包括数据）
docker-compose down -v
```

### 2.4.3 Dockerfile 自定义镜像

如需自定义 Jenkins 镜像，可创建 `Dockerfile`：

```dockerfile
# 基础镜像
FROM jenkins/jenkins:lts

# 维护者信息
LABEL maintainer="your-email@example.com"

# 安装必要的工具
USER root
RUN apt-get update && apt-get install -y \
    maven \
    git \
    curl \
    unzip \
    && rm -rf /var/lib/apt/lists/*

# 安装 Docker（用于 DinD）
RUN curl -fsSL https://get.docker.com | sh

# 恢复 Jenkins 用户
USER jenkins

# 安装插件（可选）
COPY plugins.txt /usr/share/jenkins/ref/plugins.txt
RUN jenkins-plugin-cli -f /usr/share/jenkins/ref/plugins.txt

# 挂载点声明
VOLUME ["/var/jenkins_home"]
```

创建 `plugins.txt` 文件指定要安装的插件：

```
blueocean
pipeline-stage-view
git
configuration-as-code
job-dsl
```

构建镜像：

```bash
# 构建自定义镜像
docker build -t my-jenkins:latest .

# 运行自定义镜像
docker run -d \
  --name jenkins \
  -p 8080:8080 \
  -p 50000:50000 \
  -v jenkins_data:/var/jenkins_home \
  my-jenkins:latest
```

### 2.4.4 Docker 数据持久化

Jenkins 的数据主要存储在 `/var/jenkins_home` 目录，包括：

- 插件
- 构建历史
- 用户配置
- 任务配置

#### 使用宿主机目录持久化

```bash
# 创建宿主机目录
sudo mkdir -p /data/jenkins
sudo chown -R 1000:1000 /data/jenkins

# 运行容器
docker run -d \
  --name jenkins \
  -p 8080:8080 \
  -v /data/jenkins:/var/jenkins_home \
  jenkins/jenkins:lts
```

#### 使用 Docker Volume

```bash
# 创建命名卷
docker volume create jenkins_home

# 查看卷信息
docker volume inspect jenkins_home

# 使用卷运行容器
docker run -d \
  --name jenkins \
  -p 8080:8080 \
  -v jenkins_home:/var/jenkins_home \
  jenkins/jenkins:lts
```

### 2.4.5 Docker-in-Docker (DinD)

如需在 Jenkins 容器内构建 Docker 镜像，需要配置 DinD：

```bash
# 方式一：挂载宿主机的 Docker socket
docker run -d \
  --name jenkins \
  -p 8080:8080 \
  -v /var/run/docker.sock:/var/run/docker.sock \
  jenkins/jenkins:lts

# 方式二：使用 dind 服务（更安全）
docker run -d \
  --name jenkins \
  -p 8080:8080 \
  --privileged \
  jenkins/jenkins:lts-dind
```

## 2.5 Kubernetes 安装

### 2.5.1 使用 Helm 部署 Jenkins

Helm 是 Kubernetes 的包管理器，推荐使用 Helm 进行 Jenkins 部署。

#### 前提条件

- Kubernetes 1.19+
- Helm 3.2+
- 动态存储类（StorageClass）

#### 步骤 1：添加 Jenkins Helm 仓库

```bash
# 添加 Jenkins 仓库
helm repo add jenkins https://charts.jenkins.io

# 更新 Helm 仓库
helm repo update

# 查看可用版本
helm search repo jenkins
```

#### 步骤 2：创建 values.yaml 配置文件

```yaml
# values.yaml

controller:
  # Jenkins controller 配置
  image: jenkins/jenkins:lts
  tag: "2.462"
  
  # 资源配置
  resources:
    requests:
      cpu: "500m"
      memory: "512Mi"
    limits:
      cpu: "2000m"
      memory: "4Gi"
  
  # 服务配置
  service:
    type: ClusterIP
    port: 8080
    targetPort: 8080
  
  # 持久化存储
  persistence:
    enabled: true
    storageClass: "standard"
    size: "20Gi"
  
  # 入口配置
  ingress:
    enabled: true
    annotations:
      kubernetes.io/ingress.class: nginx
    hosts:
      - host: jenkins.example.com
        paths: []
  
  # 初始插件列表
  installPlugins:
    - kubernetes
    - workflow-aggregator
    - git
    - configuration-as-code
    - blueocean

  # Java 参数
  javaOpts: "-Xmx2048m -Xms512m"

agent:
  # 默认 agent 配置
  image: jenkins/inbound-agent
  imageTag: "3107.v665ddc4f4b_23"
  resources:
    requests:
      cpu: "200m"
      memory: "256Mi"
    limits:
      cpu: "500m"
      memory: "512Mi"
```

#### 步骤 3：部署 Jenkins

```bash
# 创建命名空间
kubectl create namespace jenkins

# 部署 Jenkins
helm install jenkins jenkins/jenkins -n jenkins -f values.yaml

# 查看部署状态
kubectl get pods -n jenkins

# 查看详细状态
kubectl describe pod -n jenkins -l app.kubernetes.io/name=jenkins
```

#### 步骤 4：获取初始密码

```bash
# 获取 admin 密码
kubectl exec -n jenkins svc/jenkins -- cat /var/jenkins_home/secrets/initialAdminPassword

# 或者通过日志查看
kubectl logs -n jenkins -l app.kubernetes.io/name=jenkins --tail=100
```

#### 步骤 5：访问 Jenkins

```bash
# 获取 ingress 地址
kubectl get ingress -n jenkins

# 或通过端口转发访问
kubectl port-forward -n jenkins svc/jenkins 8080:8080
```

### 2.5.2 手动 YAML 部署（不使用 Helm）

如需更精细的控制，可使用原生 YAML 方式部署。

#### 创建 Namespace

```yaml
# jenkins-namespace.yaml
apiVersion: v1
kind: Namespace
metadata:
  name: jenkins
```

#### 创建 StorageClass（可选）

```yaml
# jenkins-storage.yaml
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: jenkins-storage
provisioner: kubernetes.io/gce-pd  # 根据实际环境修改
parameters:
  type: pd-standard
  replication-type: regional
```

#### 创建 ConfigMap

```yaml
# jenkins-config.yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: jenkins-config
  namespace: jenkins
data:
  jenkins.conf: |
    jenkins.model.JenkinsLocation
    {
      url = "http://jenkins.example.com"
    }
```

#### 创建 StatefulSet

```yaml
# jenkins-statefulset.yaml
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: jenkins
  namespace: jenkins
spec:
  serviceName: jenkins
  replicas: 1
  selector:
    matchLabels:
      app: jenkins
  template:
    metadata:
      labels:
        app: jenkins
    spec:
      securityContext:
        fsGroup: 1000
      initContainers:
        - name: init
          image: busybox:1.35
          command:
            - sh
            - -c
            - |
              chown -R 1000:1000 /var/jenkins_home
          volumeMounts:
            - name: jenkins-home
              mountPath: /var/jenkins_home
      containers:
        - name: jenkins
          image: jenkins/jenkins:lts
          ports:
            - containerPort: 8080
              name: http
            - containerPort: 50000
              name: jnlp
          resources:
            requests:
              cpu: "500m"
              memory: "512Mi"
            limits:
              cpu: "2000m"
              memory: "4Gi"
          volumeMounts:
            - name: jenkins-home
              mountPath: /var/jenkins_home
          env:
            - name: JAVA_OPTS
              value: "-Xmx2048m -Xms512m"
          livenessProbe:
            httpGet:
              path: /login
              port: 8080
            initialDelaySeconds: 60
            periodSeconds: 10
          readinessProbe:
            httpGet:
              path: /login
              port: 8080
            initialDelaySeconds: 60
            periodSeconds: 10
  volumeClaimTemplates:
    - metadata:
        name: jenkins-home
      spec:
        accessModes: ["ReadWriteOnce"]
        resources:
          requests:
            storage: 20Gi
```

#### 创建 Service

```yaml
# jenkins-service.yaml
apiVersion: v1
kind: Service
metadata:
  name: jenkins
  namespace: jenkins
spec:
  type: ClusterIP
  selector:
    app: jenkins
  ports:
    - name: http
      port: 8080
      targetPort: 8080
    - name: jnlp
      port: 50000
      targetPort: 50000
```

#### 应用所有 YAML

```bash
# 创建所有资源
kubectl apply -f jenkins-namespace.yaml
kubectl apply -f jenkins-config.yaml
kubectl apply -f jenkins-statefulset.yaml
kubectl apply -f jenkins-service.yaml

# 查看部署结果
kubectl get all -n jenkins

# 查看日志
kubectl logs -n jenkins statefulset/jenkins -f
```

### 2.5.3 Jenkins Agent 在 Kubernetes 中的配置

在 Kubernetes 环境中，Jenkins 可以动态创建 Pod 作为 Agent。

#### 安装 Kubernetes Plugin

1. 进入 Manage Jenkins > Manage Plugins
2. 搜索 "Kubernetes" 并安装
3. 重启 Jenkins

#### 配置 Kubernetes Cloud

1. 进入 Manage Jenkins > Manage Nodes > Configure Clouds
2. 点击 "Add a new cloud" > "Kubernetes"
3. 配置以下内容：

```
名称：kubernetes
Kubernetes 地址：https://kubernetes.default.svc.cluster.local
Namespace：jenkins
Credentials：添加 kubeconfig 或服务账户 token
Jenkins 地址：http://jenkins:8080
```

#### Kubernetes Pod 模板示例

```yaml
jenkins-agent:
  name: jnlp
  image: jenkins/inbound-agent:latest
  yaml: |
    apiVersion: v1
    kind: Pod
    spec:
      containers:
        - name: jnlp
          image: jenkins/inbound-agent:latest
          imagePullPolicy: IfNotPresent
          resources:
            requests:
              cpu: "200m"
              memory: "256Mi"
            limits:
              cpu: "500m"
              memory: "512Mi"
          env:
            - name: JAVA_OPTS
              value: "-Xmx256m"
      restartPolicy: Never
```

## 2.6 WAR 包安装（Tomcat/Jetty）

Jenkins 本质上是一个 WAR 文件，可以部署到任何 Java Web 容器中。

### 2.6.1 Tomcat 部署

#### 步骤 1：安装 Tomcat

```bash
# 下载 Tomcat 10
cd /opt
sudo wget https://dlcdn.apache.org/tomcat/tomcat-10/v10.1.20/bin/apache-tomcat-10.1.20.tar.gz
sudo tar -xzf apache-tomcat-10.1.20.tar.gz
sudo mv apache-tomcat-10.1.20 tomcat

# 设置环境变量
echo 'export CATALINA_HOME=/opt/tomcat' >> ~/.bashrc
source ~/.bashrc
```

#### 步骤 2：部署 Jenkins WAR

```bash
# 下载 Jenkins WAR
sudo wget https://get.jenkins.io/war-stable/latest/jenkins.war -O /opt/tomcat/webapps/jenkins.war

# 或者移动已下载的 WAR
sudo mv jenkins.war /opt/tomcat/webapps/

# 设置权限
sudo chown -R tomcat:tomcat /opt/tomcat
```

#### 步骤 3：配置 Tomcat 内存

编辑 `/opt/tomcat/bin/setenv.sh`：

```bash
# 创建 setenv.sh
sudo tee /opt/tomcat/bin/setenv.sh << 'EOF'
# Jenkins 内存配置
CATALINA_OPTS="-Xms512m -Xmx2048m -XX:+UseG1GC"

# Jenkins agent 端口
CATALINA_OPTS="$CATALINA_OPTS -Dhudson.master.root=/var/jenkins_home"

# 字符编码
JAVA_OPTS="-Dfile.encoding=UTF-8 -Dsun.jnu.encoding=UTF-8"
EOF

# 设置权限
sudo chmod +x /opt/tomcat/bin/setenv.sh
sudo chown tomcat:tomcat /opt/tomcat/bin/setenv.sh
```

#### 步骤 4：启动 Tomcat

```bash
# 启动 Tomcat
sudo -u tomcat /opt/tomcat/bin/startup.sh

# 或者前台运行（查看日志）
sudo -u tomcat /opt/tomcat/bin/catalina.sh run

# 查看日志
tail -f /opt/tomcat/logs/catalina.out
```

#### 步骤 5：访问 Jenkins

- Jenkins: `http://your-server:8080/jenkins`
- Tomcat Manager: `http://your-server:8080/manager/html`

### 2.6.2 Jetty 部署

#### 步骤 1：下载 Jetty

```bash
# 下载 Jetty 12
cd /opt
sudo wget https://repo1.maven.org/apache/tomee/jetty/12.0.12/jetty-home-12.0.12.tar.gz
sudo tar -xzf jetty-home-12.0.12.tar.gz
sudo mv jetty-home-12.0.12 jetty

# 下载 Jetty Runner（用于运行 WAR）
sudo wget https://repo1.maven.org/apache/tomee/jetty-runner/12.0.12/jetty-runner-12.0.12.jar
```

#### 步骤 2：创建启动脚本

```bash
# 创建启动脚本
sudo tee /opt/start-jenkins.sh << 'EOF'
#!/bin/bash

# Jetty Runner 启动 Jenkins
java -jar /opt/jetty-runner-12.0.12.jar \
  --port 8080 \
  --path /jenkins \
  --log /var/log/jetty/jetty.log \
  --ini /opt/jetty/etc/jetty.ini \
  /opt/jenkins.war
EOF

# 设置权限
sudo chmod +x /opt/start-jenkins.sh
sudo chown -R jenkins:jenkins /opt/jenkins.war
```

#### 步骤 3：创建数据目录

```bash
sudo mkdir -p /var/log/jetty /var/lib/jenkins
sudo chown -R jenkins:jenkins /var/lib/jenkins /var/log/jetty
```

#### 步骤 4：启动 Jenkins

```bash
# 后台运行
nohup sudo -u jenkins /opt/start-jenkins.sh &

# 或前台运行（调试）
sudo -u jenkins /opt/start-jenkins.sh
```

### 2.6.3 使用 Docker 运行 Jenkins WAR

```bash
# 下载 Jenkins WAR
wget https://get.jenkins.io/war-stable/latest/jenkins.war -O jenkins.war

# 使用 Jetty Runner 运行
docker run -d \
  --name jenkins-war \
  -p 8080:8080 \
  -v $(pwd)/jenkins.war:/opt/jenkins.war \
  eclipse/jetty:12 \
  java -jar /opt/jenkins.war

# 或使用 Tomcat
docker run -d \
  --name jenkins-tomcat \
  -p 8080:8080 \
  -v $(pwd)/jenkins.war:/usr/local/tomcat/webapps/jenkins.war \
  tomcat:10
```

## 2.7 升级与迁移

### 2.7.1 备份策略

在升级前，强烈建议进行完整备份。

#### 备份内容

1. **Jenkins Home 目录**：包含所有配置、插件、历史数据
2. **配置文件**：`config.xml`、`jobs/`、`users/` 等
3. **秘密文件**：`secrets/` 目录下的密钥文件

#### 备份脚本示例

```bash
#!/bin/bash
# backup-jenkins.sh

# 配置
JENKINS_HOME=/var/lib/jenkins
BACKUP_DIR=/backup/jenkins
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_FILE="$BACKUP_DIR/jenkins_backup_$DATE.tar.gz"

# 创建备份目录
mkdir -p $BACKUP_DIR

# 停止 Jenkins（可选，不停止也可备份）
# systemctl stop jenkins

# 执行备份
echo "Starting Jenkins backup at $DATE"
tar -czf $BACKUP_FILE \
  --exclude='workspace' \
  --exclude='builds' \
  --exclude='*.log' \
  -C $JENKINS_HOME .

# 上传备份到远程存储（可选）
# rclone copy $BACKUP_FILE remote:backups/jenkins/

# 清理旧备份（保留最近 30 天）
find $BACKUP_DIR -name "jenkins_backup_*.tar.gz" -mtime +30 -delete

echo "Backup completed: $BACKUP_FILE"
ls -lh $BACKUP_FILE
```

### 2.7.2 Windows 升级

#### 方法一：使用安装包升级

1. 下载最新版本的 `jenkins.msi`
2. 停止 Jenkins 服务
3. 运行安装包，选择相同的安装目录
4. 选择"升级"选项
5. 完成安装后启动服务

#### 方法二：手动替换 WAR 文件

```powershell
# 1. 停止 Jenkins 服务

# 2. 备份旧版本
Copy-Item "C:\Program Files\Jenkins\jenkins.war" "C:\Program Files\Jenkins\jenkins.war.bak"

# 3. 下载新版本
Invoke-WebRequest -Uri "https://get.jenkins.io/war-stable/latest/jenkins.war" -OutFile "C:\Program Files\Jenkins\jenkins.war"

# 4. 启动 Jenkins 服务
net start Jenkins

# 5. 查看日志确认升级成功
Get-Content "C:\Program Files\Jenkins\jenkins.out.log" -Tail 50 -Wait
```

## 2.8 目录结构说明

理解 Jenkins 的目录结构对于故障排查和日常维护非常重要。

### 2.8.1 Jenkins Home 目录

Jenkins Home 目录（默认：`~/.jenkins`）是 Jenkins 存储所有数据的中心位置。

```
~/.jenkins/
├── config.xml                 # 主配置文件
├── jenkins.install.InstallUtil.lastExecVersion  # 安装版本记录
├── jenkins.install.UpgradeWizard.state  # 升级状态
├── secrets/                   # 密钥目录（重要）
│   ├── hudson.util.Secret    # 加密密钥
│   ├── master.key            # 主密钥
│   └── initialAdminPassword  # 初始管理员密码
├── plugins/                  # 插件目录
│   ├── plugin-name/
│   │   ├── META-INF/
│   │   ├── webapp/
│   │   └── id
│   └── ...
├── war/                      # Web 应用解压目录
├── jobs/                     # 任务目录
│   ├── job-name/
│   │   ├── config.xml       # 任务配置
│   │   ├── builds/          # 构建记录
│   │   │   ├── 1/
│   │   │   ├── 2/
│   │   │   └── ...
│   │   ├── workspace/        # 工作空间
│   │   └── ...
│   └── ...
├── users/                   # 用户目录
├── userContent/             # 用户上传的文件
├── logs/                     # 日志目录
│   ├── tasks/              # 任务日志
│   └── ...
├── cache/                   # 缓存目录
├── war/                     # WAR 文件解压目录
└── updates/                 # 更新目录
    └── default.json         # 可用更新列表
```

### 2.8.2 配置文件详解

#### config.xml（主配置）

```xml
<?xml version='1.1' encoding='UTF-8'?>
<hudson>
  <version>2.462</version>
  <numExecutors>2</numExecutors>           <!-- 执行器数量 -->
  <mode>EXCLUSIVE</mode>                    <!-- 模式：EXCLUSIVE/NORMAL -->
  <numRetention>10</numRetention>          <!-- 构建保留数量 -->
  <systemMessage>Jenkins CI Server</systemMessage>  <!-- 系统消息 -->

  <!-- 视图配置 -->
  <views>
    <hudson.model.AllView>
      <owner class="hudson.model.Hudson" reference=".."/>
      <name>all</name>
      <filterExecutors>false</filterExecutors>
      <filterQueue>false</filterQueue>
      <properties class="hudson.model.View$PropertyList"/>
    </hudson.model.AllView>
  </views>

  <primaryView>all</primaryView>           <!-- 默认视图 -->

  <slaveAgentPort>50000</slaveAgentPort>   <!-- Agent 通信端口 -->
  <disableRememberMe>false</disableRememberMe>

  <!-- 全局安全配置 -->
  <security>
    <hudson.security.AuthorizationMatrixProperty>
      <!-- 权限矩阵 -->
    </hudson.security.AuthorizationMatrixProperty>
  </security>

  <!-- 全局工具配置 -->
  <globalLibraries>...</globalLibraries>
  <proxy>...</proxy>

  <!-- 邮件通知配置 -->
  <hudson.tasks.Mailer>
    <SMTPHost>smtp.example.com</SMTPHost>
    <SMTPPort>587</SMTPPort>
    <useSMTPSSL>false</useSMTPSSL>
  </hudson.tasks.Mailer>

</hudson>
```

#### jobs 目录结构

```
jobs/
├── job-name/
│   ├── config.xml           # 任务核心配置
│   ├── builds/              # 构建历史
│   │   ├── 1/               # 第 1 次构建
│   │   │   ├── build.xml    # 构建信息
│   │   │   ├── log          # 构建日志
│   │   │   └── workflow/    # Pipeline 相关
│   │   ├── 2/
│   │   │   └── ...
│   │   └── lastStable/      # 指向最后稳定构建的软链接
│   │   └── lastSuccessful/  # 指向最后成功构建的软链接
│   ├── workspace/           # 工作空间（源代码检出目录）
│   │   └── ...
│   ├── modules/             # 模块目录
│   ├── scm-polling.log     # SCM 轮询日志
│   └── .lastBuild.old      # 最后的构建目录备份
└── ...
```

### 2.8.3 日志文件说明

| 日志文件 | 说明 |
|----------|------|
| `var/log/jenkins/jenkins.log` | 主日志文件（Linux） |
| `C:\Program Files\Jenkins\jenkins.out.log` | 主日志文件（Windows） |
| `logs/tasks/` | 异步任务日志 |
| `jobs/<job-name>/builds/<N>/log` | 特定构建的日志 |

### 2.8.4 插件目录结构

```
plugins/
├── plugin-name/
│   ├── META-INF/
│   │   └── manifest.mf           # 插件清单
│   ├── webapp/
│   │   ├── index.jelly           # 主页
│   │   └── ...                   # 静态资源
│   ├── id                        # 插件 ID
│   ├── SKIP-SERIALIZED-DATA      # 跳过序列化数据检查标记
│   └── depends                   # 依赖列表
├── plugin-dependency/
└── ...
```

### 2.9.1 解锁 Jenkins

首次访问 Jenkins 时，系统会要求输入初始管理员密码。

#### 获取初始密码

```bash
# Linux
cat /var/lib/jenkins/secrets/initialAdminPassword

# Windows
type C:\Program Files\Jenkins\secrets\initialAdminPassword

# Docker
docker exec jenkins cat /var/jenkins_home/secrets/initialAdminPassword
```

#### 解锁步骤

1. 打开浏览器访问 `http://your-server:8080`
2. 会看到 "Unlock Jenkins" 页面
3. 复制密码文件中的内容粘贴到输入框
4. 点击 "Continue"

## 2.10 常见问题排查

### 2.10.1 安装后白屏

**原因**：Java 版本不兼容或插件冲突

**解决方案**：
```bash
# 1. 检查 Java 版本
java -version

# 2. 确保 Java 17+
# 3. 清理浏览器缓存
# 4. 清除插件缓存
rm -rf /var/lib/jenkins/plugins/*.bak
rm -rf /var/lib/jenkins/cache/*
systemctl restart jenkins
```

### 2.10.2 端口被占用

**问题**：8080 端口被其他程序占用

**解决方案**：
```bash
# Linux: 查找占用端口的进程
lsof -i:8080
netstat -tlnp | grep 8080

# Windows: 查找端口占用
netstat -ano | findstr :8080
```

### 2.10.3 权限问题

**问题**：无法创建文件或目录

**解决方案**：
```bash
# Linux: 修复 Jenkins Home 权限
chown -R jenkins:jenkins /var/lib/jenkins
chmod -R 755 /var/lib/jenkins

# Windows: 以管理员身份运行
```

### 2.10.4 内存不足

**问题**：Jenkins 频繁崩溃或 OOM

**解决方案**：

编辑启动参数增加内存：

```bash
# Linux (systemd)
# 编辑 /etc/default/jenkins 或 /etc/systemd/system/jenkins.service
JAVA_ARGS="-Xmx4096m -Xms1024m"

# Docker
docker run -d -e JAVA_OPTS="-Xmx4096m" jenkins/jenkins:lts
```
