# 第8章：自动化测试集成

## 8.1 概述

自动化测试是持续集成和持续交付流程中的核心环节，它能够及时发现代码缺陷、保证软件质量，并防止 regression（回归错误）。本章将详细介绍如何在 Jenkins 中集成各类测试工具，实现全面的自动化测试体系。

### 8.1.1 测试金字塔

在讨论具体实现之前，我们需要理解测试金字塔模型，这是指导测试策略的重要理论框架。

```
                    ┌───────────────┐
                    │   UI 测试     │        端到端、浏览器自动化
                    │   (少量)      │        覆盖核心用户流程
                   ┌┴───────────────┴┐
                   │   集成测试       │       API 交互、服务间通信
                   │   (适量)        │       组件协作验证
                  ┌┴─────────────────┴┐
                  │    单元测试       │       业务逻辑、边界条件
                  │    (大量)        │       快速反馈、高覆盖率
                 ┌┴───────────────────┴┐
                 │                     │
                 └─────────────────────┘
```

**示例测试类：**

```java
package com.example.calculator;

import org.junit.jupiter.api.*;
import org.junit.jupiter.params.ParameterizedTest;
import org.junit.jupiter.params.provider.CsvSource;
import org.junit.jupiter.params.provider.ValueSource;
import org.junit.jupiter.api.DisplayName;

import java.time.Duration;

import static org.assertj.core.api.Assertions.*;
import static org.junit.jupiter.api.Assertions.*;

/**
 * 计算器服务的单元测试
 */
@DisplayName("计算器服务测试")
class CalculatorServiceTest {

    private CalculatorService calculator;

    @BeforeEach
    void setUp() {
        calculator = new CalculatorService();
    }

    @Nested
    @DisplayName("加法运算测试")
    class AdditionTests {

        @Test
        @DisplayName("两个正整数相加应返回正确结果")
        void addTwoPositiveIntegers() {
            int result = calculator.add(2, 3);
            assertThat(result).isEqualTo(5);
        }

        @Test
        @DisplayName("负数加正数应返回正确结果")
        void addNegativeAndPositive() {
            int result = calculator.add(-5, 3);
            assertThat(result).isEqualTo(-2);
        }

        @ParameterizedTest
        @CsvSource({
            "1, 2, 3",
            "0, 0, 0",
            "-1, -1, -2",
            "100, 200, 300"
        })
        @DisplayName("参数化测试：多组加法数据")
        void parameterizedAddition(int a, int b, int expected) {
            assertEquals(expected, calculator.add(a, b));
        }
    }

    @Nested
    @DisplayName("除法运算测试")
    class DivisionTests {

        @Test
        @DisplayName("正常除法应返回正确结果")
        void divideTwoNumbers() {
            int result = calculator.divide(10, 2);
            assertEquals(5, result);
        }

        @Test
        @DisplayName("除以零应抛出 ArithmeticException")
        void divideByZeroShouldThrow() {
            assertThrows(ArithmeticException.class, () -> calculator.divide(10, 0));
        }
    }

    @Test
    @DisplayName("性能测试：运算应在100ms内完成")
    void performanceTest() {
        assertTimeout(Duration.ofMillis(100), () -> {
            for (int i = 0; i < 1000; i++) {
                calculator.add(i, i);
            }
        });
    }

    @AfterEach
    void tearDown() {
        calculator = null;
    }
}
```

### 8.2.3 测试报告自定义

#### 进阶配置：自定义测试报告生成

**自定义报告生成器：**

```java
package com.example.report;

import org.junit.platform.engine.*;
import org.junit.platform.engine.support.descriptor.*;
import org.junit.platform.launcher.*;
import org.junit.platform.launcher.listeners.*;
import java.io.*;
import java.nio.file.*;
import java.time.*;
import java.time.format.DateTimeFormatter;
import java.util.*;

/**
 * 自定义 JUnit 5 报告生成器
 * 输出 JSON 格式的测试结果，供 Jenkins 解析使用
 */
public class CustomTestReportGenerator implements TestExecutionListener {
    
    private static final DateTimeFormatter FORMATTER = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
    private final List<TestResult> results = new ArrayList<>();
    private TestResult currentResult;
    
    @Override
    public void executionStarted(TestIdentifier testIdentifier) {
        currentResult = new TestResult();
        currentResult.setTestId(testIdentifier.getUniqueId());
        currentResult.setDisplayName(testIdentifier.getDisplayName());
        currentResult.setType(testIdentifier.getType().toString());
        currentResult.setStartTime(LocalDateTime.now());
    }
    
    @Override
    public void executionFinished(TestIdentifier testIdentifier, TestExecutionResult result) {
        if (currentResult != null) {
            currentResult.setEndTime(LocalDateTime.now());
            currentResult.setDuration(
                Duration.between(currentResult.getStartTime(), currentResult.getEndTime()).toMillis()
            );
            
            if (result.getStatus() == TestExecutionResult.Status.SUCCESSFUL) {
                currentResult.setStatus("PASSED");
            } else if (result.getStatus() == TestExecutionResult.Status.FAILED) {
                currentResult.setStatus("FAILED");
                result.getThrowable().ifPresent(t -> currentResult.setErrorMessage(t.getMessage()));
            } else {
                currentResult.setStatus("SKIPPED");
            }
            
            results.add(currentResult);
            currentResult = null;
        }
    }
    
    public void writeReport(Path outputPath) throws IOException {
        Map<String, Object> report = new LinkedHashMap<>();
        report.put("timestamp", LocalDateTime.now().format(FORMATTER));
        report.put("totalTests", results.size());
        report.put("passed", results.stream().filter(r -> "PASSED".equals(r.getStatus())).count());
        report.put("failed", results.stream().Filter(r -> "FAILED".equals(r.getStatus())).count());
        report.put("skipped", results.stream().filter(r -> "SKIPPED".equals(r.getStatus())).count());
        report.put("testResults", results);
        
        ObjectMapper mapper = new ObjectMapper();
        mapper.writerWithDefaultPrettyPrinter().writeValue(outputPath.toFile(), report);
    }
    
    static class TestResult {
        private String testId;
        private String displayName;
        private String type;
        private LocalDateTime startTime;
        private LocalDateTime endTime;
        private long duration;
        private String status;
        private String errorMessage;
        
        // Getters and Setters
        public String getTestId() { return testId; }
        public void setTestId(String testId) { this.testId = testId; }
        public String getDisplayName() { return displayName; }
        public void setDisplayName(String displayName) { this.displayName = displayName; }
        public String getType() { return type; }
        public void setType(String type) { this.type = type; }
        public LocalDateTime getStartTime() { return startTime; }
        public void setStartTime(LocalDateTime startTime) { this.startTime = startTime; }
        public LocalDateTime getEndTime() { return endTime; }
        public void setEndTime(LocalDateTime endTime) { this.endTime = endTime; }
        public long getDuration() { return duration; }
        public void setDuration(long duration) { this.duration = duration; }
        public String getStatus() { return status; }
        public void setStatus(String status) { this.status = status; }
        public String getErrorMessage() { return errorMessage; }
        public void setErrorMessage(String errorMessage) { this.errorMessage = errorMessage; }
    }
}
```

### 8.3.3 Selenium 测试类实现

```java
package com.example.e2e;

import org.openqa.selenium.*;
import org.openqa.selenium.chrome.ChromeOptions;
import org.openqa.selenium.edge.EdgeOptions;
import org.openqa.selenium.firefox.FirefoxOptions;
import org.openqa.selenium.remote.RemoteWebDriver;
import org.openqa.selenium.support.ui.*;
import org.openqa.selenium.interactions.Actions;
import org.testng.annotations.*;
import org.testng.asserts.SoftAssert;

import java.net.URL;
import java.time.Duration;
import java.util.*;

import static org.assertj.core.api.Assertions.*;

/**
 * 端到端测试：用户登录流程
 */
public class LoginFlowTest {

    private RemoteWebDriver driver;
    private WebDriverWait wait;
    private Actions actions;
    
    // Jenkins 配置的 Selenium Grid URL
    private static final String SELENIUM_GRID_URL = System.getenv("SELENIUM_GRID_URL");
    
    @Parameters("browser")
    @BeforeMethod
    public void setUp(@Optional("chrome") String browser) throws MalformedURLException {
        WebDriver driver;
        
        switch (browser.toLowerCase()) {
            case "chrome":
                ChromeOptions chromeOptions = new ChromeOptions();
                chromeOptions.addArguments("--start-maximized");
                chromeOptions.addArguments("--disable-notifications");
                chromeOptions.addArguments("--no-sandbox");
                chromeOptions.addArguments("--disable-dev-shm-usage");
                chromeOptions.setAcceptInsecureCerts(true);
                if (SELENIUM_GRID_URL != null) {
                    driver = new RemoteWebDriver(new URL(SELENIUM_GRID_URL), chromeOptions);
                } else {
                    driver = new ChromeDriver(chromeOptions);
                }
                break;
            case "firefox":
                FirefoxOptions firefoxOptions = new FirefoxOptions();
                firefoxOptions.addArguments("--start-maximized");
                if (SELENIUM_GRID_URL != null) {
                    driver = new RemoteWebDriver(new URL(SELENIUM_GRID_URL), firefoxOptions);
                } else {
                    driver = new FirefoxDriver(firefoxOptions);
                }
                break;
            default:
                throw new IllegalArgumentException("Unsupported browser: " + browser);
        }
        
        this.driver = (RemoteWebDriver) driver;
        this.wait = new WebDriverWait(this.driver, Duration.ofSeconds(20));
        this.actions = new Actions(this.driver);
    }
    
    @Test(description = "用户登录成功测试")
    public void testSuccessfulLogin() {
        SoftAssert softAssert = new SoftAssert();
        
        // 1. 打开登录页面
        driver.get("https://demo.example.com/login");
        
        // 2. 输入用户名
        WebElement usernameField = wait.until(
            ExpectedConditions.visibilityOfElementLocated(By.id("username"))
        );
        usernameField.clear();
        usernameField.sendKeys("testuser@example.com");
        
        // 3. 输入密码
        WebElement passwordField = driver.findElement(By.id("password"));
        passwordField.clear();
        passwordField.sendKeys("SecurePass123!");
        
        // 4. 点击登录按钮
        WebElement loginButton = driver.findElement(By.xpath("//button[@type='submit']"));
        loginButton.click();
        
        // 5. 验证登录成功
        WebElement dashboardTitle = wait.until(
            ExpectedConditions.visibilityOfElementLocated(By.cssSelector(".dashboard-title"))
        );
        
        softAssert.assertEquals(dashboardTitle.getText(), "Welcome, Test User");
        softAssert.assertTrue(
            driver.getCurrentUrl().contains("/dashboard"),
            "URL should contain /dashboard"
```

```groovy
// 等待 Selenium Grid 就绪的函数
def waitForSeleniumGrid() {
    int maxAttempts = 30
    int attempt = 0
    while (attempt < maxAttempts) {
        try {
            def response = httpRequest(url: 'http://selenium-hub:4444/wd/hub/status')
            if (response.status == 200) {
                def json = readJSON(text: response.content)
                if (json.value.ready) {
                    echo "Selenium Grid is ready"
                    return
                }
            }
        } catch (Exception e) {
            echo "Waiting for Selenium Grid... attempt ${attempt + 1}"
        }
        sleep 2
        attempt++
    }
    error "Selenium Grid did not become ready in time"
}
```

```scala
package com.example.performance

import io.gatling.core.Predef._
import io.gatling.http.Predef._
import scala.concurrent.duration._

class LoginSimulation extends Simulation {
    
    // 配置
    val baseUrl = System.getProperty("baseUrl", "https://api.example.com")
    val threadCount = Integer.getInteger("threads", 100)
    val rampDuration = Integer.getInteger("ramp", 60).seconds
    val testDuration = Integer.getInteger("duration", 300).seconds
    
    // HTTP 配置
    val httpConfig = http
        .baseUrl(baseUrl)
        .acceptHeader("application/json")
        .contentTypeHeader("application/json")
        .header("User-Agent", "Gatling Performance Test")
        .connectionHeader("keep-alive")
        .responseInfoExtractor { response =>
            // 记录响应信息
            val status = response.status.code
            val bodySize = response.body.length
            List(s"Status: $status, Size: $bodySize bytes")
        }
    
    // 登录请求 feeder
    val loginFeeder = csv("user_credentials.csv").circular
    
    // 场景定义
    val scn = scenario("User Login Flow")
        // 1. 用户登录
        .feed(loginFeeder)
        .exec(
            http("Login API")
                .post("/api/v1/auth/login")
                .body(StringBody(session => {
                    s"""{"username":"${session("username").as[String]}",""" +
                    s""""password":"${session("password").as[String]}"}"""
                })).asJson
                .check(
                    status.is(200),
                    jsonPath("$.token").exists.saveAs("authToken"),
                    jsonPath("$.userId").exists.saveAs("userId")
                )
        )
        // 2. 携带 token 获取用户信息
        .exec(
            http("Get User Profile")
                .get("/api/v1/users/${userId}")
                .header("Authorization", "Bearer ${authToken}")
                .check(
                    status.is(200),
                    jsonPath("$.username").exists
                )
        )
        // 3. 获取资源列表
        .pause(100.millis, 200.millis) // 模拟用户思考时间
        .exec(
            http("List Resources")
                .get("/api/v1/resources")
                .header("Authorization", "Bearer ${authToken}")
                .queryParam("page", "1")
                .queryParam("size", "20")
                .check(
                    status.is(200),
                    jsonPath("$.items").exists
                )
        )
        // 4. 登出
        .exec(
            http("Logout")
                .post("/api/v1/auth/logout")
                .header("Authorization", "Bearer ${authToken}")
                .check(status.is(200))
        )
    
    // 场景设置
    setUp(
        scn.inject(
            rampUsers(threadCount).during(rampDuration)
        ).protocols(httpConfig)
    )
    .maxDuration(testDuration)
    .assertions(
        global.responseTime.percentile(95).lt(2000),
        global.responseTime.percentile(99).lt(3000),
        global.successfulRequests.percent.gt(95),
        global.allRequests.count.gt(1000)
    )
    .reports(
        "gatling-reports"
    )
}
```

```groovy
                            --reporter-json-export "%REPORT_DIR%/results.json" ^
                            --reporter-html-export "%REPORT_DIR%/report.html" ^
                            --reporter-html-title "API Test Report - ${params.ENVIRONMENT}" ^
                            --iteration-count %ITERATION_COUNT% ^
                            --environment "%envFile%" ^
                            --delay-request 100 ^
                            --timeout-request 5000 ^
                            --timeout-script 10000
                    """
                }
            }
            post {
                always {
                    // 归档测试结果
                    archiveArtifacts artifacts: 'target/newman-reports/**/*',
                                    fingerprint: true,
                                    allowEmptyArchive: true
                    
                    // 发布 HTML 报告
                    publishHTML([
                        allowMissing: false,
                        alwaysLinkToLastBuild: true,
                        keepAll: true,
                        reportDir: 'target/newman-reports',
                        reportFiles: 'report.html',
                        reportName: 'Postman API Test Report'
                    ])
                }
            }
        }
    }
    
    post {
        always {
            // 解析 Newman JSON 结果
            script {
                def resultFile = 'target/newman-reports/results.json'
                if (fileExists(resultFile)) {
                    def results = readJSON(file: resultFile)
                    
                    // 提取关键指标
                    def totalRequests = results.run.stats.requests.total
                    def passedRequests = results.run.stats.requests.ok
                    def failedRequests = results.run.stats.requests.failed
                    def avgResponseTime = results.run.timings.meanResponseTime
                    
                    echo "=== Postman API Test Results ==="
                    echo "Total Requests: ${totalRequests}"
                    echo "Passed: ${passedRequests}"
                    echo "Failed: ${failedRequests}"
                    echo "Avg Response Time: ${avgResponseTime}ms"
                    
                    // 失败时设置构建状态
                    if (failedRequests > 0) {
                        currentBuild.result = 'UNSTABLE'
                    }
                }
            }
        }
```

### 8.8.2 自定义测试结果 Dashboard

```groovy
// 生成自定义测试 Dashboard
def generateTestDashboard() {
    def dashboard = [:]
    
    // 收集各类型测试结果
    def unitTestResults = null
    def integrationTestResults = null
    def apiTestResults = null
    
    // 读取 JUnit XML 文件
    def unitTestFile = 'target/surefire-reports/TEST-*.xml'
    if (fileExists(unitTestFile)) {
        unitTestResults = readXML(unitTestFile)
        dashboard['unitTests'] = [
            total: unitTestResults.testsuite.@tests.text().toInteger(),
            passed: unitTestResults.testsuite.@tests.text().toInteger() - 
                    unitTestResults.testsuite.@failures.text().toInteger(),
            failed: unitTestResults.testsuite.@failures.text().toInteger(),
            skipped: unitTestResults.testsuite.@skipped.text().toInteger(),
            duration: unitTestResults.testsuite.@time.text().toDouble()
        ]
    }
    
    // 计算趋势
    def previousBuilds = []
    for (int i = 1; i <= 10; i++) {
        def build = Hudson.instance.getItemByFullName(env.JOB_NAME).getBuildByNumber(env.BUILD_NUMBER - i)
        if (build) {
            previousBuilds.add(build)
        }
    }
    
    dashboard['trend'] = previousBuilds.collect { build ->
        def result = build.result
        def testResult = build.actions.find { it instanceof hudson.tasks.test.TestResultAction }
        return [
            number: build.number,
            result: result?.toString() ?: 'SUCCESS',
            testCount: testResult?.result?.totalCount ?: 0,
            failCount: testResult?.result?.failCount ?: 0
        ]
    }
    
    return dashboard
}

// 在 Pipeline 中使用
script {
    def dashboard = generateTestDashboard()
    
    // 输出 Dashboard JSON

    // 发布 Dashboard
    publishHTML([
        allowMissing: true,
        keepAll: true,
        reportDir: 'target',
        reportFiles: 'test-dashboard.json',
        reportName: 'Test Dashboard'
    ])
}
```

## 8.9 本章小结

本章详细介绍了 Jenkins 中各类自动化测试工具的集成方法：

### 核心要点

1. **单元测试集成**
   - JUnit 5 和 TestNG 提供标准化的测试结果
   - 通过 `junit` step 自动归档和展示测试报告
   - 使用参数化测试提高测试覆盖效率

2. **Selenium 浏览器测试**
   - 推荐使用 Selenium Grid 进行分布式测试
   - Docker Compose 可快速搭建测试环境
   - 截图和录制功能便于调试失败测试

3. **静态代码分析**
   - SonarQube 提供全面的代码质量分析
   - PMD、Checkstyle、SpotBugs 各有侧重
   - `recordIssues` 步骤统一管理分析结果

4. **代码覆盖率**
   - JaCoCo 和 Cobertura 可同时使用
   - 质量门配置确保覆盖率达标
   - HTML 报告便于人工审查

5. **性能测试**
   - JMeter 和 Gatling 分别适合不同场景
   - Performance 插件支持趋势分析
   - 阈值设置实现自动化质量门

6. **API 测试**
   - Postman/Newman 提供直观的 API 测试方式
   - SoapUI 适合复杂的企业级 Web Service
   - 环境变量支持多环境测试

### 最佳实践

1. **测试金字塔原则**：大量单元测试，少量集成测试，极少量端到端测试
2. **快速反馈**：单元测试应在分钟级完成，失败即停
3. **质量门禁**：覆盖率、静态分析阈值未达标不允许合并
4. **结果聚合**：统一报告格式，便于管理层查看
5. **测试隔离**：测试间不应有依赖关系，可并行执行
