# 第9章：自动化部署 CI/CD

## 9.1 概述

自动化部署是 CI/CD 流水线的最终环节，也是将代码从开发环境最终交付生产环境的核心流程。本章将详细介绍各种部署策略、部署工具的集成方式、以及完整的自动化部署流水线实现。

本章涵盖的主要内容：

- **部署策略**：蓝绿部署、灰度部署、金丝雀发布的原理与实现
- **部署方式**：SSH 远程部署、Docker 部署、Kubernetes 部署、Ansible 集成、Docker Compose 多容器部署
- **数据库迁移**：自动化数据库迁移脚本管理
- **部署安全**：部署确认流程与回滚机制
- **环境 promotion**：完整的环境 promotion 流程（dev -> staging -> prod）

---

## 9.2 部署策略详解

### 9.2.1 蓝绿部署（Blue-Green Deployment）

蓝绿部署是一种提供即时回滚能力的部署策略。系统维护两套完全相同的生产环境（蓝环境+绿环境），在任何时刻只有其中一个在线。本节详细讲解蓝绿部署的原理和 Jenkins 实现。

#### 原理说明

蓝绿部署的核心思想是预备两套完全等价的生产环境：一套是当前正在服务的"绿环境"（Blue），另一套是已经准备好的新版本环境称为"蓝环境"（Green）。在部署过程中，我们先将新版本部署到不接收流量的环境中，完成所有验证后，通过负载均衡器的切换，将流量一次性从旧环境切换到新环境。如果部署后出现问题，我们可以立即将流量切回旧环境，实现秒级回滚。

这种策略的优势非常明显：部署和回滚都是原子操作，不存在新旧版本共存的情况，因此不会出现数据库字段变更导致的兼容性问题。同时，由于切换是通过负载均衡器完成的，不存在服务下线时间窗口，用户体验非常平滑。然而，这种策略的劣势在于需要维护两套完全等价的环境，资源成本较高。

在实际项目中，蓝绿部署通常需要配合以下基础设施：

- 负载均衡器或反向代理（如 Nginx、HAProxy、AWS ALB 等）
- 两套完全独立的服务器/容器环境
- 共享的数据存储（数据库、分布式缓存等）
- 健康检查机制
- 自动化 DNS 或负载均衡切换脚本

#### Jenkins Pipeline 实现

```groovy
// Blue-Green Deployment Pipeline
pipeline {
    agent any

    parameters {
        string(name: 'BLUE_ENV_IP', defaultValue: '10.0.1.100', description: 'Blue环境IP地址')
        string(name: 'GREEN_ENV_IP', defaultValue: '10.0.1.200', description: 'Green环境IP地址')
        string(name: 'LOAD_BALANCER_IP', defaultValue: '10.0.1.50', description: '负载均衡器IP')
        string(name: 'APP_NAME', defaultValue: 'myapp', description: '应用名称')
        choice(name: 'AUTO_SWITCH', choices: ['true', 'false'], description: '部署后自动切换流量')
        choice(name: 'HEALTH_CHECK_TYPE', choices: ['http', 'tcp', 'none'], description: '健康检查类型')
    }

    environment {
        DEPLOY_TIMEOUT = '300'
        HEALTH_CHECK_INTERVAL = '10'
        HEALTH_CHECK_ATTEMPTS = '30'
        SWITCH_TIMEOUT = '60'
    }

    stages {
        stage('环境检查') {
            steps {
                script {
                    echo "=== 蓝绿部署环境检查 ==="
                    echo "Blue环境: ${params.BLUE_ENV_IP}"
                    echo "Green环境: ${params.GREEN_ENV_IP}"
                    echo "负载均衡器: ${params.LOAD_BALANCER_IP}"
                    
                    // 验证环境连通性
                    def blueReachable = sh(
                        script: "ping -c 2 ${params.BLUE_ENV_IP} > /dev/null 2>&1 && echo 'ok' || echo 'fail'",
                        returnStdout: true
                    ).trim()
                    def greenReachable = sh(
                        script: "ping -c 2 ${params.GREEN_ENV_IP} > /dev/null 2>&1 && echo 'ok' || echo 'fail'",
                        returnStdout: true
                    ).trim()
                    
                    if (blueReachable != 'ok' || greenReachable != 'ok') {
                        error "环境连通性检查失败，请检查网络配置"
                    }
                    echo "环境连通性检查通过"
                }
            }
        }

        stage('确定部署目标环境') {
            steps {
                script {
                    echo "=== 确定部署目标环境 ==="
                    
                    // 通过SSH检查当前Green环境的应用版本
                    def greenVersion = sshagent(credentials: ['ssh-deploy-key']) {
                        sh """
                            ssh -o StrictHostKeyChecking=no -o ConnectTimeout=10 \
                                deployer@${params.GREEN_ENV_IP} \
                                "cat /opt/${params.APP_NAME}/current/version.txt 2>/dev/null || echo 'unknown'"
                        """
                    }.trim()
                    
                    echo "Green环境(当前环境)版本: ${greenVersion}"
                    env.CURRENT_GREEN = 'true' // 假设Green是当前环境
                    
                    // 确定Blue环境为部署目标
                    env.DEPLOY_TARGET_IP = params.BLUE_ENV_IP
                    env.DEPLOY_TARGET_NAME = 'Blue'
                    echo "Blue环境将作为部署目标"
                }
            }
        }

        stage('预部署验证') {
            steps {
                script {
                    echo "=== 预部署验证 ==="
                    
                    // 1. 检查Blue环境是否空闲（未被使用）
                    def blueStatus = sshagent(credentials: ['ssh-deploy-key']) {
                        sh """
                            ssh -o StrictHostKeyChecking=no deployer@${params.DEPLOY_TARGET_IP} \
                                "systemctl is-active ${params.APP_NAME} 2>/dev/null || echo 'inactive'"
                        """
                    }.trim()
                    
                    if (blueStatus == 'active') {
                        error "Blue环境中的应用仍在运行，请先停止再部署"
                    }
                    echo "Blue环境状态: ${blueStatus} - 可以部署"
                    
                    // 2. 检查磁盘空间
                    def diskUsage = sshagent(credentials: ['ssh-deploy-key']) {
                        sh """
                            ssh -o StrictHostKeyChecking=no deployer@${params.DEPLOY_TARGET_IP} \
                                "df -h /opt/${params.APP_NAME} | tail -1 | awk '{print \$5}' | sed 's/%//'"
                        """
                    }.trim().toInteger()
                    
                    if (diskUsage > 85) {
                        error "Blue环境磁盘空间不足(${diskUsage}%)，请清理后重试"
                    }
                    echo "Blue环境磁盘使用率: ${diskUsage}% - 正常"
                }
            }
        }

        stage('备份当前环境') {
            steps {
                script {
                    echo "=== 备份Green环境 ==="
                    
                    def backupDir = "${env.BUILD_NUMBER}_${new Date().format('yyyyMMdd_HHmmss')}"
                    env.BACKUP_DIR = backupDir
                    
                    // 创建备份目录
                    sshagent(credentials: ['ssh-deploy-key']) {
                        sh """
                            ssh -o StrictHostKeyChecking=no deployer@${params.GREEN_ENV_IP} \
                                "mkdir -p /opt/${params.APP_NAME}/backups/${backupDir}"
                            
                            # 备份应用目录
                            ssh -o StrictHostKeyChecking=no deployer@${params.GREEN_ENV_IP} \
                                "cp -r /opt/${params.APP_NAME}/current /opt/${params.APP_NAME}/backups/${backupDir}/"
                            
                            # 备份配置文件
                            ssh -o StrictHostKeyChecking=no deployer@${params.GREEN_ENV_IP} \
                                "cp -r /opt/${params.APP_NAME}/config /opt/${params.APP_NAME}/backups/${backupDir}/ 2>/dev/null || true"
                            
                            # 备份日志
                            ssh -o StrictHostKeyChecking=no deployer@${params.GREEN_ENV_IP} \
                                "cp -r /var/log/${params.APP_NAME} /opt/${params.APP_NAME}/backups/${backupDir}/ 2>/dev/null || true"
                        """
                    }
                    
                    echo "Green环境已备份到: /opt/${params.APP_NAME}/backups/${backupDir}"
                }
            }
        }

        stage('部署到Blue环境') {
            steps {
                script {
                    echo "=== 部署应用到Blue环境 ==="
                    
                    def buildNumber = env.BUILD_NUMBER
                    def artifactUrl = "${env.BUILD_URL}artifact/${params.APP_NAME}-${buildNumber}.tar.gz"
                    
                    sshagent(credentials: ['ssh-deploy-key']) {
                        sh """
                            # 创建部署目录
                            ssh -o StrictHostKeyChecking=no deployer@${params.DEPLOY_TARGET_IP} \
                                "mkdir -p /opt/${params.APP_NAME}/releases/${buildNumber}"
                            
                            # 下载构建产物
                            ssh -o StrictHostKeyChecking=no deployer@${params.DEPLOY_TARGET_IP} \
                                "cd /opt/${params.APP_NAME}/releases/${buildNumber} && \
                                 curl -s -o ${params.APP_NAME}.tar.gz ${artifactUrl}"
                            
                            # 解压
                            ssh -o StrictHostKeyChecking=no deployer@${params.DEPLOY_TARGET_IP} \
                                "cd /opt/${params.APP_NAME}/releases/${buildNumber} && \
                                 tar -xzf ${params.APP_NAME}.tar.gz && \
                                 rm -f ${params.APP_NAME}.tar.gz"
                            
                            # 创建符号链接指向新版本
                            ssh -o StrictHostKeyChecking=no deployer@${params.DEPLOY_TARGET_IP} \
                                "ln -sfn /opt/${params.APP_NAME}/releases/${buildNumber} /opt/${params.APP_NAME}/current"
                            
                            # 写入版本信息
                            ssh -o StrictHostKeyChecking=no deployer@${params.DEPLOY_TARGET_IP} \
                                "echo '${buildNumber}' > /opt/${params.APP_NAME}/current/version.txt && \
                                 echo '${new Date().format('yyyy-MM-dd HH:mm:ss')}' >> /opt/${params.APP_NAME}/current/version.txt"
                        """
                    }
                    
                    echo "应用已部署到Blue环境: ${params.DEPLOY_TARGET_IP}"
                }
            }
        }

        stage('配置Blue环境') {
            steps {
                script {
                    echo "=== 配置Blue环境 ==="
                    
                    sshagent(credentials: ['ssh-deploy-key']) {
                        sh """
                            # 设置环境变量
                            ssh -o StrictHostKeyChecking=no deployer@${params.DEPLOY_TARGET_IP} \
                                "cp /opt/${params.APP_NAME}/config/env.template /opt/${params.APP_NAME}/current/.env"
                            
                            # 配置日志目录
                            ssh -o StrictHostKeyChecking=no deployer@${params.DEPLOY_TARGET_IP} \
                                "mkdir -p /var/log/${params.APP_NAME}"
                            
                            # 设置目录权限
                            ssh -o StrictHostKeyChecking=no deployer@${params.DEPLOY_TARGET_IP} \
                                "chown -R ${params.APP_NAME}:${params.APP_NAME} /opt/${params.APP_NAME}/current"
                        """
                    }
                    
                    echo "Blue环境配置完成"
                }
            }
        }

        stage('启动Blue环境应用') {
            steps {
                script {
                    echo "=== 启动Blue环境应用 ==="
                    
                    sshagent(credentials: ['ssh-deploy-key']) {
                        sh """
                            # 启动应用
                            ssh -o StrictHostKeyChecking=no deployer@${params.DEPLOY_TARGET_IP} \
                                "systemctl start ${params.APP_NAME}"
                            
                            # 等待应用启动
                            sleep 5
                            
                            # 检查应用状态
                            ssh -o StrictHostKeyChecking=no deployer@${params.DEPLOY_TARGET_IP} \
                                "systemctl is-active ${params.APP_NAME}"
                        """
                    }
                    
                    echo "Blue环境应用已启动"
                }
            }
        }

        stage('健康检查') {
            steps {
                script {
                    echo "=== 健康检查 ==="
                    
                    def healthCheckUrl = "http://${params.DEPLOY_TARGET_IP}:8080/health"
                    def attempts = 0
                    def maxAttempts = env.HEALTH_CHECK_ATTEMPTS.toInteger()
                    def interval = env.HEALTH_CHECK_INTERVAL.toInteger()
                    def isHealthy = false
                    
                    while (attempts < maxAttempts) {
                        attempts++
                        echo "健康检查尝试 ${attempts}/${maxAttempts}"
                        
                        def response = sh(
                            script: "curl -s -o /dev/null -w '%{http_code}' --connect-timeout 5 ${healthCheckUrl} || echo '000'",
                            returnStdout: true
                        ).trim()
                        
                        if (response == '200') {
                            isHealthy = true
                            echo "Blue环境健康检查通过 (HTTP 200)"
                            break
                        }
                        
                        echo "等待 ${interval} 秒后重试..."
                        sleep(interval)
                    }
                    
                    if (!isHealthy) {
                        error "健康检查失败，Blue环境未通过验证"
                    }
                }
            }
        }

        stage('预热Blue环境') {
            steps {
                script {
                    echo "=== 预热Blue环境 ==="
                    
                    // 模拟一些请求来预热JIT编译器和缓存
                    def warmupRequests = 100
                    def warmupUrl = "http://${params.DEPLOY_TARGET_IP}:8080/api/warmup"
                    
                    sh """
                        for i in \$(seq 1 ${warmupRequests}); do
                            curl -s -o /dev/null ${warmupUrl} &
                        done
                        wait
                        echo "预热请求已完成"
                    """
                    
                    echo "Blue环境预热完成"
                }
            }
        }

        stage('切换流量') {
            when {
                expression { return params.AUTO_SWITCH == 'true' }
            }
            steps {
                script {
                    echo "=== 切换流量到Blue环境 ==="
                    
                    // 更新负载均衡器配置
                    sh """
                        # 备份当前Nginx配置
                        cp /etc/nginx/conf.d/${params.APP_NAME}.conf /etc/nginx/conf.d/${params.APP_NAME}.conf.backup
                        
                        # 生成新的Nginx配置（切换到Blue）
                        cat > /etc/nginx/conf.d/${params.APP_NAME}.conf << 'EOF'
                            upstream ${params.APP_NAME}_backend {
                                server ${params.BLUE_ENV_IP}:8080;
                            }
                            
                            server {
                                listen 80;
                                server_name ${params.APP_NAME}.example.com;
                                
                                location / {
                                    proxy_pass http://${params.APP_NAME}_backend;
                                    proxy_set_header Host \$host;
                                    proxy_set_header X-Real-IP \$remote_addr;
                                    proxy_set_header X-Forwarded-For \$proxy_add_x_forwarded_for;
                                    proxy_set_header X-Forwarded-Proto \$scheme;
                                }
                            }
                        EOF
                        
                        # 测试配置
                        nginx -t
                        
                        # 重新加载Nginx
                        nginx -s reload
                        
                        echo "流量已切换到Blue环境"
                    """
                }
            }
        }

        stage('验证部署') {
            steps {
                script {
                    echo "=== 验证部署 ==="
                    
                    def verificationChecks = [
                        [name: '主站响应', url: "http://${params.APP_NAME}.example.com"],
                        [name: 'API响应', url: "http://${params.APP_NAME}.example.com/api/v1/health"],
                        [name: '静态资源', url: "http://${params.APP_NAME}.example.com/static/version.txt"]
                    ]
                    
                    def allPassed = true
                    for (check in verificationChecks) {
                        def response = sh(
                            script: "curl -s -o /dev/null -w '%{http_code}' --connect-timeout 10 ${check.url} || echo '000'",
                            returnStdout: true
                        ).trim()
                        
                        if (response == '200') {
                            echo "[OK] ${check.name}: 通过"
                        } else {
                            echo "[FAIL] ${check.name}: 失败 (HTTP ${response})"
                            allPassed = false
                        }
                    }
                    
                    if (!allPassed) {
                        error "部署验证失败，部分检查未通过"
                    }
                    
                    echo "所有验证检查通过"
                }
            }
        }
    }

    post {
        success {
            script {
                echo "=== 部署成功 ==="
                def deploymentInfo = """
                    部署成功！
                    时间: ${new Date().format('yyyy-MM-dd HH:mm:ss')}
                    构建号: ${env.BUILD_NUMBER}
                    部署环境: Blue (${params.BLUE_ENV_IP})
                    原环境: Green (${params.GREEN_ENV_IP})
                    备份目录: /opt/${params.APP_NAME}/backups/${env.BACKUP_DIR}
                """
                echo deploymentInfo
            }
        }
        
        failure {
            script {
                echo "=== 部署失败 ==="
                echo "正在执行自动回滚..."
                
                sh """
                    cp /etc/nginx/conf.d/${params.APP_NAME}.conf.backup /etc/nginx/conf.d/${params.APP_NAME}.conf
                    nginx -s reload
                    echo "已回滚到Green环境"
                """
            }
        }
        
        always {
            script {
                // 清理旧的备份（保留最近10个）
                sshagent(credentials: ['ssh-deploy-key']) {
                    sh """
                        ssh -o StrictHostKeyChecking=no deployer@${params.GREEN_ENV_IP} \
                            "cd /opt/${params.APP_NAME}/backups && \
                             ls -dt */ | tail -n +11 | xargs rm -rf 2>/dev/null || true"
                    """
                }
                echo "部署流水线执行完成"
            }
        }
    }
}
```

#### 回滚专用 Pipeline

```groovy
// Blue-Green 回滚 Pipeline
pipeline {
    agent any

    parameters {
        choice(name: 'ROLLBACK_TARGET', choices: ['Green', 'Blue'], description: '回滚目标环境')
        choice(name: 'BACKUP_SELECTION', choices: ['latest', 'previous', 'specific'], description: '选择备份')
        string(name: 'SPECIFIC_BACKUP_DIR', defaultValue: '', description: '指定备份目录（当选择specific时）')
        password(name: 'ROLLBACK_REASON', description: '回滚原因（必填）')
    }

    stages {
        stage('确认回滚信息') {
            steps {
                script {
                    echo "=== 回滚信息确认 ==="
                    echo "回滚目标: ${params.ROLLBACK_TARGET}"
                    echo "备份选择: ${params.BACKUP_SELECTION}"
                    echo "回滚原因: ${params.ROLLBACK_REASON}"
                    
                    def confirmed = input message: '确认回滚操作？',
                                        ok: '确认回滚',
                                        submitter: 'devops-admin',
                                        parameters: [
                                            choice(name: 'CONFIRM', choices: ['yes', 'no'], description: '确认执行回滚')
                                        ]
                    
                    if (confirmed.CONFIRM != 'yes') {
                        error "回滚操作已取消"
                    }
                }
            }
        }

        stage('确定备份目录') {
            steps {
                script {
                    def targetEnv = params.ROLLBACK_TARGET == 'Green' ? '10.0.1.200' : '10.0.1.100'
                    env.TARGET_IP = targetEnv
                    
                    def backupDir = ''
                    if (params.BACKUP_SELECTION == 'latest') {
                        backupDir = sh(
                            script: "ssh deployer@${targetEnv} 'ls -dt /opt/myapp/backups/*/ | head -1'",
                            returnStdout: true
                        ).trim()
                    } else if (params.BACKUP_SELECTION == 'previous') {
                        backupDir = sh(
                            script: "ssh deployer@${targetEnv} 'ls -dt /opt/myapp/backups/*/ | sed -n 2p'",
                            returnStdout: true
                        ).trim()
                    } else {
                        backupDir = "/opt/myapp/backups/${params.SPECIFIC_BACKUP_DIR}"
                    }
                    
                    env.ROLLBACK_BACKUP_DIR = backupDir
                    echo "将回滚到备份: ${backupDir}"
                }
            }
        }

        stage('停止应用') {
            steps {
                script {
                    echo "=== 停止应用 ==="
                    sshagent(credentials: ['ssh-deploy-key']) {
                        sh "ssh -o StrictHostKeyChecking=no deployer@${env.TARGET_IP} 'systemctl stop myapp'"
                    }
                    echo "应用已停止"
                }
            }
        }

        stage('恢复备份') {
            steps {
                script {
                    echo "=== 恢复备份到${params.ROLLBACK_TARGET}环境 ==="
                    sshagent(credentials: ['ssh-deploy-key']) {
                        sh """
                            ssh -o StrictHostKeyChecking=no deployer@${env.TARGET_IP} \
                                "rm -rf /opt/myapp/current && \
                                 cp -r ${env.ROLLBACK_BACKUP_DIR}/current /opt/myapp/current && \
                                 chown -R myapp:myapp /opt/myapp/current"
                        """
                    }
                    echo "备份已恢复"
                }
            }
        }

        stage('启动应用') {
            steps {
                script {
                    echo "=== 启动应用 ==="
                    sshagent(credentials: ['ssh-deploy-key']) {
                        sh """
                            ssh -o StrictHostKeyChecking=no deployer@${env.TARGET_IP} \
                                'systemctl start myapp && sleep 5 && systemctl is-active myapp'
                        """
                    }
                    echo "应用已启动"
                }
            }
        }

        stage('切换流量') {
            steps {
                script {
                    echo "=== 切换流量到${params.ROLLBACK_TARGET}环境 ==="
                    def targetIp = params.ROLLBACK_TARGET == 'Green' ? '10.0.1.200' : '10.0.1.100'
                    
                    sh """
                        cat > /etc/nginx/conf.d/myapp.conf << 'EOF'
                            upstream myapp_backend {
                                server ${targetIp}:8080;
                            }
                            
                            server {
                                listen 80;
                                server_name myapp.example.com;
                                
                                location / {
                                    proxy_pass http://myapp_backend;
                                    proxy_set_header Host \$host;
                                    proxy_set_header X-Real-IP \$remote_addr;
                                }
                            }
                        EOF
                        
                        nginx -t && nginx -s reload
                    """
                    
                    echo "流量已切换到${params.ROLLBACK_TARGET}环境"
                }
            }
        }

        stage('验证回滚') {
            steps {
                script {
                    sleep 10
                    def response = sh(
                        script: "curl -s -o /dev/null -w '%{http_code}' http://myapp.example.com/health",
                        returnStdout: true
                    ).trim()
                    
                    if (response != '200') {
                        error "回滚验证失败 (HTTP ${response})"
                    }
                    echo "回滚验证成功！"
                }
            }
        }
    }
}
```

### 9.2.2 灰度部署（Gayscale Deployment）

灰度部署是将新版本逐步推送到生产环境的策略，通过控制流量分配比例，在保证服务稳定性的前提下实现平滑升级。

#### 原理说明

灰度发布的核心思想是将新版本按照预设的比例或规则逐步暴露给用户，而不是一次性替换所有流量。在灰度发布过程中，我们可以：

- **流量比例控制**：通过负载均衡器将 5%、10%、50%、100% 的流量逐步切换到新版本
- **用户群体控制**：先让内部用户、VIP 用户、特定地区的用户体验新版本
- **功能开关控制**：在代码层面通过 feature flag 控制新功能的可见性
- **地域机房控制**：先在特定机房或地域部署新版本

#### Jenkins Pipeline 实现

```groovy
// Gayscale Deployment Pipeline
pipeline {
    agent any

    parameters {
        string(name: 'APP_NAME', defaultValue: 'myapp', description: '应用名称')
        string(name: 'NEW_VERSION', defaultValue: '', description: '新版本号')
        string(name: 'STAGE_INSTANCE_IP', defaultValue: '10.0.1.101', description: '灰度实例IP')
        string(name: 'PROD_INSTANCE_IPS', defaultValue: '10.0.1.201,10.0.1.202,10.0.1.203', description: '生产实例IP列表')
        choice(name: 'INITIAL_TRAFFIC_PERCENT', choices: ['5', '10', '20'], description: '初始流量百分比')
        choice(name: 'AUTO_PROMOTE', choices: ['true', 'false'], description: '是否自动提升流量')
        string(name: 'GRAYSCALE_STAGES', defaultValue: '5,10,30,50,100', description: '灰度阶段（逗号分隔）')
        string(name: 'STAGE_DELAY_MINUTES', defaultValue: '10', description: '每个阶段延迟（分钟）')
    }

    environment {
        CONFIG_FILE = '/etc/nginx/conf.d/myapp-gray.conf'
        ERROR_THRESHOLD = '2'
        LATENCY_THRESHOLD = '500'
    }

    stages {
        stage('部署新版本到灰度实例') {
            steps {
                script {
                    echo "=== 部署新版本到灰度实例 ==="
                    
                    def buildUrl = "${env.BUILD_URL}artifact/${params.APP_NAME}-${params.NEW_VERSION}.tar.gz"
                    
                    sshagent(credentials: ['ssh-deploy-key']) {
                        sh """
                            ssh -o StrictHostKeyChecking=no deployer@${params.STAGE_INSTANCE_IP} << 'EOF'
                                set -e
                                mkdir -p /opt/${params.APP_NAME}/releases/${params.NEW_VERSION}
                                cd /opt/${params.APP_NAME}/releases/${params.NEW_VERSION}
                                curl -s -o ${params.APP_NAME}.tar.gz '${buildUrl}'
                                tar -xzf ${params.APP_NAME}.tar.gz
                                rm -f ${params.APP_NAME}.tar.gz
                                ln -sfn /opt/${params.APP_NAME}/releases/${params.NEW_VERSION} /opt/${params.APP_NAME}/gray_current
                                echo '${params.NEW_VERSION}' > /opt/${params.APP_NAME}/gray_current/version.txt
                                echo "部署完成"
                            EOF
                        """
                    }
                }
            }
        }

        stage('启动灰度实例') {
            steps {
                script {
                    echo "=== 启动灰度实例 ==="
                    
                    sshagent(credentials: ['ssh-deploy-key']) {
                        sh """
                            ssh -o StrictHostKeyChecking=no deployer@${params.STAGE_INSTANCE_IP} \
                                "systemctl stop ${params.APP_NAME}-gray 2>/dev/null || true; \
                                 systemctl start ${params.APP_NAME}-gray && \
                                 sleep 5 && \
                                 systemctl is-active ${params.APP_NAME}-gray"
                        """
                    }
                }
            }
        }

        stage('灰度发布阶段') {
            steps {
                script {
                    echo "=== 开始灰度发布阶段 ==="
                    
                    def stages = params.GRAYSCALE_STAGES.split(',').collect { it.trim().toInteger() }
                    def delayMinutes = params.STAGE_DELAY_MINUTES.toInteger()
                    
                    for (stagePercent in stages) {
                        echo ""
                        echo "========== 灰度阶段: ${stagePercent}% =========="
                        
                        updateGrayWeight(stagePercent, params.STAGE_INSTANCE_IP, params.PROD_INSTANCE_IPS)
                        
                        if (stagePercent > (stages[0] as int)) {
                            echo "等待 ${delayMinutes} 分钟观察..."
                            sleep(delayMinutes * 60)
                        }
                        
                        if (!performMonitoringCheck()) {
                            echo "监控检查失败，触发自动回滚"
                            error "灰度发布失败"
                        }
                        
                        echo "阶段 ${stagePercent}% 通过"
                    }
                }
            }
        }

        stage('流量全量切换') {
            steps {
                script {
                    echo "=== 流量全量切换到新版本 ==="
                    
                    sh """
                        cat > /etc/nginx/conf.d/${params.APP_NAME}.conf << 'EOF'
                            upstream ${params.APP_NAME}_backend {
                                server ${params.STAGE_INSTANCE_IP}:8080;
                            }
                            
                            server {
                                listen 80;
                                server_name myapp.example.com;
                                
                                location / {
                                    proxy_pass http://${params.APP_NAME}_backend;
                                }
                            }
                        EOF
                        
                        nginx -t && nginx -s reload
                    """
                }
            }
        }
    }
}

// 辅助函数：更新灰度权重
def updateGrayWeight(int grayPercent, String stageIp, String prodIpsStr) {
    def prodIps = prodIpsStr.split(',').collect { it.trim() }
    def prodWeight = 100 - grayPercent
    def prodInstanceWeight = prodWeight / prodIps.size()
    
    sh """
        cat > ${env.CONFIG_FILE} << 'EOF'
            upstream ${params.APP_NAME}_all {
                server ${stageIp}:8080 weight=${grayPercent};
                ${prodIps.collect { "server ${it}:8080 weight=${prodInstanceWeight};" }.join('\n')}
            }
        EOF
        
        nginx -t && nginx -s reload
        echo "灰度权重已更新: 新版本 ${grayPercent}%, 旧版本 ${prodWeight}%"
    """
}

// 辅助函数：执行监控检查
def performMonitoringCheck() {
    // 模拟监控检查
    def errorRate = Math.random() * 1.5
    def latency = 100 + Math.random() * 100
    
    if (errorRate > env.ERROR_THRESHOLD.toDouble()) {
        echo "错误率过高: ${errorRate}%"
        return false
    }
    
    if (latency > env.LATENCY_THRESHOLD.toDouble()) {
        echo "延迟过高: ${latency}ms"
        return false
    }
    
    echo "监控检查通过 (错误率: ${errorRate}%, 延迟: ${latency}ms)"
    return true
}
```

### 9.2.3 金丝雀发布（Canary Release）

金丝雀发布是灰度发布的一种高级形式，核心思想是将新版本先部署到少数实例（"金丝雀"），观察其表现指标，如果指标正常则逐步扩大部署范围。

#### Jenkins Pipeline 实现

```groovy
// Canary Release Pipeline
pipeline {
    agent any

    parameters {
        string(name: 'APP_NAME', defaultValue: 'myapp', description: '应用名称')
        string(name: 'NEW_VERSION', defaultValue: '', description: '新版本号')
        string(name: 'CANARY_INSTANCES', defaultValue: '1', description: '初始金丝雀实例数量')
        string(name: 'TOTAL_INSTANCES', defaultValue: '10', description: '总实例数')
        string(name: 'ERROR_RATE_THRESHOLD', defaultValue: '1.0', description: '错误率阈值(%)')
        string(name: 'LATENCY_THRESHOLD_MS', defaultValue: '300', description: '延迟阈值(ms)')
        string(name: 'MIN_CANARY_TIME', defaultValue: '15', description: '金丝雀最少运行时间(分钟)')
        choice(name: 'AUTO_APPROVE', choices: ['true', 'false'], description: '指标正常时自动批准')
    }

    environment {
        PROMETHEUS_URL = 'http://prometheus.example.com'
    }

    stages {
        stage('初始化金丝雀部署') {
            steps {
                script {
                    echo "=== 初始化金丝雀部署 ==="
                    
                    env.CANARY_VERSION = params.NEW_VERSION
                    env.CANARY_PERCENT = 0
                    env.CANARY_INSTANCES_CURRENT = 0
                    
                    // 确定金丝雀实例IP列表
                    def allInstances = getInstanceIps(params.APP_NAME, params.TOTAL_INSTANCES.toInteger())
                    env.CANARY_INSTANCE_IPS = allInstances[0..params.CANARY_INSTANCES.toInteger()-1].join(',')
                    env.PROD_INSTANCE_IPS = allInstances[params.CANARY_INSTANCES.toInteger()..-1].join(',')
                    
                    echo "金丝雀实例: ${env.CANARY_INSTANCE_IPS}"
                    echo "生产实例: ${env.PROD_INSTANCE_IPS}"
                }
            }
        }

        stage('部署金丝雀实例') {
            steps {
                script {
                    echo "=== 部署金丝雀实例 ==="
                    
                    def canaryIps = env.CANARY_INSTANCE_IPS.split(',')
                    def buildUrl = "${env.BUILD_URL}artifact/${params.APP_NAME}-${params.CANARY_VERSION}.tar.gz"
                    
                    for (ip in canaryIps) {
                        deployToInstance(ip.trim(), params.CANARY_VERSION, buildUrl, 'canary')
                    }
                }
            }
        }

        stage('金丝雀测试阶段') {
            steps {
                script {
                    echo "=== 金丝雀测试阶段 ==="
                    
                    def testDuration = 0
                    def maxDuration = params.MIN_CANARY_TIME.toInteger() * 60
                    def checkInterval = 60
                    def allMetricsHealthy = false
                    
                    while (testDuration < maxDuration) {
                        sleep(checkInterval)
                        testDuration += checkInterval
                        
                        echo "累计测试时间: ${testDuration / 60} 分钟"
                        
                        def metrics = collectCanaryMetrics()
                        echo "当前指标: 错误率=${metrics.errorRate}%, 延迟P99=${metrics.latencyP99}ms"
                        
                        if (isMetricsHealthy(metrics)) {
                            echo "指标检查通过"
                            allMetricsHealthy = true
                            break
                        }
                    }
                    
                    if (!allMetricsHealthy) {
                        error "金丝雀测试阶段未能在 ${params.MIN_CANARY_TIME} 分钟内通过指标检查"
                    }
                }
            }
        }

        stage('全量部署准备') {
            steps {
                script {
                    if (params.AUTO_APPROVE != 'true') {
                        def userInput = input message: '金丝雀测试通过，是否继续全量部署？',
                                            ok: '确认全量部署',
                                            submitter: 'devops-lead',
                                            parameters: [
                                                choice(name: 'PROCEED', choices: ['yes', 'no'], description: '是否全量部署')
                                            ]
                        
                        if (userInput.PROCEED != 'yes') {
                            error "用户取消全量部署"
                        }
                    }
                }
            }
        }

        stage('全量部署') {
            steps {
                script {
                    echo "=== 全量部署到所有实例 ==="
                    
                    def allInstances = getInstanceIps(params.APP_NAME, params.TOTAL_INSTANCES.toInteger())
                    def buildUrl = "${env.BUILD_URL}artifact/${params.APP_NAME}-${params.CANARY_VERSION}.tar.gz"
                    
                    parallel allInstances.collectEntries { ip ->
                        ["deploy-${ip.replace('.', '-')}": {
                            deployToInstance(ip, params.CANARY_VERSION, buildUrl, 'prod')
                        }]
                    }
                }
            }
        }
    }

    post {
        success {
            echo "金丝雀发布成功！"
        }
        
        failure {
            echo "金丝雀发布失败，执行自动回滚..."
            rollbackCanary()
        }
    }
}

// 辅助函数：获取实例IP列表
def getInstanceIps(String appName, int count) {
    def baseIp = '10.0.1.'
    def startIndex = 100
    return (startIndex..startIndex + count - 1).collect { "${baseIp}${it}" }
}

// 辅助函数：部署到指定实例
def deployToInstance(String ip, String version, String buildUrl, String role) {
    sshagent(credentials: ['ssh-deploy-key']) {
        sh """
            ssh -o StrictHostKeyChecking=no -o ConnectTimeout=30 deployer@${ip} << 'EOF'
                set -e
                
                APP_NAME="${params.APP_NAME}"
                VERSION="${version}"
                
                sudo mkdir -p /opt/${APP_NAME}/releases/${VERSION}
                sudo mkdir -p /var/log/${APP_NAME}
                
                cd /opt/${APP_NAME}/releases/${VERSION}
                curl -s -o ${APP_NAME}.tar.gz "${buildUrl}"
                tar -xzf ${APP_NAME}.tar.gz
                rm -f ${APP_NAME}.tar.gz
                
                sudo chown -R ${APP_NAME}:${APP_NAME} /opt/${APP_NAME}/releases/${VERSION}
                sudo ln -sfn /opt/${APP_NAME}/releases/${VERSION} /opt/${APP_NAME}/${role}_current
                echo "${VERSION}" | sudo tee /opt/${APP_NAME}/${role}_current/version.txt
                
                sudo systemctl restart ${APP_NAME}-${role}
                echo "部署成功: ${ip} -> ${VERSION} (${role})"
            EOF
        """
    }
}

// 辅助函数：收集金丝雀指标
def collectCanaryMetrics() {
    return [
        errorRate: Math.random() * 0.5,
        latencyP99: 100 + Math.random() * 100,
        qps: 1000 + Math.random() * 500
    ]
}

// 辅助函数：检查指标是否健康
def isMetricsHealthy(def metrics) {
    def errorThreshold = params.ERROR_RATE_THRESHOLD.toDouble()
    def latencyThreshold = params.LATENCY_THRESHOLD_MS.toDouble()
    
    return metrics.errorRate < errorThreshold && metrics.latencyP99 < latencyThreshold
}

// 辅助函数：回滚金丝雀
def rollbackCanary() {
    echo "执行金丝雀回滚..."
    
    def canaryIps = env.CANARY_INSTANCE_IPS.split(',')
    for (ip in canaryIps) {
        sshagent(credentials: ['ssh-deploy-key']) {
            sh """
                ssh -o StrictHostKeyChecking=no deployer@${ip} \
                    "systemctl stop ${params.APP_NAME}-canary"
            """
        }
    }
}
```

### 9.2.4 部署策略对比

| 特性 | 蓝绿部署 | 灰度部署 | 金丝雀发布 |
|------|---------|---------|-----------|
| **资源需求** | 两套完整环境 | 额外灰度实例 | 少量金丝雀实例 |
| **部署速度** | 快（全量切换） | 较慢（渐进） | 慢（按指标决策） |
| **回滚速度** | 秒级 | 分钟级 | 自动/即时 |
| **风险控制** | 无风险窗口 | 风险可控 | 基于指标决策 |
| **适用场景** | 所有变更 | 大规模变更 | 高风险变更 |
| **用户影响** | 无感知 | 部分用户影响 | 极少量用户影响 |
| **监控要求** | 中等 | 较高 | 高 |
| **实现复杂度** | 中等 | 中等 | 较高 |

## 9.3 SSH 远程部署

SSH 远程部署是最基础也是最灵活的部署方式，适用于物理机、虚拟机以及没有容器化管理工具的场景。

### 完整的 SSH 部署 Pipeline

```groovy
// SSH 远程部署完整 Pipeline
pipeline {
    agent any

    parameters {
        string(name: 'DEPLOY_HOST', defaultValue: '10.0.1.100', description: '部署目标主机')
        string(name: 'DEPLOY_USER', defaultValue: 'deployer', description: '部署用户')
        string(name: 'DEPLOY_PATH', defaultValue: '/opt/myapp', description: '部署路径')
        choice(name: 'DEPLOY_STRATEGY', choices: ['rolling', 'restart', 'reload'], description: '部署策略')
    }

    environment {
        SSH_CREDENTIALS_ID = 'deploy-ssh-key'
        DEPLOY_TIMEOUT = '300'
        HEALTH_CHECK_TIMEOUT = '60'
    }

    stages {
        stage('前置验证') {
            steps {
                script {
                    echo "=== 前置验证 ==="
                    
                    def canConnect = sh(
                        script: "nc -z -w 5 ${params.DEPLOY_HOST} 22 && echo 'ok' || echo 'fail'",
                        returnStdout: true
                    ).trim()
                    
                    if (canConnect != 'ok') {
                        error "无法连接到目标主机 ${params.DEPLOY_HOST}:22"
                    }
                }
            }
        }

        stage('备份当前版本') {
            steps {
                script {
                    echo "=== 备份当前版本 ==="
                    
                    sshagent(credentials: [env.SSH_CREDENTIALS_ID]) {
                        sh """
                            ssh -o StrictHostKeyChecking=no ${params.DEPLOY_USER}@${params.DEPLOY_HOST} << 'EOF'
                                set -e
                                
                                if [ -d "${params.DEPLOY_PATH}/current" ]; then
                                    TIMESTAMP=$(date +%Y%m%d_%H%M%S)
                                    BACKUP_NAME="${BUILD_NUMBER}_backup_\${TIMESTAMP}"
                                    
                                    sudo cp -r ${params.DEPLOY_PATH}/current ${params.DEPLOY_PATH}/backups/\${BACKUP_NAME}
                                    sudo tar -czf ${params.DEPLOY_PATH}/backups/\${BACKUP_NAME}.tar.gz -C ${params.DEPLOY_PATH}/backups \${BACKUP_NAME}
                                    sudo rm -rf ${params.DEPLOY_PATH}/backups/\${BACKUP_NAME}
                                    
                                    echo "备份已创建: \${BACKUP_NAME}.tar.gz"
                                fi
                            EOF
                        """
                    }
                }
            }
        }

        stage('上传并部署') {
            steps {
                script {
                    echo "=== 上传并部署 ==="
                    
                    sshagent(credentials: [env.SSH_CREDENTIALS_ID]) {
                        sh """
                            scp -o StrictHostKeyChecking=no \
                                ${WORKSPACE}/build/myapp.tar.gz \
                                ${params.DEPLOY_USER}@${params.DEPLOY_HOST}:/tmp/myapp_${BUILD_NUMBER}.tar.gz
                            
                            ssh -o StrictHostKeyChecking=no ${params.DEPLOY_USER}@${params.DEPLOY_HOST} << 'EOF'
                                set -e
                                
                                sudo mkdir -p ${params.DEPLOY_PATH}/releases/${BUILD_NUMBER}
                                cd ${params.DEPLOY_PATH}/releases/${BUILD_NUMBER}
                                sudo cp /tmp/myapp_${BUILD_NUMBER}.tar.gz ./myapp.tar.gz
                                sudo tar -xzf myapp.tar.gz
                                sudo rm -f myapp.tar.gz
                                sudo chown -R myapp:myapp ${params.DEPLOY_PATH}/releases/${BUILD_NUMBER}
                                sudo ln -sfn ${params.DEPLOY_PATH}/releases/${BUILD_NUMBER} ${params.DEPLOY_PATH}/current
                                echo "${BUILD_NUMBER}" | sudo tee ${params.DEPLOY_PATH}/current/version.txt
                                rm -f /tmp/myapp_${BUILD_NUMBER}.tar.gz
                            EOF
                        """
                    }
                }
            }
        }

        stage('执行部署策略') {
            steps {
                script {
                    echo "=== 执行部署策略: ${params.DEPLOY_STRATEGY} ==="
                    
                    sshagent(credentials: [env.SSH_CREDENTIALS_ID]) {
                        sh """
                            ssh -o StrictHostKeyChecking=no ${params.DEPLOY_USER}@${params.DEPLOY_HOST} << 'EOF'
                                set -e
                                
                                case "${params.DEPLOY_STRATEGY}" in
                                    rolling)
                                        sudo systemctl stop myapp || true
                                        sleep 2
                                        sudo systemctl start myapp
                                        ;;
                                    restart)
                                        sudo systemctl restart myapp
                                        ;;
                                    reload)
                                        APP_PID=\$(pgrep -f "myapp")
                                        if [ -n "\${APP_PID}" ]; then
                                            sudo kill -HUP \${APP_PID}
                                        else
                                            sudo systemctl start myapp
                                        fi
                                        ;;
                                esac
                                
                                sleep 5
                                sudo systemctl is-active myapp
                            EOF
                        """
                    }
                }
            }
        }

        stage('健康检查') {
            steps {
                script {
                    echo "=== 健康检查 ==="
                    
                    def healthUrl = "http://${params.DEPLOY_HOST}:8080/health"
                    def attempts = 0
                    def maxAttempts = env.HEALTH_CHECK_TIMEOUT.toInteger() / 5
                    def isHealthy = false
                    
                    while (attempts < maxAttempts) {
                        attempts++
                        
                        def response = sh(
                            script: "curl -s -o /dev/null -w '%{http_code}' --connect-timeout 5 '${healthUrl}' || echo '000'",
                            returnStdout: true
                        ).trim()
                        
                        if (response == '200') {
                            isHealthy = true
                            break
                        }
                        
                        sleep(5)
                    }
                    
                    if (!isHealthy) {
                        error "健康检查失败"
                    }
                }
            }
        }
    }

    post {
        failure {
            script {
                echo "部署失败，尝试回滚..."
                
                sshagent(credentials: [env.SSH_CREDENTIALS_ID]) {
                    sh """
                        ssh -o StrictHostKeyChecking=no ${params.DEPLOY_USER}@${params.DEPLOY_HOST} << 'EOF'
                            set -e
                            
                            LATEST_BACKUP=\$(ls -t ${params.DEPLOY_PATH}/backups/*.tar.gz | head -1)
                            
                            if [ -n "\${LATEST_BACKUP}" ]; then
                                cd ${params.DEPLOY_PATH}
                                tar -xzf "\${LATEST_BACKUP}"
                                BACKUP_DIR=\$(basename "\${LATEST_BACKUP}" .tar.gz)
                                
                                sudo rm -rf ${params.DEPLOY_PATH}/current
                                sudo cp -r ${params.DEPLOY_PATH}/backups/\${BACKUP_DIR} ${params.DEPLOY_PATH}/current
                                sudo rm -rf ${params.DEPLOY_PATH}/backups/\${BACKUP_DIR}
                                sudo systemctl restart myapp
                            fi
                        EOF
                    """
                }
            }
        }
    }
}
```

### 多主机并行部署

```groovy
// 多主机并行部署 Pipeline
pipeline {
    agent any

    parameters {
        text(name: 'DEPLOY_HOSTS', defaultValue: '10.0.1.101\n10.0.1.102\n10.0.1.103', description: '部署目标主机列表')
        string(name: 'MAX_PARALLEL', defaultValue: '3', description: '最大并行数')
    }

    environment {
        SSH_CREDENTIALS_ID = 'deploy-ssh-key'
    }

    stages {
        stage('解析主机列表') {
            steps {
                script {
                    env.DEPLOY_HOST_LIST = params.DEPLOY_HOSTS.split('\n').collect { it.trim() }.findAll { it }
                    echo "待部署主机: ${env.DEPLOY_HOST_LIST.join(', ')}"
                }
            }
        }

        stage('并行部署') {
            steps {
                script {
                    def chunks = env.DEPLOY_HOST_LIST.collate(params.MAX_PARALLEL.toInteger())
                    
                    for (chunk in chunks) {
                        def deployments = [:]
                        for (host in chunk) {
                            deployments["deploy-${host}"] = {
                                deployToHost(host)
                            }
                        }
                        parallel deployments
                    }
                }
            }
        }

        stage('全局健康检查') {
            steps {
                script {
                    def allHealthy = true
                    for (host in env.DEPLOY_HOST_LIST) {
                        def response = sh(
                            script: "curl -s -o /dev/null -w '%{http_code}' http://${host}:8080/health || echo '000'",
                            returnStdout: true
                        ).trim()
                        
                        if (response != '200') {
                            echo "${host} 健康检查失败"
                            allHealthy = false
                        }
                    }
                    
                    if (!allHealthy) {
                        error "部分主机健康检查失败"
                    }
                }
            }
        }
    }
}
```

### Docker 部署脚本

```bash
#!/bin/bash
# docker-deploy.sh - Docker 部署脚本

set -e

APP_NAME=${APP_NAME:-myapp}
IMAGE=${IMAGE:-registry.example.com/myapp/myapp:latest}
CONTAINER_NAME=${CONTAINER_NAME:-$APP_NAME}
NETWORK=${NETWORK:-$APP_NAME-network}

RED='\\033[0;31m'
GREEN='\\033[0;32m'
YELLOW='\\033[1;33m'
NC='\\033[0m'

log_info() { echo -e "${GREEN}[INFO]${NC} $1"; }
log_warn() { echo -e "${YELLOW}[WARN]${NC} $1"; }
log_error() { echo -e "${RED}[ERROR]${NC} $1"; }

check_health() {
    local url=$1
    local max_attempts=${2:-30}
    local attempt=0
    
    while [ $attempt -lt $max_attempts ]; do
        if curl -sf "$url" > /dev/null 2>&1; then
            return 0
        fi
        attempt=$((attempt + 1))
        sleep 5
    done
    return 1
}

deploy() {
    log_info "开始部署 $APP_NAME"
    log_info "镜像: $IMAGE"
    
    # 拉取新镜像
    log_info "拉取新镜像..."
    docker pull "$IMAGE"
    
    # 创建网络
    log_info "创建网络..."
    docker network create "$NETWORK" 2>/dev/null || true
    
    # 停止旧容器
    log_info "停止旧容器..."
    if docker ps -a --format '{{.Names}}' | grep -q "^${CONTAINER_NAME}$"; then
        docker stop "$CONTAINER_NAME" 2>/dev/null || true
        docker rm "$CONTAINER_NAME" 2>/dev/null || true
    fi
    
    # 启动新容器
    log_info "启动新容器..."
    docker run -d \
        --name "$CONTAINER_NAME" \
        --network "$NETWORK" \
        --restart unless-stopped \
        -p 8080:8080 \
        -e SPRING_PROFILES_ACTIVE="${SPRING_PROFILES:-prod}" \
        --health-cmd="curl -f http://localhost:8080/actuator/health || exit 1" \
        --health-interval=30s \
        --health-retries=3 \
        "$IMAGE"
    
    # 等待健康检查
    log_info "等待健康检查..."
    if check_health "http://localhost:8080/actuator/health" 60; then
        log_info "容器启动成功"
    else
        log_error "健康检查失败"
        docker logs "$CONTAINER_NAME" --tail 100
        exit 1
    fi
    
    log_info "部署完成！"
}

rollback() {
    log_warn "开始回滚..."
    docker stop "$CONTAINER_NAME" 2>/dev/null || true
    docker rm "$CONTAINER_NAME" 2>/dev/null || true
    log_info "回滚完成"
}

case "${1:-deploy}" in
    deploy) deploy ;;
    rollback) rollback ;;
    *) echo "用法: $0 {deploy|rollback}" ;;
esac
```

```yaml
# ansible/playbooks/deploy.yml
---
- name: Deploy Application
  hosts: app_servers
  gather_facts: yes
  become: yes
  
  vars:
    app_name: myapp
    deploy_path: /opt/{{ app_name }}
    backup_path: /opt/{{ app_name }}/backups
    current_link: "{{ deploy_path }}/current"
    release_dir: "{{ deploy_path }}/releases/{{ build_number }}"
    
  tasks:
    - name: Include environment variables
      include_vars:
        file: "vars/{{ deploy_env }}.yml"
    
    - name: Create deployment directories
      file:
        path: "{{ item }}"
        state: directory
        owner: "{{ app_user }}"
        group: "{{ app_user }}"
        mode: '0755'
      loop:
        - "{{ deploy_path }}"
        - "{{ deploy_path }}/releases"
        - "{{ deploy_path }}/backups"
        - "{{ backup_path }}"
    
    - name: Backup current release
      when: symlink.stat.exists
      block:
        - name: Create backup directory
          file:
            path: "{{ backup_path }}/{{ backup_name }}"
            state: directory
        
        - name: Copy current release to backup
          synchronize:
            src: "{{ current_link }}/"
            dest: "{{ backup_path }}/{{ backup_name }}/"
            delete: yes
            recursive: yes
        
        - name: Compress backup
          archive:
            path: "{{ backup_path }}/{{ backup_name }}"
            dest: "{{ backup_path }}/{{ backup_name }}.tar.gz"
            format: gz
            remove: yes
        
        - name: Clean old backup
          file:
            path: "{{ backup_path }}/{{ item }}"
            state: absent
          loop: "{{ old_backups }}"
          when: old_backups | length > keep_backups|int
    
    - name: Download build artifact
      get_url:
        url: "{{ artifact_url }}"
        dest: "/tmp/{{ app_name }}-{{ build_number }}.tar.gz"
        mode: '0644'
    
    - name: Extract artifact
      unarchive:
        src: "/tmp/{{ app_name }}-{{ build_number }}.tar.gz"
        dest: "{{ release_dir }}"
        remote_src: yes
        creates: "{{ release_dir }}/{{ app_name }}"
    
    - name: Update symlink
      file:
        src: "{{ release_dir }}"
        dest: "{{ current_link }}"
        state: link
        force: yes
    
    - name: Set permissions
      file:
        path: "{{ deploy_path }}/current"
        owner: "{{ app_user }}"
        group: "{{ app_user }}"
        recurse: yes
    
    - name: Restart application
      systemd:
        name: "{{ app_name }}"
        state: restarted
        daemon_reload: yes
    
    - name: Wait for application to be ready
      uri:
        url: "http://{{ ansible_host }}:8080/health"
        status_code: 200
      register: health_check
      retries: 30
      delay: 5
      until: health_check is succeeded
    
    - name: Verify deployment
      uri:
        url: "http://{{ ansible_host }}:8080/api/v1/version"
        status_code: 200
      register: version_check
    
    - name: Display deployment info
      debug:
        msg:
          - "Deployment completed successfully"
          - "Version: {{ version_check.json.version }}"
          - "Build: {{ build_number }}"
    
    - name: Cleanup temp files
      file:
        path: "/tmp/{{ app_name }}-{{ build_number }}.tar.gz"
        state: absent
```

```sql
-- V8__migration_for_release.sql
-- 为新版本发布准备的迁移脚本
-- 注意：这个迁移需要配合应用代码的回滚能力

BEGIN;

-- 添加新字段用于支持分批迁移
ALTER TABLE app.orders ADD COLUMN IF NOT EXISTS new_customer_id BIGINT;
ALTER TABLE app.orders ADD COLUMN IF NOT EXISTS migration_status VARCHAR(20) DEFAULT 'pending';

-- 创建索引（使用 CONCURRENTLY 避免锁表）
CREATE INDEX CONCURRENTLY idx_orders_new_customer_id ON app.orders(new_customer_id) WHERE new_customer_id IS NOT NULL;

-- 数据迁移（分批处理）
DO $$
DECLARE
    batch_size INT := 10000;
    offset_val INT := 0;
    total_migrated INT := 0;
    max_id INT;
BEGIN
    -- 获取最大 ID
    SELECT COALESCE(MAX(id), 0) INTO max_id FROM app.orders;
    
    -- 分批迁移数据
    WHILE offset_val <= max_id LOOP
        UPDATE app.orders 
        SET new_customer_id = customer_id,
            migration_status = 'completed',
            updated_at = CURRENT_TIMESTAMP
        WHERE id IN (
            SELECT id FROM app.orders 
            WHERE id > offset_val AND id <= offset_val + batch_size
            AND migration_status = 'pending'
            AND customer_id IS NOT NULL
        );
        
        GET DIAGNOSTICS total_migrated = ROW_COUNT;
        
        IF total_migrated < batch_size THEN
            EXIT;
        END IF;
        
        offset_val := offset_val + batch_size;
        
        -- 每批之间休息一下，避免对数据库造成太大压力
        PERFORM pg_sleep(0.1);
    END LOOP;
    
    RAISE NOTICE 'Migration completed. Total records processed: %', offset_val + total_migrated;
END $$;

-- 添加约束
ALTER TABLE app.orders 
    ADD CONSTRAINT fk_orders_customer_new 
    FOREIGN KEY (new_customer_id) 
    REFERENCES app.customers(id) 
    DEFERRABLE INITIALLY DEFERRED;

-- 删除旧字段（需要在应用代码完全切换后执行）
-- ALTER TABLE app.orders DROP COLUMN IF EXISTS old_customer_id;

COMMIT;

-- 记录迁移版本
INSERT INTO app.schema_migrations (version, description, installed_on)
VALUES ('8', 'Release migration for new features', CURRENT_TIMESTAMP)
ON CONFLICT (version) DO NOTHING;
```

### 回滚脚本

```sql
-- R__rollback_V8.sql
-- V8 迁移的回滚脚本

BEGIN;

-- 移除新添加的约束
ALTER TABLE app.orders DROP CONSTRAINT IF EXISTS fk_orders_customer_new;

-- 移除索引
DROP INDEX IF EXISTS idx_orders_new_customer_id;

-- 移除新增的字段
```

```groovy
                    """
                }
            }
```

## 9.9 环境 Promotion（dev->staging->prod）

环境 promotion 是将经过验证的构建在多个环境中逐步推进的流程，确保每次部署都经过适当的测试和审批。

### 完整的 Promotion Pipeline

```groovy
// 环境 Promotion Pipeline
pipeline {
    agent any

    parameters {
        string(name: 'BUILD_VERSION', defaultValue: '', description: '要 Promotion 的构建版本')
        choice(name: 'PROMOTION_PATH', choices: ['dev->staging', 'staging->production', 'dev->staging->production'], description: 'Promotion 路径')
        choice(name: 'AUTO_PROMOTE', choices: ['true', 'false'], description: '是否自动推进')
    }

    environment {
        PROMOTION_TIMEOUT = 3600 // 秒
    }

    stages {
        stage('验证构建版本') {
            steps {
                script {
                    echo "=== 验证构建版本 ==="
                    
                    if (!params.BUILD_VERSION) {
                        // 如果未指定版本，使用最新的成功构建
                        env.BUILD_VERSION = getLatestSuccessfulBuild()
                    }
                    
                    echo "Promotion 版本: ${env.BUILD_VERSION}"
                    
                    // 验证构建是否存在
                    def buildExists = verifyBuildExists(env.BUILD_VERSION)
                    if (!buildExists) {
                        error "构建版本 ${env.BUILD_VERSION} 不存在"
                    }
                    
                    // 验证构建是否通过所有测试
                    def testPassed = verifyAllTestsPassed(env.BUILD_VERSION)
                    if (!testPassed) {
                        error "构建版本 ${env.BUILD_VERSION} 未通过所有测试"
                    }
                }
            }
        }

        stage('环境检查') {
            steps {
                script {
                    echo "=== 环境可用性检查 ==="
                    
                    def environments = getPromotionEnvironments(params.PROMOTION_PATH)
                    
                    for (envName in environments) {
                        def isReady = checkEnvironmentReady(envName)
                        if (!isReady) {
                            error "环境 ${envName} 不可用"
                        }
                        echo "✓ ${envName} 就绪"
                    }
                }
            }
        }

        stage('Promotion 到 Dev') {
            when {
                expression { return params.PROMOTION_PATH.contains('dev') }
            }
            steps {
                script {
                    echo "=== Promotion 到 Dev 环境 ==="
                    
                    // 部署到 Dev
                    deployToEnvironment('dev', env.BUILD_VERSION)
                    
                    // Dev 环境健康检查
                    verifyEnvironmentHealth('dev')
                    
                    // 等待一段时间观察
                    echo "在 Dev 环境观察 5 分钟..."
                    sleep(5 * 60)
                    
                    // Dev 环境功能验证
                    verifyEnvironmentFunctionality('dev')
                }
            }
        }

        stage('Dev 环境审批') {
            when {
                expression { return params.PROMOTION_PATH.contains('dev') && params.PROMOTION_PATH.contains('staging') }
            }
            steps {
                script {
                    echo "=== Dev 环境审批 ==="
                    
                    if (params.AUTO_PROMOTE != 'true') {
                        def userInput = input message: 'Dev 环境验证通过，是否推进到 Staging？',
                                            ok: '确认推进',
                                            submitter: 'dev-lead',
                                            parameters: [
                                                choice(name: 'PROCEED', choices: ['yes', 'no', 'rollback'], description: '操作选择')
                                            ]
                        
                        switch (userInput.PROCEED) {
                            case 'yes':
                                echo "继续推进到 Staging"
                                break
                            case 'no':
                                echo "暂停 Promotion，等待进一步指示"
                                break
                            case 'rollback':
                                error "用户要求回滚"
                                break
                        }
                    }
                }
            }
        }

        stage('Promotion 到 Staging') {
            when {
                expression { return params.PROMOTION_PATH.contains('staging') }
            }
            steps {
                script {
                    echo "=== Promotion 到 Staging 环境 ==="
                    
                    // 部署到 Staging
                    deployToEnvironment('staging', env.BUILD_VERSION)
                    
                    // Staging 环境健康检查
                    verifyEnvironmentHealth('staging')
                    
                    // 等待一段时间观察
                    echo "在 Staging 环境观察 10 分钟..."
                    sleep(10 * 60)
                    
                    // Staging 环境功能验证
                    verifyEnvironmentFunctionality('staging')
                    
                    // 性能测试
                    runPerformanceTests('staging')
                }
            }
        }

        stage('Staging 环境审批') {
            when {
                expression { return params.PROMOTION_PATH.contains('staging') && params.PROMOTION_PATH.contains('production') }
            }
            steps {
                script {
                    echo "=== Staging 环境审批 ==="
                    
                    if (params.AUTO_PROMOTE != 'true') {
                        def userInput = input message: 'Staging 环境验证通过，是否推进到 Production？',
                                            ok: '确认推进',
                                            submitter: 'prod-manager',
                                            parameters: [
                                                choice(name: 'PROCEED', choices: ['yes', 'no', 'rollback'], description: '操作选择')
                                            ]
                        
                        switch (userInput.PROCEED) {
                            case 'yes':
                                echo "继续推进到 Production"
                                break
                            case 'no':
                                echo "暂停 Promotion，等待进一步指示"
                                break
                            case 'rollback':
                                error "用户要求回滚"
                                break
                        }
                    }
                }
            }
        }

        stage('Promotion 到 Production') {
            when {
                expression { return params.PROMOTION_PATH.contains('production') }
            }
            steps {
                script {
                    echo "=== Promotion 到 Production 环境 ==="
                    
                    // 选择部署策略
                    def deploymentStrategy = selectDeploymentStrategy()
                    
                    // 部署到 Production
                    deployToEnvironmentWithStrategy('production', env.BUILD_VERSION, deploymentStrategy)
                    
                    // Production 环境健康检查
                    verifyEnvironmentHealth('production')
                }
            }
        }

        stage('Production 最终验证') {
            when {
                expression { return params.PROMOTION_PATH.contains('production') }
            }
            steps {
                script {
                    echo "=== Production 最终验证 ==="
                    
                    // 等待服务完全就绪
                    sleep(60)
                    
                    // 全面健康检查
                    verifyEnvironmentHealth('production')
                    
                    // 关键业务功能验证
                    verifyCriticalBusinessFunctions('production')
                    
                    // 监控检查
                    checkMonitoringMetrics('production')
                }
            }
        }

        stage('生成 Promotion 报告') {
            steps {
                script {
                    echo "=== 生成 Promotion 报告 ==="
                    
                    def report = generatePromotionReport()
                    
                    echo report
                    
                    // 保存报告
                    archiveArtifacts artifacts: 'promotion-report.txt', allowEmptyArchive: true
                }
            }
        }
    }

    post {
        success {
            echo "Promotion 流程成功完成！"
            
            // 发送成功通知
            slackSend channel: '#deployments',
                      color: 'good',
                      message: """
                          *Promotion 成功！*
                          版本: ${env.BUILD_VERSION}
                          路径: ${params.PROMOTION_PATH}
                      """
            
            mail to: 'devops@example.com,product@example.com',
                 subject: "[Promotion 成功] ${env.BUILD_VERSION}",
                 body: "Promotion 成功完成\n版本: ${env.BUILD_VERSION}\n路径: ${params.PROMOTION_PATH}"
        }
        
        failure {
            echo "Promotion 流程失败！"
            
            // 发送失败通知
            slackSend channel: '#deployments',
                      color: 'danger',
                      message: """
                          *Promotion 失败！*
                          版本: ${env.BUILD_VERSION}
                          失败阶段: ${currentBuild.currentStage ?: 'unknown'}
                      """
        }
    }
}
```

## 9.10 最佳实践

### 10.1 部署安全最佳实践

1. **代码签名**：在部署前验证所有构建产物的签名
2. **镜像扫描**：使用 Trivy 或其他工具扫描容器镜像漏洞
3. **密钥管理**：使用 HashiCorp Vault 或 AWS Secrets Manager 管理敏感信息
4. **网络隔离**：生产环境与其他环境网络隔离
5. **审计日志**：记录所有部署操作的审计日志

### 10.2 部署性能最佳实践

1. **并行部署**：使用 parallel 阶段加速多主机部署
2. **增量部署**：只部署变更的部分
3. **本地缓存**：利用本地镜像缓存减少拉取时间
4. **预热机制**：部署后预热应用避免冷启动

### 10.3 部署稳定性最佳实践

1. **健康检查**：配置合理的健康检查阈值
2. **优雅关闭**：确保应用能够优雅处理关闭信号
3. **连接排空**：负载均衡器支持连接排空
4. **多次验证**：部署后多次验证确保稳定性

### 10.4 监控和告警

```groovy
// 部署后监控
stage('部署后监控') {
    steps {
        script {
            echo "=== 部署后监控 ==="
            
            def monitoringDuration = 600 // 10分钟
            def checkInterval = 30
            def elapsed = 0
            def metricsHistory = []
            
            while (elapsed < monitoringDuration) {
                sleep(checkInterval)
                elapsed += checkInterval
                
                def metrics = collectDeploymentMetrics()
                metricsHistory << metrics
                
                // 检查异常指标
                if (hasAnomaly(metrics)) {
                    echo "检测到异常指标，触发告警"
                    sendAlert(metrics)
                }
                
                echo "监控进度: ${elapsed}/${monitoringDuration}秒"
            }
            
            // 生成监控报告
            def report = generateMonitoringReport(metricsHistory)
            echo report
        }
    }
}

// 收集部署指标
def collectDeploymentMetrics() {
    return [
        errorRate: Math.random() * 0.5,
        latencyP99: 100 + Math.random() * 50,
        cpuUsage: 30 + Math.random() * 30,
        memoryUsage: 40 + Math.random() * 30,
        requestCount: 1000 + Math.random() * 500
    ]
}

// 检查异常
def hasAnomaly(def metrics) {
    return metrics.errorRate > 1.0 || metrics.latencyP99 > 200
}

// 发送告警
def sendAlert(def metrics) {
    slackSend channel: '#alerts',
              color: 'danger',
              message: """
                  *部署告警！*
                  错误率: ${metrics.errorRate}%
                  P99延迟: ${metrics.latencyP99}ms
              """
}

// 生成监控报告
def generateMonitoringReport(List history) {
    def avgErrorRate = history.collect { it.errorRate }.average()
    def avgLatency = history.collect { it.latencyP99 }.average()
    
    return """
        监控报告
        --------
        平均错误率: ${avgErrorRate}%
        平均延迟: ${avgLatency}ms
        监控时长: ${history.size() * 30}秒
    """
}
```
