## 教程特色

### 1. 全景式业务建模
从**供应商 → 采购 → 生产 → 仓储 → 库存 → 订单 → 运输 → 配送 → 退货**的完整链路，覆盖 15 大业务域、40+ 系统模块。

### 2. 行业实践导向
- **京东**：自营一体化供应链、亚洲一号自动化仓
- **亚马逊**：FBA、Kiva 机器人、Anticipatory Shipping
- **Zara**：极速供应链、2 周从设计到门店
- **SHEIN**：柔性供应链 + 小单快反
- **菜鸟**：平台化、智慧仓配
- **沃尔玛**：CPFR 协同补货
- **美团/饿了么**：即时配送、众包
- **苹果**：多级供应商管理

### 3. 完整代码示例
86+ 个代码块，覆盖：
- 状态机引擎
- 库存预占（Redis Lua）
- 三单匹配
- 寻比价算法
- VRP 路径规划
- 蚁群算法
- LSTM 销量预测
- 强化学习补货
- 多 AGV 调度
- 数字孪生仿真

### 4. 5 层架构全景
```
┌─────────────────────────────────────┐
│ 决策层：控制塔 / 大屏 / 预警 / BI     │
├─────────────────────────────────────┤
│ 智能层：ML 预测 / 运筹优化 / LLM      │
├─────────────────────────────────────┤
│ 计划层：S&OP / 补货 / 排产 / 仿真     │
├─────────────────────────────────────┤
│ 执行层：SRM / OMS / WMS / TMS / IMS  │
├─────────────────────────────────────┤
│ 感知层：IoT / RFID / PDA / 摄像头     │
└─────────────────────────────────────┘
```

## 学习路径建议

### 🚀 快速入门（1-2 周）
1. 第 1 章：建立供应链全局视野
2. 第 4 章 OMS：理解订单流转
3. 第 5 章 WMS：理解仓库作业
4. 第 6 章 IMS：理解库存计算

### 💼 求职面试（2-3 周）
重点学习：
- 第 1 章（牛鞭效应、四大流）
- 第 3 章（三单匹配、TCO）
- 第 4 章（防超卖、状态机）
- 第 6 章（ATP、安全库存）
- 第 8 章（VRP、运费计算）

### 🔧 系统设计实战（4-6 周）
- 全章节系统学习
- 完成每章末尾的"面试高频问题"自测
- 模拟设计一个中等规模供应链系统

### 🏗️ 架构师视角（6-8 周）
- 重点：第 11-15 章
- 决策引擎、数字孪生、协同中台、全球化架构
