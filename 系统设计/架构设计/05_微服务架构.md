## 1. 微服务架构概述

### 1.1 什么是微服务架构

微服务架构（Microservices Architecture）是一种将应用程序拆分为一组小型、自治服务的软件架构风格。每个服务运行在独立的进程中，通过轻量级通信机制（通常是HTTP REST API或消息队列）进行交互。每个服务围绕特定业务领域构建，可以独立部署、扩展和更新。

### 2.2 核心维度对比表

| 对比维度 | 单体架构 | 微服务架构 |
|---------|---------|-----------|
| **代码组织** | 单一代码库 | 多个独立代码库 |
| **部署方式** | 整体部署 | 独立部署 |
| **扩展方式** | 垂直扩展（复制整个应用） | 水平扩展（按需扩展单个服务） |
| **数据库** | 共享单一数据库 | 每个服务独立数据库 |
| **开发团队** | 大型团队 | 小型自治团队 |
| **技术栈** | 统一技术栈 | 可混合技术栈 |
| **部署复杂度** | 低 | 高 |
| **运维复杂度** | 低 | 高 |
| **故障隔离** | 差（单点故障） | 好（服务隔离） |
| **可扩展性** | 差 | 好 |
| **开发速度** | 早期快，后期慢 | 持续快速 |

## 3. 微服务设计原则

### 3.1 单一职责原则（SRP）

每个微服务只负责一个业务功能域，具有明确的边界和职责。

```mermaid

    subgraph "不当拆分"
        B1["用户+订单+商品+支付+库存"]

    end

    subgraph "正确拆分"
        G1["用户服务"]
        G2["订单服务"]

        G4["支付服务"]
        G5["库存服务"]
    end

    B1 -->|"按职责拆分"| Good
```

**示例代码：Java Spring Boot**

```java
// 用户服务 - 单一职责：只处理用户相关业务
@Service
@Transactional
public class UserService {
    
    private final UserRepository userRepository;
    private final UserMapper userMapper;
    
    public UserService(UserRepository userRepository, UserMapper userMapper) {
        this.userRepository = userRepository;
        this.userMapper = userMapper;
    }
    
    public UserDTO createUser(CreateUserRequest request) {
        // 只处理用户创建逻辑
        validateUserRequest(request);
        User user = userMapper.toEntity(request);
        return userMapper.toDTO(userRepository.save(user));
    }
    
    public UserDTO getUserById(Long id) {
        return userRepository.findById(id)
            .map(userMapper::toDTO)
            .orElseThrow(() -> new UserNotFoundException(id));
    }
    
    public Page<UserDTO> searchUsers(UserSearchCriteria criteria) {
        // 只处理用户搜索逻辑
        return userRepository.search(criteria)
            .map(userMapper::toDTO);
    }
}
```

```java
// 订单服务 - 单一职责：只处理订单相关业务
@Service
@Transactional
public class OrderService {
    
    private final OrderRepository orderRepository;
    private final OrderMapper orderMapper;
    private final ProductClient productClient;  // 外部调用
    private final PaymentClient paymentClient;  // 外部调用
    
    public OrderDTO createOrder(CreateOrderRequest request) {
        // 订单创建逻辑
        validateOrderRequest(request);
        
        // 调用商品服务校验库存
        productClient.verifyInventory(request.getItems());
        
        Order order = orderMapper.toEntity(request);
        order.setStatus(OrderStatus.PENDING);
        
        return orderMapper.toDTO(orderRepository.save(order));
    }
    
    public OrderDTO updateOrderStatus(Long orderId, OrderStatus status) {
        // 只处理订单状态更新
        Order order = orderRepository.findById(orderId)
            .orElseThrow(() -> new OrderNotFoundException(orderId));
        
        order.setStatus(status);
        return orderMapper.toDTO(orderRepository.save(order));
    }
}
```

```java
// 领域层 - 核心业务逻辑（独立于基础设施）
package com.ecommerce.order.domain;

public class Order {
    
    private OrderId id;
    private CustomerId customerId;
    private List<OrderItem> items;
    private OrderStatus status;
    private Money totalAmount;
    private ShippingAddress shippingAddress;
    
    // 工厂方法 - 确保聚合根创建的一致性
    public static Order create(CustomerId customerId, ShippingAddress address) {
        Order order = new Order();
        order.id = OrderId.generate();
        order.customerId = customerId;
        order.items = new ArrayList<>();
        order.status = OrderStatus.DRAFT;
        order.shippingAddress = address;
        order.totalAmount = Money.ZERO;
        return order;
    }
    
    // 聚合根的业务方法 - 确保业务规则不被违反
    public void addItem(ProductId productId, Money price, int quantity) {
        if (this.status != OrderStatus.DRAFT) {
            throw new OrderException("Cannot add items to non-draft order");
        }
        
        OrderItem item = OrderItem.create(productId, price, quantity);
        this.items.add(item);
        this.totalAmount = this.totalAmount.add(item.getSubtotal());
    }
    
    public void submit() {
        if (this.items.isEmpty()) {
            throw new OrderException("Cannot submit empty order");
        }
        this.status = OrderStatus.SUBMITTED;
        // 发布领域事件
        DomainEvents.publish(new OrderSubmittedEvent(this.id));
    }
    
    // Getters only - 保护内部状态
    public OrderId getId() { return id; }
    public OrderStatus getStatus() { return status; }
    public Money getTotalAmount() { return totalAmount; }
}

// 值对象
public class Money {
    private final BigDecimal amount;
    private final Currency currency;
    
    public Money add(Money other) {
        if (!this.currency.equals(other.currency)) {
            throw new IllegalArgumentException("Cannot add money with different currencies");
        }
        return new Money(this.amount.add(other.amount), this.currency);
    }
}
```

```java
// 应用层 - 编排领域对象和外部服务
package com.ecommerce.order.application;

@Service
public class OrderApplicationService {
    
    private final OrderRepository orderRepository;
    private final ProductService productService;  // 外部服务
    private final PaymentService paymentService;
    private final EventPublisher eventPublisher;
    
    @Transactional
    public OrderDTO createOrder(CreateOrderCommand command) {
        // 1. 创建订单聚合
        Order order = Order.create(
            CustomerId.of(command.getCustomerId()),
            ShippingAddress.of(command.getAddress())
        );
        
        // 2. 添加订单项
        for (OrderItemCommand item : command.getItems()) {
            // 调用商品服务获取价格
            Product product = productService.getProduct(item.getProductId());
            order.addItem(
                product.getId(),
                product.getPrice(),
                item.getQuantity()
            );
        }
        
        // 3. 提交订单
        order.submit();
        
        // 4. 保存
        orderRepository.save(order);
        
        // 5. 发布事件（异步处理库存扣减等）
        eventPublisher.publish(new OrderCreatedEvent(order));
        
        return OrderDTO.from(order);
    }
}
```

## 4. 微服务基础设施

### 4.1 服务注册与发现

服务注册与发现是微服务架构的核心基础设施，让服务能够动态感知其他服务的位置。

```mermaid
sequenceDiagram
    participant S1 as 服务提供者
    participant R as 注册中心
    participant S2 as 服务消费者
    participant GW as API网关
    
    S1->>R: 启动时注册服务 (IP:Port)
    R-->>S1: 注册成功
    S1->>R: 发送心跳维持注册
    R-->>S1: 确认心跳
    
    S2->>R: 查询服务列表
    R-->>S2: 返回可用服务地址
    S2->>S1: 发起服务调用
    
    S1->>R: 下线服务
    R-->>S1: 下线确认
    R-->>S2: 推送服务变更通知
```

**服务注册中心选择对比：**

| 特性 | Eureka | Consul | Nacos | etcd |
|-----|--------|--------|-------|------|
| **CAP理论** | AP | CP | CP/AP | CP |
| **多数据中心** | 支持 | 原生支持 | 支持 | 支持 |
| **健康检查** | 心跳 | TCP/HTTP | TCP/HTTP | TCP |
| **Kv存储** | 无 | 支持 | 支持 | 支持 |
| **成熟度** | 成熟(不再维护) | 成熟 | 成熟 | 成熟 |

**Consul 服务注册示例（Go）：**

```go
package main

import (
    "fmt"
    "net/http"
    "os"
    "time"
    
    "github.com/hashicorp/consul/api"
)

func main() {
    // 创建 Consul 客户端
    config := api.DefaultConfig()
    config.Address = os.Getenv("CONSUL_ADDR")
    client, err := api.NewClient(config)
    if err != nil {
        panic(err)
    }
    
    // 服务注册
    registration := &api.AgentServiceRegistration{
        ID:   "user-service-1",  // 唯一实例ID
        Name: "user-service",    // 服务名
        Tags: []string{"v1", "production"},
        Port: 8080,
        Address: getOutboundIP(),  // 自动获取IP
        Check: &api.AgentServiceCheck{
            HTTP: "http://localhost:8080/health",
            Interval: "10s",
            Timeout: "5s",
            DeregisterCriticalServiceAfter: "30s",
        },
        Meta: map[string]string{
            "version": "1.0.0",
            "region":  "us-east-1",
        },
    }
    
    if err := client.Agent().ServiceRegister(registration); err != nil {
        panic(err)
    }
    
    // 启动健康检查上报
    go heartbeat(client)
    
    <-make(chan struct{})
}

func heartbeat(client *api.Client) {
    ticker := time.NewTicker(5 * time.Second)
    for range ticker.C {
        // Consul 会自动调用健康检查端点
        // 这里可以手动更新服务元数据
        if err := client.Agent().UpdateTTL(
            "service:user-service-1",
            "ok",
            api.HealthPassing,
        ); err != nil {
            fmt.Printf("Failed to update heartbeat: %v\n", err)
        }
    }
}

func getOutboundIP() string {
    resp, _ := http.Get("https://api.ipify.org")
    defer resp.Body.Close()
    b := make([]byte, 20)
    resp.Read(b)
    return string(b)
}
```

```yaml
# application.yml
spring:
  application:
    name: api-gateway
  cloud:
    gateway:
      routes:
        # 用户服务路由
        - id: user-service
          uri: lb://user-service  # lb 表示负载均衡
          predicates:
            - Path=/api/users/**
          filters:
            - StripPrefix=1  # 去掉前缀
            - name: RequestRateLimiter
              args:
                redis-rate-limiter.replenishRate: 100
                redis-rate-limiter.burstCapacity: 200
            - name: CircuitBreaker
              args:
                name: userCircuitBreaker
                fallbackUri: forward:/fallback/user
        
        # 订单服务路由
        - id: order-service
          uri: lb://order-service
          predicates:
            - Path=/api/orders/**
          filters:
            - StripPrefix=1
            - name: Retry
```

```java
// 自定义网关过滤器
@Component
public class AuthenticationFilter implements GlobalFilter, Ordered {
    
    private final JwtService jwtService;
    private final UserServiceClient userService;
    
    public AuthenticationFilter(JwtService jwtService, UserServiceClient userService) {
        this.jwtService = jwtService;
        this.userService = userService;
    }
    
    @Override
    public Mono<Void> filter(ServerWebExchange exchange, GatewayFilterChain chain) {
        String path = exchange.getRequest().getPath().value();
        
        // 跳过公开路径
        if (isPublicPath(path)) {
            return chain.filter(exchange);
        }
        
        String authHeader = exchange.getRequest().getHeaders().getFirst("Authorization");
        
        if (authHeader == null || !authHeader.startsWith("Bearer ")) {
            exchange.getResponse().setStatusCode(HttpStatus.UNAUTHORIZED);
            return exchange.getResponse().setComplete();
        }
        
        String token = authHeader.substring(7);
        
        try {
            Claims claims = jwtService.validateToken(token);
            
            // 将用户信息添加到请求头
            ServerHttpRequest mutatedRequest = exchange.getRequest().mutate()
                .header("X-User-Id", claims.getSubject())
                .header("X-User-Role", claims.get("role", String.class))
                .build();
            
            return chain.filter(
                exchange.mutate().request(mutatedRequest).build()
            );
            
        } catch (JwtException e) {
            exchange.getResponse().setStatusCode(HttpStatus.UNAUTHORIZED);
            return exchange.getResponse().setComplete();
        }
    }
    
    private boolean isPublicPath(String path) {
        return path.startsWith("/api/auth/") ||
               path.startsWith("/api/public/") ||
               path.equals("/health");
    }
    
    @Override
    public int getOrder() {
        return -100;  // 优先级最高
    }
}
```

```java
    }
    
    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                    HttpServletResponse response,
                                    FilterChain chain) throws ServletException, IOException {
        try {
            // 从请求头获取或生成 traceId
            String traceId = request.getHeader("X-Trace-Id");
            if (traceId == null) {
                traceId = UUID.randomUUID().toString();
            }

            response.setHeader("X-Trace-Id", traceId);

        }
```

```java
            return orderProcessingTimer.record(() -> {
                // 订单处理逻辑

                orderCreatedCounter.increment();
                return result;
            });
        } catch (Exception e) {
            orderFailedCounter.increment();
            throw e;
        } finally {
            activeOrders.decrementAndGet();
        }
    }
```

```java
// gRPC 服务端
@GrpcService
public class UserGrpcService extends UserServiceGrpc.UserServiceImplBase {
    
    private final UserService userService;
    private final UserMapper userMapper;
    
    public UserGrpcService(UserService userService, UserMapper userMapper) {
        this.userService = userService;
        this.userMapper = userMapper;
    }
    
    @Override
    public void getUser(GetUserRequest request, StreamObserver<UserResponse> responseObserver) {
        try {
            UserDTO user = userService.getUserById(request.getUserId());
            responseObserver.onNext(userMapper.toProto(user));
            responseObserver.onCompleted();
        } catch (UserNotFoundException e) {
            responseObserver.onError(Status.NOT_FOUND
                .withDescription(e.getMessage())
                .asRuntimeException());
        }
    }
    
    @Override
    public void searchUsers(SearchUsersRequest request, StreamObserver<UserResponse> responseObserver) {
        // 服务端流式返回
        Page<UserDTO> users = userService.searchUsers(request.getQuery(), 
            PageRequest.of(0, request.getPageSize()));
        
        for (UserDTO user : users) {
            responseObserver.onNext(userMapper.toProto(user));
        }
        responseObserver.onCompleted();
    }
    
    @Override
    public StreamObserver<BatchGetUsersRequest> batchGetUsers(StreamObserver<BatchGetUsersResponse> responseObserver) {
        // 客户端流式处理
        List<UserDTO> users = new ArrayList<>();
        
        return new StreamObserver<BatchGetUsersRequest>() {
            @Override
            public void onNext(BatchGetUsersRequest request) {
                users.add(userService.getUserById(request.getUserId()));
            }
            
            @Override
            public void onError(Throwable t) {
                responseObserver.onError(t);
            }
            
            @Override
            public void onCompleted() {
                BatchGetUsersResponse.Builder builder = BatchGetUsersResponse.newBuilder();
                users.forEach(u -> builder.addUsers(userMapper.toProto(u)));
                responseObserver.onNext(builder.build());
                responseObserver.onCompleted();
            }
        };
    }
}
```

```java
@Service
public class OrderEventPublisher {

    public OrderEventPublisher(KafkaTemplate<String, OrderEvent> kafkaTemplate) {
        this.kafkaTemplate = kafkaTemplate;
    }
    
    public void publishOrderCreated(Order order) {
        OrderEvent event = OrderEvent.builder()
            .eventId(UUID.randomUUID().toString())
            .eventType("ORDER_CREATED")
            .orderId(order.getId())
            .customerId(order.getCustomerId())
            .items(order.getItems().stream()
                .map(this::toItemEvent)
                .collect(Collectors.toList()))
            .totalAmount(order.getTotalAmount())
            .timestamp(Instant.now())
            .build();

        kafkaTemplate.send("order-events", 
            order.getId().toString(), 
            event);
    }

        return OrderEvent.OrderItemEvent.builder()
            .productId(item.getProductId())
            .productName(item.getProductName())
            .quantity(item.getQuantity())
            .price(item.getPrice())
            .build();

// 消息消费者 - 库存服务
@Service
public class InventoryEventConsumer {
    
    private final InventoryService inventoryService;
    
    @KafkaListener(
        topics = "order-events",
        groupId = "inventory-service",
        containerFactory = "kafkaListenerContainerFactory"
    )
    public void handleOrderEvent(OrderEvent event) {
        if (!"ORDER_CREATED".equals(event.getEventType())) {
            return;
        }
        
        log.info("Received order event: {}", event.getEventId());
        
        try {
            // 扣减库存
            for (OrderEvent.OrderItemEvent item : event.getItems()) {
                inventoryService.reserveStock(
                    item.getProductId(),
                    item.getQuantity()
                );
            }
            log.info("Stock reserved for order: {}", event.getOrderId());
        } catch (InsufficientStockException e) {

            publishStockShortageEvent(event);

    }
```

```java
@Service
public class OrderSagaOrchestrator {
    
    private final OrderRepository orderRepository;
    private final ProductClient productClient;
    private final InventoryClient inventoryClient;
    private final PaymentClient paymentClient;
    private final EventPublisher eventPublisher;
    
    @Transactional
    public OrderDTO createOrderSaga(CreateOrderCommand command) {
        // 1. 创建订单（待支付状态）
        Order order = Order.create(command.getCustomerId(), command.getShippingAddress());
        
        // 2. 验证商品信息
        List<ProductInfo> products = productClient.getProducts(
            command.getItems().stream()
                .map(OrderItemCommand::getProductId)
                .collect(Collectors.toList())
        );
        
        // 3. 锁定库存
        InventoryLockResult lockResult = inventoryClient.lockStock(
            command.getItems().stream()
                .map(item -> new StockLock(
                    item.getProductId(),
                    item.getQuantity()
                ))
                .collect(Collectors.toList())
        );
        
        if (!lockResult.isSuccess()) {
            throw new InsufficientStockException(lockResult.getFailedProducts());
        }
        
        // 4. 计算价格
        Money totalAmount = calculateTotal(products, command.getItems());
        
        // 5. 创建订单
        command.getItems().forEach(item -> {
            ProductInfo product = findProduct(products, item.getProductId());
            order.addItem(product, item.getQuantity());
        });
        order.setTotalAmount(totalAmount);
        order.setInventoryLockId(lockResult.getLockId());
        
        order = orderRepository.save(order);
        
        // 6. 发布订单创建事件
        eventPublisher.publish(new OrderCreatedEvent(order.getId()));
        
        return toDTO(order);
    }
    
    // 补偿事务：释放库存
    public void compensateReleaseStock(Long orderId) {
        orderRepository.findById(orderId)
            .ifPresent(order -> {
                inventoryClient.releaseStock(order.getInventoryLockId());
                order.setStatus(OrderStatus.CANCELLED);
                orderRepository.save(order);
            });
    }
```

```java
// 库存服务 - 乐观锁实现
@Service
public class InventoryService {
    
    private final InventoryRepository inventoryRepository;
    
    @Transactional
    public InventoryLockResult lockStock(List<StockLock> locks) {
        List<String> failedProducts = new ArrayList<>();
        
        for (StockLock lock : locks) {
            int updated = inventoryRepository.updateStockWithOptimisticLock(
                lock.getProductId(),
                lock.getQuantity(),
                LocalDateTime.now().plusMinutes(15)  // 15分钟锁定
            );
            
            if (updated == 0) {
                failedProducts.add(lock.getProductId().toString());
            }
        }
        
        if (!failedProducts.isEmpty()) {
            return InventoryLockResult.fail(failedProducts);
        }
        
        String lockId = UUID.randomUUID().toString();
        return InventoryLockResult.success(lockId);
    }
}

@Repository
public interface InventoryRepository extends JpaRepository<Inventory, Long> {
    
    // 乐观锁扣减库存
    @Modifying
    @Query("UPDATE Inventory i SET i.stock = i.stock - :quantity, " +
           "i.lockedStock = i.lockedStock + :quantity, " +
           "i.lockExpireTime = :expireTime " +
           "WHERE i.productId = :productId " +
           "AND i.stock >= :quantity " +
           "AND i.version = :version")
    int updateStockWithOptimisticLock(
        @Param("productId") Long productId,
        @Param("quantity") int quantity,
        @Param("expireTime") LocalDateTime expireTime,
        @Param("version") Long version
    );
}

// 定时释放过期锁
@Scheduled(fixedRate = 60000)
public void releaseExpiredStockLocks() {
    List<Inventory> expiredInventories = 
        inventoryRepository.findByLockExpireTimeBefore(LocalDateTime.now());
    
    for (Inventory inventory : expiredInventories) {
        inventoryRepository.releaseExpiredLock(inventory.getId(), inventory.getLockedStock());
    }
}
```

## 总结

本章介绍了微服务架构的核心概念和实践要点：

### 核心要点

| 主题 | 关键点 |
|-----|-------|
| **架构特征** | 独立进程、业务聚焦、轻量通信、独立部署、去中心化管理 |
| **设计原则** | 单一职责、领域驱动设计（DDD）、独立部署 |
| **基础设施** | 服务注册发现、API网关、配置中心、分布式日志、监控追踪 |
| **服务通信** | 同步通信（REST/gRPC）、异步通信（消息队列） |
| **服务治理** | 限流、熔断、降级、超时处理 |
| **工程实践** | 电商系统微服务拆分案例 |

### 微服务架构优势

- 独立部署，加快交付速度
- 故障隔离，提高系统稳定性
- 技术多样性，适应不同业务场景
- 团队自治，提升开发效率
- 按需扩展，优化资源利用

### 微服务架构挑战

- 分布式系统复杂性
- 数据一致性挑战
- 运维复杂度增加
- 服务间通信开销
- 调试和追踪困难

在实际项目中，需要根据业务规模、团队能力和业务特性来权衡是否采用微服务架构，并逐步演进。
