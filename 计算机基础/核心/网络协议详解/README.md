## 学习路径建议

```
初学者路径：
1. 应用层概述 + DNS
2. HTTP/HTTPS (最常用，优先掌握)
3. WebSocket (与HTTP关联)
4. SSH (实践性强)
5. DHCP (理解网络基础)

进阶路径：
1. FTP + SMTP + POP3/IMAP
2. MQTT
3. 协议安全
4. 调试工具
```
